# 第一话「最后一单」· P14

**场景**：现代 · 山边别墅一层门厅 · 同一清晨（接 P13）

**页旨**：苏昭一口回绝——她没兴趣为一只老鼠下山。但她抬头看了一眼楼梯口那个端面的年轻人，改了主意：她去不了的地方，有人能去。她把陈默借出去了。

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 44% 处。竖线**左侧**由一条横格线切成上下两格；竖线**右侧**是一整格不间断的满高纵格，内部不许出现任何横线或斜线。Total regions = 3。主格是第 3 格右列满高纵格。
- 逐格人物数：第 1 格只有苏昭的**手与袖口**，不许出现任何脸；第 2 格只有苏雀一个人；第 3 格是苏昭 + 陈默两张正脸，加苏雀的**背影肩与后脑马尾一角**（无脸）作为前景。除这三格以外不出现第三个人，不许镜像、不许分身。
- 第 3 格是本页情绪落点，纵格要给足高度：苏昭站直（她比陈默略矮一点，抬眼看他），手搭在他肩上，姿态是「把东西递出去」而不是「吩咐」；陈默不许显出害怕，只有茫然。
- **苏昭不解释她为什么去不了**——三十里那个理由一个字都不提，画面与台词都不许出现锁、印、结界意象。
- 苏昭按 `assets/characters/su-zhao.png`：深墨长外套 + 低髻 + 右鬓一缕白发；全程不笑。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹；**没有白发、没有长外套**；第 3 格只允许背影视角。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫，左腕旧红绳必须露在袖口外；手里是那碗面，除此之外手上什么都没有（无包、无钥匙、无手机）。
- 变异鼠仍未定妆：第 2 格那张照片上只允许一个**无细节的黑色剪影**，不许画出老鼠的毛、牙、眼睛。
- 室内以 `comic/ch01/p13.jpg` 为准：老木长桌、桌角纸扎竹骨（竹骨 + 白纸团，不许骷髅、肋骨、人脸）、空白挂轴、后方木楼梯、黑窗外山影、桌上一盏铜罩灯（全页只这一盏亮着）。
- 桌面不许出现钞票捆；画面内不出现任何文字。
- 不画超自然现象。
- 配色：清晨冷白室内；饱和色只有苏雀的朱红与桌角灯的旧金。
