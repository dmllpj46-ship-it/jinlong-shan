# 第一话「最后一单」· P66 / 066

**场景**：现代 · 内河闸口 · 深夜，布饵

**页旨**：这一页把「认震动，不认人」变成可执行的动作：苏雀把三只系了纸的铅坠沉到深槽，**坠到底就停**，网绳绕一圈，水面只留三道同心弧；然后她咬住手电、手指立在唇前——「别动」。陈默一个人站在灯下的浅水里，第一次发现自己不需要搭场子：**场子就是这条河**。**主格是全段第一个不安：水面来了一道很宽、不动的鼓包**——不给水花、不给浪、不给露头，只给重量。

## 绘制备注

- **分格版式（恰好 3 格）**：三条横带各占页高 0–30% / 30–58% / 58–100%，**每带都是一整格通栏，带内不再切任何格线**；第 1、2 格之间的格线近水平微斜，第 2、3 格之间是**一条贯通全宽的斜格线**（左缘约 56% 页高、右缘约 60% 页高）。Total regions = 3。主格是第 3 格底部通栏 splash（42%）。**本页由 4 格降档为 3 格**：首 roll 与二 roll 都把中带溢出成 5 格，按 rule 14「连续两次溢出就降档」执行；原第 2、3 格合并为第 2 格的越肩构图。
- 逐格人物数：第 1 格**恰好两个人各一次**（苏雀在台阶、陈默在浅水），**电瓶车只有一辆**；第 2 格**恰好一个人**——苏雀（半侧脸与肩，咬着手电、手指立唇），前景水面**只有三只坠、三道纸、一圈网绳、三道弧**，**绝对不出现第二张脸**；第 3 格**恰好一个人**——陈默。**第 3 格绝对不许出现苏雀**，也不许出现鱼怪的头、鳍、须、眼。
- **数死的道具**：符纸**三道**、铅坠**三只**、同心弧**三道**；数字错了就重画。符纸全空白、无字无纹。
- **鼓包口径（全段最重要的一条）**：第 3 格那道鼓包是**水面被顶起来的一条很宽、边缘钝、不动的隆起**，只把灯的反光顶歪。**禁止**水花、浪、波纹扩散、气泡、漩涡、发光、露鳍、露头、露须、影子轮廓、水下剪影。它必须读起来像「重量在挪」，不像「有东西跳」。
- **苏雀不下水**：她全程在台阶或岸上；只有陈默的水到小腿。
- **HAIR / CAST LOCK**：纯黑发高马尾、红雀发夹、短款红夹克、银剪皮套在腰的是**苏雀**；短黑发、灰蓝工装夹克、左腕旧红绳、手里是更粗的旧木棍的是**陈默**——他**没有烧伤疤、没有长发、没有道袍**，掌心只有**一道细红印**（不肿、不破皮、无血、不发光）。
- **台词硬分配**：苏雀——「三道。坠到底就停。」「别踩那三道线。」「别动。」「它朝出声的地方去。」；陈默只有「……哦。」加两句心声。**苏雀不许说「这是练你」「你要变强」。**
- **内河口径**：窄、黑水、水泥护岸、老式水闸与闸房、铁爬梯、木桩、破渔网、倒扣塑料桶、留白警示牌；**禁止**游船、景观灯带、步道栏杆、钓客帐篷、广告灯箱、警车灯；水面除手电反光与灯反光外不自发光。
- 光：深夜，高杆路灯冷白单侧硬光、闸房钠黄一小片；第 2 格那只手电是关着的，不亮。
- 配色：墨黑 + 水泥灰 + 冷白 + 钠黄一点 + 苏雀红夹克与银剪冷银 + 陈默灰蓝；无金。
- 画面内不出现任何文字。
