# 第一话「最后一单」· P26

**场景**：现代 · 山边别墅一层门厅（长桌与墙边木架）· 凌晨（接 P25）

**页旨**：这一行的账不是钱——瓶是苏昭出的，单是苏雀跑的，所以元能**对半分**。陈默在旁边看着那圈东西自己爬过两只瓶口之间的一线空隙，第一次明白它不是「力量」，是「活的东西」。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 40% 处；线**以上**由一条斜切线分成左右两格（46% / 54%），该斜线起止都在这条上带内部，不得越到下半页；线**以下**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线。Total regions = 3。主格是第 3 格底通栏。
- 逐格人物数：第 1 格只有苏昭的手与瓶（**不给全身、不给第二个人**）；第 2 格只有苏雀 + 陈默 2 人（苏昭只露一只手，不给脸）；第 3 格只有陈默的半张脸 + 苏昭的手 + 苏雀的手——**共 3 人，任何一格都不许出现第四个头、镜像或分身**。
- **单件规则（本页最容易错的地方）**：全页**只有两只玻璃瓶**——一只里面有金色线圈（苏雀的），一只是空的（苏昭的）。不许出现第三只瓶、不许把同一只瓶复制到两只手里、不许瓶口对瓶口时多出第二对瓶。木架上的备用瓶一律画成**远处虚焦的一排轮廓**，不参与动作。
- 元能画法：只有**一缕丝**和瓶底**一小圈**，圈上只允许一个极小的头；不画光柱、不画漩涡、不画雾、不画电光。金是画面里唯一的过亮色。
- 室内以 `comic/ch01/p10.jpg`、`comic/ch01/p11.jpg` 成图为准：老木长桌、桌角纸扎竹骨、空白挂轴、油布裹的断水、木楼梯、黑窗外山影。全页只桌上那盏铜罩灯亮着。
- **HAIR / CAST LOCK**：
  - 苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发**；她**不碰符纸、不碰剪刀**。
  - 苏雀 = 朱红**短夹克** + **全黑高马尾** + 红雀发夹 + 左眼下小痣；**没有白发、没有长外套、没有提灯**，照明靠桌上那盏灯。
  - 陈默 = 藏青冲锋衣 + 灰连帽 + 全黑散发 + 左腕红绳 + 空白工牌。
  - **穿长外套的一定有白发；穿红夹克的一定是全黑高马尾；捧瓶的手按人头数分配，不许多出一双手。**
- 道具连续性：两只瓶都是**撕掉标签的普通小玻璃瓶**，无刻度、无字、无 logo；苏雀的瓶 = P22/P23 那只。
- 画面内不出现任何文字：瓶身、木架标签、挂轴、夹克纹样一律留白。
- 配色：室内旧金灯 + 墨黑；饱和色只给那缕金、苏雀的朱红、陈默的红绳。
