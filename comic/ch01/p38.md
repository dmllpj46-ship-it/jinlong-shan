# 第一话「最后一单」· P38

**场景**：现代 · 山边别墅院门外碎石路 → 门厅 · 当日傍晚（苏雀被叫上山）

**页旨**：人到齐。苏雀一进院的语气就不对——她不是来拿单子的，她是被叫来的；陈默刚刚从「她今天怎么没带吃的」这一件小事里意识到这家里有另一套规矩。本页只写到齐，任务一个字不出口。

## 绘制备注

- **分格版式（恰好 3 格）**：一条**贯通全高**的斜竖格线落在页宽 50% 处（上端偏右、下端偏左）；线左是一整格不间断的满高纵格（主格），内部不许再出现任何横线或斜线；线右由一条**贯通右列宽度的水平线**在页高 46% 处分成上下两格。Total regions = 3。
- 逐格人物数：第 1 格只有苏雀 1 人（在电瓶车上、脚撑地）；第 2 格只有陈默的手、膝盖和下半张脸；第 3 格只有苏昭的一只手 + 一只杯 + 一张空白纸条。**三个人各占一格，每格一个人**；全页不许出现第四个人头、不许同一个人出现两次。
- **HAIR / CAST LOCK**（三人同页，逐人锁死）：苏雀 = 朱红**短夹克** + 黑色高领 + **全黑高马尾** + 红雀发夹 + 左眼下小痣 + 腰侧纸符链 + 鞘里银剪——**穿朱红短夹克的人一定没有白发**。苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发**——**全页唯一有白发、唯一穿长外套的是苏昭**。陈默 = 藏青冲锋衣 + 灰连帽 + **短黑发** + 左腕红绳 + 空白工牌——**陈默没有白发、没有马尾、没有长外套**。谁容易被抢特征，谁的定妆稿就放参考图第一位。
- 纸雀数量：车把纸袋里**只允许一只**纸雀（延续 P12、P34 口径），不许两只、不许飞。
- 门廊灯口径：傍晚天未黑，**门廊那盏灯不亮**；全页不许出现任何点亮的灯。
- 空白纸条：无字、无纹、无印、无地址、无地图；就是一张裁白的纸。
- 场景：外观以 `assets/locations/bie-shu.png` 为准（院门、碎石路、贴山长的两层石砌老宅、爬藤、铁艺门上的空白门牌）；门厅以 `comic/ch01/p10.jpg` 的长桌与纸扎那一格为准。
- 画面内不出现任何文字：店招、纸袋、工牌、纸条、门牌一律留白。
- 配色：傍晚钠黄天光 + 沥青冷青 + 山影墨黑；饱和色只给苏雀那一身朱红与红鞋带。
