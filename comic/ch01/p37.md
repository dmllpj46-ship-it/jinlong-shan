# 第一话「最后一单」· P37

**场景**：现代 · 山边别墅一层门厅 · 同一清晨（接 P36，十分钟内）

**页旨**：一通没有名字的电话。她只问了三件事，然后说「我会安排」——读者到这一页才明白：安排早就想好了，安排就是那两个人。她一个字没告诉电话那头视频里是什么。

## 绘制备注

- **分格版式（恰好 3 格）**：一条**贯通全宽**的水平格线落在页高 42% 处；线以上由一条斜切线分成左右两格（48% / 52%），该斜线起止只在上带内部，不得越到下半页；线以下是一整格不间断的通栏 splash（主格，左、右、下三边出血），内部不许再出现任何竖线或斜线。Total regions = 3。
- 逐格人物数：第 1 格只有苏昭的一只手；第 2 格只有她的手腕 + 下颌与耳侧（同一个人，不许多出一张完整的脸）；第 3 格只有苏昭 1 人。**全页只出现一次完整的她**（第 3 格），不许有第二个她、不许玻璃或手机屏里反射出她的脸。
- **电话那头**：不给声音、不给对话气泡、不给画外文字、不给来电名字。读者只知道她问了三个问题，而且她问的顺序是**先人数、再位置**——她在核对，不在打听。
- **「我会安排」口径**：她说的是已经想好的事，不是「我去看看」。她**不问对方怎么处理、不说视频里是什么、不解释安排是什么**——安排的内容留到 P39 才给。
- **HAIR / CAST LOCK**：苏昭 = 炭灰长外套 + 月白内搭 + 低髻 + 右鬓白发 + 不笑；手里只有手机与一截纸扎竹骨；**断水用油布裹着立在墙角，不进她手里**；没有提灯。
- 光：全页只桌上那盏铜罩灯亮着（第 1 格桌角可见），主光是窗的晨光；手机屏只给一片不可读的白亮，不给 UI、不给图标。
- 现代场景禁令：手机屏、门牌、挂轴、碗上标签一律留白；不画品牌 logo、不画照片感、不画 3D。
- 画面内不出现任何文字。
- 配色：晨光冷白 + 室内墨 + 旧金灯一点；第 3 格她的影子要占到底带宽度，落点是「她做了一个决定」。

- 偏差③：第 1 格她那只拿手机的手没有同时捏竹骨，竹骨挪到了第 2 格另一只手里——两只手各做一件事，反而更好读，接受。
