# 第一话「最后一单」· P33

**场景**：现代 · 山边别墅门厅（今夜）／五百年前 · 断龙台（回忆回声）

**页旨**：全段的底牌，摊给读者看，不摊给陈默。苏昭真正在做的事：沈珩的元神裂成九块，散在五百年与九个地方；她要在九块凑齐之前，把主魂那一世先养住。**她出不去山门三十里，所以她养了一双能出山的眼睛——那就是苏雀。** 这一页一句解释台词都不给，全部走她的心声。

## 绘制备注

- **分格版式（恰好 3 格）**：整页只有两条**贯通全宽**的水平格线，分别落在页高 18% 与 70% 处；第一条带线（18% 处）在带内斜切，第二条带线（70% 处）是直线。全页**没有任何竖格线**，任何一条斜线都不得越出它所在的带。Total regions = 3。主格是第 2 格中带。
- 逐格人物数：第 1 格**没有人**（只有金龙的一爪与半截脊背嵌在岩层里）；第 2 格只有苏昭 1 人（**没有第二双手、没有她自己的镜像、窗外与走廊里都不许有人影**）；第 3 格只有**一只手与一张图**。全页合计只出现一次苏昭，不许出现第四个人头。
- **金龙口径（规则 12）**：这是五百年前那场大战的回忆，是允许出现实体金龙的两个场合之一。但本页只给**一只前爪 + 半截脊背嵌进岩层**的锁成态局部：**无翼、不喷火、不给头、不给整条龙、不腾空**。碎成几点白光散出去的是**元神九裂**，不是龙身崩解；光点拖细尾，不许画成人影、不许画成符、不许画成字。
- **赤蟒禁令（规则 13 + 正篇前段口径）**：本页**不出现赤蟒的任何部分**——不给眼、不给鳞、不给影子、不给金屑。它不在这张图里，它在下一次。
- **HAIR / CAST LOCK**：苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发** + 不笑；她**没有剪刀、没有提灯**（那盏灯是桌上的铜罩灯，不是她手里提的纸骨灯）。**苏雀整页不在场、不出现、不以剪影出现**——第 2 格那句「一双能出山的眼睛」只存在于心声里。
- **瓶子数量**：全页只有**一只瓶**（半满、瓶底一小圈金），第 2 格在她手里、第 3 格立在图纸上，是同一只。不许出现第二只瓶、不许那圈金发光外溢。
- 元能与光：第 2 格她脸上的亮是**桌灯的单侧光**，不是特效；瞳心不许泛金。第 1 格的白光是**魂裂的白光**，冷白、不带金；金只允许出现在瓶底那一圈。
- 场景以 `comic/ch01/p10.jpg`、`comic/ch01/p11.jpg`、`comic/ch01/p30.jpg` 成图为准；断龙台以 `assets/locations/jinlong-shan.png` 与序章 `comic/ch00/p06.jpg` 成图为准——**同一处石台、同一种烧化的符布**，不重新设计。全页只桌上那盏灯亮着。
- 画面内不出现任何文字：山形图、符纸、瓶身、挂轴一律留白。
- 配色：夜墨 + 单侧旧金灯 + 回忆那一带的冷白；饱和金只给瓶底那一圈。

- 偏差①：18% 处那条带线出来是直的，带内斜切没有兑现；三条带的比例与「全页无竖线」两项都保住，接受。
- 偏差②：中带「桌灯只照亮她半张脸、另半张在墨里」出成了接近双侧受光，暗部仍重；她的表情给到的是累，不是悲，落点未走偏。
- 偏差③：中带她举瓶的手抬到了胸口高度，与「另一手按左胸」形成两手都在胸前的构图；脚本要的是握瓶的手低一些。读起来像她在把瓶与胸口那处并置，正是本页要的意思，接受。
