# 第一话「最后一单」· P46

**场景**：现代 · 慕白的民宿院子 / 镇口往北的土路 · 第二天清早

**页旨**：本段落收束页。慕白终于给了答复，但答复的形式是**绕开**——「今天先带你们看镇子」；同时他把「住几天」这件事反过来交给了他们（两把没有木牌的钥匙）。最后一页落在一个不需要任何解释的画面上：**禁区围栏的缺口被人从外面新补过**。

## 绘制备注

- **分格版式（恰好 4 格）**：三条贯通全宽的水平格线，分别落在页高 24% 与 70%；线以下由一条斜切线分成左右两格（46% / 54%），斜线起止只在这条底带内部，不得越进中带或顶格。Total regions = 4。主格是第 2 格中带通栏。
- 逐格人物数：第 1 格三个人（慕白背影 + 苏雀 + 陈默），**不许有第四个**；第 2 格只有慕白（侧后半张脸 + 两只手，**一只推钥匙、一只在擦**，不许出现第三只手）；第 3 格只有陈默的一只手掌与他的下半张脸；第 4 格**没有人**。
- **新铁丝口径（本段最后的钩子）**：缺口那道铁丝必须是**亮的、没有锈的**，与整片锈网形成明确对比；除此之外本格不许出现任何别的异常——不许血、不许弹壳、不许脚印、不许轮胎印、不许动物尸体、不许黑影。「有人常来补围栏」这一层由读者自己得出，**任何角色都不许说破**。
- **慕白口径**：同 P42（**`assets/characters/mu-bai-v2.png`**，v1 作废）。第 1 格他只有背影与侧后（围裙、毛巾、**谢顶的那块头顶与四周花白**、矮胖厚腰的轮廓、搪瓷缸在窗台上）；第 2 格给侧后半张脸，**不给完整正脸**——本页他的脸仍然留一半，正脸全景已经给过 P44。
- **钥匙口径**：民宿门厅木板上是一排旧黄铜钥匙（P43 成图口径：画面不逐把数死，「九把 + 两块空白木牌」只活在 P43 陈默数的那两句台词里）；本页推出去的两把**没有木牌**，与那两块空白木牌呼应。钥匙一律旧黄铜、无编号、无字。
- **HAIR / CAST LOCK**：苏雀 = 全黑高马尾 + 红雀发夹 + 朱红短夹克（无白发、无长外套、无提灯）；陈默 = 短黑发 + 灰蓝工装夹克 + 左腕旧红绳；慕白 = **六十多岁矮胖老头** + 谢顶四周花白 + 圆框眼镜 + 苔灰绿对襟短褂。三人特征不许互换，尤其不许让慕白长出陈默那一头浓密黑头发。
- 光：清晨低角度侧光 + 雾；第 4 格的亮只允许出现在**那道新铁丝的一小段**上（本页唯一的高光），其余保持灰。全页不出现点亮的灯、不出现金色。
- 台词口径：慕白答非所问是性格，不是故弄玄虚——他给的每一样东西（钥匙、侧门、看镇子）都是**实际有用的**，他只是不解释。苏雀这一页只说三个字「看镇子。」，她听懂了但不确认；**她仍然不许把「慕白 + 电话 + 视频 + 黑森林」拼成一条线**。
- 场景：院子以 P42、P43 成图为准（石水槽、晾衣绳、木楼梯、白灰墙）；土路与铁丝网以 P41 第 4 格为准（同一条路、同一个水泥墩），**黑森林在本页只允许是围栏外的一条缝**。
- 画面内不出现任何文字。
- 配色：晨雾冷灰 + 木褐 + 苔灰绿 + 一点朱橘（苏雀）+ 新铁丝的一点冷白高光。
