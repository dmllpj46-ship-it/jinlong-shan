# 第一话「最后一单」· P61 / 061

**场景**：两时代同页 · 现代：山边别墅门厅 · 同夜 deeper（苏雀与陈默都睡了） / 回忆：五百年前，太清宫还在，龙潭镇——那时还是二十来户的一个山脚村

**页旨**：全书第一次由**苏昭自己**领读者进五百年前——不是打，是一顿饭。那一夜桌边坐着三个人：她、沈珩、还有那个已经在这个村口盛饭的老头。五百年后这桌只剩下她一个会记得，而那个「只剩下」她一个字不讲。这一页要让读者拿到三件事：**① 慕白五百年前就是现在这个样子**（没变过、不老，但只由画面说，没有人说出来）；**② 苏昭与沈珩在那里住过**，那条旧账是真的；**③「世事变迁，半点不由人」第一次由读者自己得出**，不靠旁白，不靠角色宣讲。

## 绘制备注

- **分格版式（恰好 4 格）**：两条**贯通全宽**的水平格线分别落在页高 22% 与 68%，把页面切成上（22%）、中（46%）、下（32%）三条横带；上带与中带内部**不许再切任何格线**；只有**底部那条带**内部由一条**接近竖直、略微斜切**的格线分成左右两格，该斜线的起止只在底带内部。Total regions = 4。主格是第 2 格中部通栏（占页高 46%）。
- 逐格人物数：第 1 格**只有苏昭一个人**（今生，正脸）；第 2 格**恰好三个人各一次**——沈珩（坐，正侧脸）、苏昭（前世，坐，正侧脸）、慕白（**只到侧后身与手**，弯腰摆鞋），**不许把任何一个人画成两份**；第 3 格**只有两只手 + 三只碗**，**这一格绝对不出现任何一张脸**；第 4 格**只有苏昭一个人**（今生）。
- **三个人互不认错（HAIR / CAST LOCK，逐人写死）**：① 穿**月白道袍、长发披肩、左颊一道烧伤疤**的人一定是**沈珩**——他年轻，脸按 `assets/characters/shen-heng.png`；② 穿**太清宫月白/黛青弟子袍、黑长发简单发髻、腰侧佩断水**的人一定是**苏昭的前世**，她的脸按 `assets/characters/su-zhao.png`，**这一页整页不许出现任何一缕白发**（白发是今生才有的）；③ **矮胖、谢顶四周花白、圆框眼镜、双下巴、苔灰绿对襟布扣短褂、肩灰毛巾、腰上旧黄铜钥匙串含一块空白木牌**的人一定是**慕白**——他跟现代页长得一模一样，**五百年不许给他任何「年轻版」**，也**禁止一切道士视觉语言**。穿长外套、右鬓有白发的是**今生的苏昭**，只出现在第 1、4 格。
- **不老只由画面说，禁止任何人说破**：慕白在五百年前与今晚是同一张脸、同一身衣服——**不许任何角色说「他没变」「他不老」「他几百年」**；第 2 格与第 4 格之间不许叠印、不许碎裂边框、不许回忆滤镜，只用格线硬切（承 P59 回忆页口径）。
- **回忆页禁用物（时代错位，出现即作废）**：**搪瓷缸**（近代物）——回忆里桌角那只压角的缸一律画成**粗陶缸**；**手机、塑料、电线、水泥砖、卷帘门、机动车、铁皮**一律不许出现；**铁丝网、水泥墩警示牌、混凝土掩体、石牌坊、景区石栏、台阶**全是五十年代以后的东西，回忆页不许有。
- **回忆页可用物**：木棚与瓦檐、木柱、缺腿垫石的长桌、粗瓷碗与粗陶缸、纸罩油灯、麻绳、布鞋、布幌子（**空白不可读**）、卵石、空白旧山形图、墨黑针叶、淡金雾、weathered stone。
- **山的画面**：五百年前**只允许远处一道黑山影**——不许画金脉、龙形、裂缝、光点、灯。金龙在整页不出现。
- **瓶的库存（时代约束）**：第 2、3 格（回忆）**不出现任何玻璃瓶**——撕标签的玻璃瓶是苏昭今生的常备物。第 1、4 格（现代）桌角木架上那一排瓶留在暗部，全页**只有一只是亮的**（陈默带来那半只）。
- **光源**：现代两格——桌上锥形罩台灯，**全页唯一现代光源**，窗外给黑；回忆两格——檐下纸罩油灯一处暖光 + 淡金雾的漫射，回忆与现代的光**不许互相进画**。
- **叙事禁令**：全页没有一个字可读；不许任何人说出「蛇」「白」「问您好」「守林子」「不老」「元能」「锁」「山腹」「赤蟒」；沈珩不知道自己五百年后会变成谁，苏昭前世不许有任何预知式台词；**苏昭今生心里那三句不许对她自己以外的人说出口**。
- 光：第 1、4 格冷夜单侧暖黄；第 2、3 格淡金雾 + 油灯暖点，逆光强、边缘化开。
- 场景：门厅以 `comic/ch01/p60.jpg` 成图为准（同夜延续）；回忆里的木棚客栈为本页新场景，**不与山边别墅串味**——不许出现别墅的铁艺院门、爬藤墙、两层石砌外观。
- 画面内不出现任何文字。
- 配色：现代——纸白 + 墨黑网点 + 暖黄灯锥 + 炭灰（长外套）+ 一小圈旧金；回忆——淡金雾 + 墨黑针叶 + 朱砂一点（她的发绳）+ 月白 + 苔灰绿（慕白）。
