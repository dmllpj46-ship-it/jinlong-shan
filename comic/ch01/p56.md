# 第一话「最后一单」· P56

**场景**：现代 · 龙潭镇 · 慕白的民宿堂屋与二楼走廊 · 当天深夜（围捕当晚）

**页旨**：慕白第一次把**担心**说出口，而且说得像记账：先是羊，再是人——一样东西一年里出第二次，就不是运气。他不知道元能、不知道锁、不知道山腹：他知道的只有**次数**，而次数已经够了。本页要读者拿到这一段真正的坏消息——**这不是一个事件，这是一个开始**；同时让读者第一次看见「他记得的比说出来的多」，而这一页**不解释为什么**（答案在 P59）。

## 绘制备注

- **分格版式（恰好 3 格）**：一条**贯通全高**的竖直格线落在页宽 54% 处，把页面切成左右两半；线左是**不间断的满高纵格**（主格，三边出血）；线右由一条**接近水平、略微斜切**的格线分成上下两格（约 54% / 46% 页高），该斜线的起止只在线右内部。左半内部不许再切任何格线。Total regions = 3。
- 逐格人物数：第 1 格**只有慕白一个人**，全页他不与任何人对视；第 2 格**恰好两个人**——苏雀与陈默，各一次，**不许多出第三个影子、不许把他们各自画成两份**；第 3 格**只有慕白的一只手**（腕部以下），不许出现第二只手、不许露脸。
- **纸上的圈要数死**：第 1 格纸上**已有三个圈、笔尖正在画第四个**，第四个**不闭合**；圈一律是**墨炭的圆**，纸上**没有任何字、没有图例、没有等高线数字、没有地名**。第 3 格那第四个圈刚画完、仍不闭合。
- **光源（民宿夜戏硬约束）**：全页**只允许一处光源**——第 1 格那盏锥形罩台灯。第 2 格走廊必须是暗的（只有从堂屋漏到墙上的一点点边界光，不给走廊照明）；**二楼那扇挂铜锁的门在这一格不给光，门缝下面绝对不许漏亮**（承 P45 口径）。窗外给黑，不许月光铺满房间。
- **慕白口径（v2.3，`assets/characters/mu-bai-v2.png` 为唯一依据）**：矮胖、约 163 cm、谢顶四周花白、圆框眼镜架鼻尖、双下巴、厚腰软腹；苔灰绿对襟布扣短褂 + 米白内衫 + 布腰带 + 深灰长裤 + 肩灰毛巾 + 左手木珠 + 腰上旧黄铜钥匙串（含空白木牌）+ 掉漆蓝灰搪瓷缸。**禁止一切道士视觉语言**：无道袍、无发髻、无须发、无符纸、无罗盘、无法器、无灯阵、无朱砂、无剑。他不是一个高人，他是个在灯下算数的老头——**脸上不许出现「洞悉」的表情**。
- **民宿不是苏昭的山边别墅**：不许出现长桌、没糊完的纸扎竹骨、墙上空白挂轴、立着油布断水的墙角、那一排撕了标签的玻璃瓶。堂屋里只有八仙桌、条凳、锥形罩台灯、门后钉钥匙的木板（木牌空白）、白灰墙与木梁。
- **黑森林口径**：这一页**林子不入画**，围栏、铁丝、警示牌一律不出现。
- **叙事禁令**：全页没有一个字可读；不许任何人说出「元能」「气」「山腹」「锁」「赤蟒」「狼的种类」；慕白的台词只到「它在往外走」为止，**不许他解释那是什么**。苏雀不追问，陈默不提问——本页没有一句问话得到回答。
- **HAIR / CAST LOCK**：扎全黑高马尾、红色雀形发夹、朱红短夹克、胯侧银剪皮套的是**苏雀**——没有白发、没有长外套、没有提灯、没有剑；短黑发、灰蓝工装夹克、左腕旧红绳的是**陈默**——没有烧伤疤、没有长发、没有道袍；穿苔灰绿对襟短褂的矮胖老人是**慕白**，他一定有谢顶 + 花白 + 圆框眼镜。
- 光：夜——单侧暖黄台灯锥 + 大片纯黑网点；远墙比近桌灰一档。
- 场景：堂屋与那张手绘路以 `comic/ch01/p45.jpg` 成图为准；走廊与二楼那扇门以 `comic/ch01/p43.jpg` 成图为准。
- 画面内不出现任何文字。
- 配色：暖黄灯锥 + 纸黄 + 墨黑网点 + 苔灰绿（慕白）+ 一点朱橘（苏雀）+ 水泥灰。
