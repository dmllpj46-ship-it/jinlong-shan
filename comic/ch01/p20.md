# 第一话「最后一单」· P20

**场景**：现代 · 城西货仓内部 · 通道中段 · 同一夜（战斗页一）

**页旨**：苏雀施展的是太清宫传下来的手艺——不是法阵，不是咒语，是一只铜铃、一串空白符纸和一把银剪。她要读者在这一页看清：**驱魔人是干活的，不是表演的**。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 48% 处（**斜的**，从左 46% 斜到右 50%）；线**以上**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线；线**以下**由一条斜切线分成左右两格（48% / 52%），该斜线起止都在这条下带内部，不得越到上半页。Total regions = 3。主格是第 1 格顶通栏。
- 逐格人物数：第 1 格只有苏雀（腾空全身）+ 陈默的一只手与半条腿 + 一只鼠怪；第 2 格只有苏雀（胸像）；第 3 格只有陈默的一双白球鞋与小腿 + 一只鼠怪，**苏雀不在本格，连手都不给**。
- **一只，永远一只**：全页只允许一只变异鼠，一个头、一条连续脊椎；尾巴不得接触头部。禁止第二只、禁止群鼠。
- 变异鼠按 `assets/creatures/bian-yi-shu.png`：脏灰短毛、弓背、可数肋骨、裂到耳根的嘴、两颗过长门齿、浅金小圆眼（不发光、无竖瞳）、一只粗前爪掌垫开裂、过长白尾中段打折、尾尖缠空白纸带；体型只有猫那么大。皮下金纹是暗的，只有被铃声震到时才浮起一线，**不许发光成光球、不许冒烟**。
- 苏雀的手艺只有这四样：银剪（皮套在胯侧）、空白符纸串、旧铜铃、便利店钥匙串。**禁止**法阵、光盾、剑光、符文、咒语字、翅膀、悬浮莲花。她的动作是武术 + 手工，不是法师。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾（腾空时马尾甩起）+ 红雀发夹 + 左眼下小痣 + 虎牙；**没有白发、没有长外套、没有苏昭的纸骨灯**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳 + 空白工牌 + 磨旧白球鞋。
- **HAIR / CAST LOCK**：腾空穿朱红短夹克的一定是全黑高马尾；倒地穿藏青冲锋衣的一定是全黑短发、左腕红绳。
- 元能的画法只用三种：金屑（第 1 格洒出的一小把）、过亮的金色细线（铜铃的耳鸣波纹）、半透明金雾（不许成片）。**不画黑气、不画虫、不画闪电。**
- 打斗版式硬要求：主格占页高 48%，横向力用通栏；至少一条斜切线（本页有两条）；主格三边出血；小反应格（第 2、3 格）全部排在主格之后。
- 画面内不出现任何文字：符纸、纸箱、货架、手机、铃身一律留白。
