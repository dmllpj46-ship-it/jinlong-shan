# 第一话「最后一单」· P36

**场景**：现代 · 山边别墅一层门厅 · 同一清晨（接 P35）

**页旨**：苏昭给这段视频定性——不是野狗，是撞上了东西的活物。她说的每一句都是排除法，没有一句解释来源。读者拿到「这事归这一行管」，苏雀和陈默都还没拿到。

## 绘制备注

- **分格版式（恰好 3 格）**：一条**贯通全高**的斜竖格线落在页宽 46% 处（上端偏左、下端偏右）；线左由一条**贯通左列宽度的水平线**在页高 44% 处分成上下两格；线右是一整格不间断的满高纵格（主格），内部不许再出现任何横线或斜线。Total regions = 3。
- 逐格人物数：第 1 格只有苏昭 1 人（全身小影）；第 2 格只有她的一只手；第 3 格只有苏昭的侧脸。**全页只苏昭一人**——没有第二个人、没有她的两只手各属一人、没有镜子里的她；苏雀与陈默整页不在场，也不以剪影或回忆出现。
- **排除法口径**：她只说「不是什么」和「漏得远」。**不许她说元能、不许说赤蟒、不许说山腹、不许说锁**——这一页她一个字也不解释。
- 窗外山脊口径：白天，**不给任何光点**，不留一盏没熄的灯，不画金线、不画龙形（与 P23 那个夜里针尖大的灯点明确区分）。
- 光：全页唯一的室内光源是桌上那盏铜罩灯（还亮着），主光来自窗；她脸上的亮是**窗光切出的斜边**，不是特效；瞳心不泛金。
- **HAIR / CAST LOCK**：苏昭 = 炭灰长外套 + 月白内搭 + 低髻 + 右鬓白发（全页唯一一处白发）+ 不笑；无银剪、无纸符链、无高马尾、无朱红短夹克。
- 画面内不出现任何文字：手机屏幕、挂轴、浆糊碗上的标签一律留白。
- 配色：晨光冷白 + 室内未散的夜墨 + 一点旧金灯；不出现饱和金。
