# 第一话「最后一单」· P32

**场景**：现代 · 山边别墅院中 · 一个月后的夜里

**页旨**：他做到了不该做到的事，于是问出那个真正的问题。苏昭给了他一句**真的话**——真的，但不是那一句。这一页的张力不在答案，在于她答得太快：快得像她早就准备好了一句可以说的。

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 54% 处；线**左侧**是一整格不间断的满高纵格，内部不许再出现任何横线或斜线；线**右侧**由一条斜切线分成上下两格（约 44% / 56% 页高），该斜线起止都只在右列内部，不得越到左半页。Total regions = 3。主格是第 3 格左列满高。
- 逐格人物数：第 1 格只有**陈默的一只手**（不给脸）；第 2 格只有**苏昭的下半张脸**（不给眼睛、不给第二张脸）；第 3 格只有苏昭 + 陈默 2 人。全页不出现第三人，苏雀不在场；**主格里那两张脸必须与两格特写分别对得上，不许多出第三张脸、不许镜像**。
- **HAIR / CAST LOCK**：
  - 苏昭 = 炭灰**长外套** + 月白内搭立领 + **低髻** + **右鬓白发** + 不笑；她手里**没有瓶、没有剪刀、没有提灯**。
  - 陈默 = 藏青冲锋衣 + 灰连帽 + **全黑散发** + 左腕红绳 + 空白工牌；年轻男人，**不许低髻、发簪、白发、长外套**。
  - **穿长外套的一定有白发；穿冲锋衣的一定是全黑散发。**
- 元能：第 1 格掌心那一圈是**一小圈 + 一个极小的头**，稳、不溢；不许画光柱、光晕、漩涡、雾。第 3 格主格里**没有任何发光**——两人之间那点亮是屋里的灯，不是特效。
- **瞳心禁令**：苏昭的眼睛不许画成运功状态、不许瞳心泛金；她脸上的亮是灯与月光的交界，陈默同理。
- 器械：地上那根旧木棍无护手、无剑格、无绑绳；断水不出现（它在屋里墙角，油布裹着）。
- 场景：院子与门厅以 `assets/locations/bie-shu.png`、`comic/ch01/p24.jpg`、`comic/ch01/p31.jpg` 成图为准；屋后山脊压下来比房子大三倍，**山脊上没有任何光点**，山腹也不画金线。全页只屋里那一盏灯亮着。
- 画面内不出现任何文字：工牌、手机、院墙、门牌、夹克纹样一律留白。
- 配色：夜墨 + 月光冷青 + 一线旧金灯；饱和色只给掌心那一圈金、陈默的红绳。
