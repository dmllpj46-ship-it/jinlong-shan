# 第一话「最后一单」· P76 / 076

**场景**：现代 · 李家小院 → 回程山道 · 后天上午近午

**页旨**：收束页交给两个人。第一刀给李母：她拉苏昭的袖口，轻声说「我知道没用。」「我就是想让他有个事做。」——**母亲配合的不是风水，是儿子的孝心**；这句全段只许她说一次，往后任何角色不许复述。苏昭的反应上限承 P60：手停半拍 + 「……嗯。」她的两句心声只给读者：「我知道两个月长什么样。」「我送走过四个。」第二刀给回程：陈默问「阵有用吗。」苏昭答「有用。」——**真话，缺一块**（有用是对儿子有用）；陈默的心声收在全章反复出现的那句观察上：「她答得太快了。」（承 P32）。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 22% 与 60%；只有中带内部由一条近竖、略斜的格线切成左 46% / 右 54%，斜线起止只在本带内部；上带与下带内部不许再切。Total regions = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好三个人**——陈默（背对）、李母（坐、给脸）、李锦鸿（背影弯腰），苏昭**只到手臂与衣袖**；第 2 格**恰好两个人各一次**（李母、苏昭半脸）；第 3 格**恰好一个人**——苏昭；第 4 格**恰好两个人各一次**（苏昭、陈默）。
- **那两句刀只说一次**：李母的「我知道没用 / 我就是想让他有个事做」**全段仅此一处**，轻声、只够两人听见；**禁止**旁白复述、禁止陈默听见、禁止苏昭回应解释。苏昭的反应上限＝手停半拍 + 「……嗯。」，**禁止**动容、笑、低头、拥抱。
- **「我送走过四个」只给读者**：这是心声，指她看过四个「他」活完一生；**禁止**任何角色在本页或往后复述这句，**禁止**陈默听懂。
- **「有用」是真话缺一块**：苏昭答得平、不回头；**禁止**她解释对谁有用。**禁止**陈默想明白；他的心声只到「她答得太快了」为止（承 P32 同一句观察）。
- **山的口径**：第 3 格山只给墨黑剪影 + 白天；**不给金脉、不给龙形、不给光点**（城里望山是另一侧山面）。
- **HAIR / CAST LOCK**：右鬓白 + 低髻 + 炭灰高领长外套的是**苏昭**；短黑发 + 灰蓝夹克 + 左腕红绳 + 怀里竹骨捆的是**陈默**；针织帽 + 驼色围巾 + 红布袋的是**李母**；灰鬓角 + 炭灰大衣的是**李锦鸿**（本页只给背影）。
- **道具收尾**：图纸袋与安全帽**本页不再入画**（P75 只此一次）；陈默怀里是拢好的竹骨捆与那盏熄了的纸灯；苏昭手里没有瓶（本段瓶全程不入画）。
