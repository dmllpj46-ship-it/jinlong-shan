# 第一话「最后一单」· P47

**场景**：现代 · 龙潭镇 · 慕白的民宿堂屋 · 下午（到达的当天下午，黑森林还没进）

**页旨**：读者第一次拿到「袭人」的完整版本——不是网传视频那一段，而是镇上知道得更早的事：**先是牲口，然后是人**。慕白讲的方式是只讲他亲眼看见的，不讲结论、不讲种类、不讲数量；他讲得越平静，读者越清楚这个人在镇上知道的事比镇子多。本页另一个落点：他是**劝过那三个人**的人。

## 绘制备注

- **分格版式（恰好 3 格）**：一条**贯通全高**的垂直格线落在页宽 48% 处；线以左是一整格不间断的满高纵格（主格），线以右由一条斜切线分成上下两格（54% / 46%），该斜线的起止只在这条右带内部，不得越到左格。Total regions = 3。主格是第 1 格左列满高。
- 逐格人物数：第 1 格只有慕白一个人；第 2 格只有苏雀一个人（陈默只到肩，不给脸）；第 3 格只有**一只手 + 陈默的半张侧脸**。全页不许出现第四个人，不许有镜中像、窗外人影、楼上探头的人。慕白**一页只出现一次**——第 3 格那只手是他的，但不许再画他的脸或身体。
- **慕白口径（v2.3，`assets/characters/mu-bai-v2.png` 为唯一依据；v1 作废）**：六十多岁矮胖老头，约 163 cm，厚腰软腹、微微驼，头顶谢、四周稀疏花白，圆脸垂腮、双下巴，圆框金属眼镜架在鼻尖，胡子刮净，嘴角向下但无恶意；苔灰绿对襟布扣短褂 + 米白内衫 + 布腰带 + 深灰长裤，肩搭灰毛巾，左手木珠，腰上一串旧黄铜钥匙（一把坠空白木牌），右手掉漆蓝灰搪瓷缸。**禁止一切道士视觉语言**：无道袍、无须发、无发髻、无符纸、无罗盘、无剑、无灯、无朱砂。脸上不许有「高人在此」。
- **民宿 ≠ 苏昭的山边别墅**：本页不许出现长桌、没糊完的纸扎竹骨、空白挂轴、立着油布断水的墙角、那一排撕了标签的玻璃瓶。标志物只有：木结构、石槽、晾衣绳、门后那块钥匙木板、八仙桌与方凳。
- **叙事禁令（慕白的台词口径）**：他只讲**他看见的**——牲口、坡、围栏、他劝过；不许他说出「狼」「变异」「元能」「几只」「从哪来」。他的信息一律写成结论或目击，不写成推理；允许只说半句，禁止他说完。「我劝过」是他本页唯一一次露出自己的位置。
- **HAIR / CAST LOCK**：穿苔灰绿对襟短褂、戴圆框眼镜的**一定是那个谢顶矮胖、四周花白的老人**；扎全黑高马尾、戴红色雀形发夹、穿朱红短夹克、胯侧挂银剪皮套的是苏雀——**没有白发、没有长外套、没有提灯、没有剑**；短黑发、灰蓝工装夹克、左腕旧红绳的是陈默——**没有沈珩的烧伤疤、没有长发、没有道袍**。慕白不许长出陈默那一头浓密黑头发。
- 光：全页下午的散射日光，从右侧门洞进来，慕白在门洞光的边缘上（半张脸亮、半张脸灰）；右带两格是室内平光。全页不出现点亮的灯、不出现金色。
- 场景：民宿堂屋以 `comic/ch01/p44.jpg`（饭桌与吊灯）与 `comic/ch01/p45.jpg`（堂屋门板、方凳、锥形罩台灯）成图为准；本页是同一间屋子的白天。
- 画面内不出现任何文字：手绘路上无字，钥匙木牌空白，招牌留白。
- 配色：木褐 + 白灰墙 + 苔灰绿 + 搪瓷蓝灰 + 席黄；一点朱橘只给苏雀的夹克。
