# 第一话「最后一单」· P09

**场景**：现代 · 山门镇东侧 · 山边别墅门外 · 次日入夜

**页旨**：陈默骑着电瓶车找到景区范围之外的那条旧路，看见的不是一间铺子，而是一栋贴着山长的别墅。灯先给人看见，人才给灯照出来。

## 绘制备注

- **分格版式（恰好 4 格 = 右列一整格满高主格 + 左列三格纵向堆叠，整页铺满，多一格都不许有）**：左列三格上中下相加等于整页高度；右列是一整格，内部不得再切分、不得加插图、不得有人像压住格线。斜切格线只在左列中格与上/下格之间。
- 别墅外观严格按 `assets/locations/bie-shu.png`：两层石砌、爬藤绞东墙、铁皮屋檐、木格窗、铁艺院门、门廊下一盏灯、背后是金龙山山脊。
- 苏昭按 `assets/characters/su-zhao.png`：右鬓一缕白发、低髻素木簪、炭灰高领长外套、月白交领内搭；灯按第一话 P01–P03 成图的旧铜罩玻璃灯（同尺寸、褪色朱砂绳灯柄），不画光柱。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕红绳 + 车钥匙；不戴头盔、不穿制服。
- **尺度对比**是这一页的重点：主格里山比房子大、房子比人大，人不许画得比窗还高。
- 金龙山在主格只允许作为黑色山脊出现，最多在岩缝里透一线将熄的金；不画龙形、不画金雾、不画光束。
- 画面内不出现任何文字：门牌、导览牌、招牌、车牌一律留白；无真实品牌 logo。
- 配色：夜色冷青 + 钠黄路灯 + 一点旧金灯焰；饱和金只给灯。
