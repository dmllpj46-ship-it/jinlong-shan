# 第一话「最后一单」· P18

**场景**：现代 · 城西货仓内部 · 封条被起开之后 · 同一夜

**页旨**：两个人在仓里找了一遍。苏雀一眼就读完这口仓的账——撞弯的立柱、长拖痕、墙脚一排爪痕；陈默什么都没读出来，他只是一个被叫来搬东西的人。这一页要把「专业」和「茫然」并排放。

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 44% 处；线**左侧**由一条斜切线分成上下两格（42% / 58% 页高），斜线起止都在这条左列内部，不得越到右半页；线**右侧**是一整格不间断的满高纵格，内部不许再出现任何横线或斜线。Total regions = 3。主格是第 3 格右列满高。
- 逐格人物数：第 1 格只有苏雀（两指 + 半张脸）；第 2 格只有苏雀（蹲姿侧影）+ 陈默的一双白球鞋与小腿；第 3 格只有两人，远景，都不给正脸。不许出现第三个人、不许出现鼠、不许出现影子以外的第二个轮廓。
- 主格必须画出尺度差：货架与桁架占满整格，两个人只占约页高十分之一；通道尽头的亮点是唯一的视线出口。
- 场景以 `assets/locations/huo-cang.png` 为准：波纹铁皮顶与桁架、单人高钢制货架、水泥地、塌掉的空白纸箱垛、手推液压车、挂在墙上的铁罩灯（本页**全灭**）。立柱的弯折方向、拖痕位置、墙脚爪痕都要和设定图对得上。**苏雀不许提灯**——纸骨灯是苏昭的道具，本页光源只有手电与门缝那条钠黄。
- 变异鼠在本页**不出现**：只允许爪痕、拖痕、撞弯的货架、塌掉的纸箱。禁止任何正脸、剪影、发光眼。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹 + 腰侧银剪与纸符链；**没有白发、没有长外套**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳 + 空白工牌 + 磨旧白球鞋；手机屏幕是黑的、无信号格、无任何文案。
- **HAIR / CAST LOCK**：穿朱红短夹克的一定是全黑高马尾；穿藏青冲锋衣的一定是全黑短发、左腕红绳。
- 光的规则：仓里没有任何顶灯、没有应急灯亮，也没有任何明火；光源只有苏雀手里那道冷白手电、陈默已经暗下去的手机屏，和通道尽头门缝底下的一条钠黄。
- 画面内不出现任何文字：纸箱、货架标签、墙面、手机、灯罩一律留白。
- 配色：混凝土灰 + 钢架蓝灰 + 纸箱土黄 + 墨黑；暖色只有那一盏灯。
