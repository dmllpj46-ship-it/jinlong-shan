# 第一话「最后一单」· P24

**场景**：现代 · 山边别墅院门外与门廊 · 凌晨（货仓之夜之后，接 P23 收罐）

**页旨**：干完活的第一句话不是「多少钱」，是「回来了」。苏昭在凌晨开着门廊那一盏灯等着——她走不出三十里，所以只能在这里等；而陈默第一次意识到，山上这个人知道他今晚去了哪儿。

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 56% 处；线**右侧**是一整格不间断的满高纵格，内部不许再出现任何横线或斜线；线**左侧**由一条斜切线分成上下两格（各约 46% / 54% 页高），该斜线起止都只在左列内部，不得越到右半页。Total regions = 3。主格是第 1 格右列满高。不要窄条、不要内嵌小格、不要第 4 格。
- 逐格人物数：第 1 格 = 苏昭（门廊下，中景，给到脸但不是特写）+ 门外两个极小的背影（苏雀、陈默），共 3 人，两个小身影**不给正脸**；第 2 格只有陈默 1 人；第 3 格只有苏雀 1 人。任何一格都不许出现第 4 个人、镜像或分身。
- 主格必须画出尺度差：山脊与屋体占画面上部三分之二，两个刚下车的人在画面下方只占约十分之一页高——「人被山和灯牵着走」。
- 别墅外观以 `assets/locations/bie-shu.png` 为准：粗砌灰褐石墙、木格窗（多数是暗的）、压扁的铁皮屋檐、只绞住一面墙的爬藤、锈铁艺院门与门柱上一块**空白**门牌、门廊下一盏旧铜罩玻璃灯（灯柄褪色朱砂绳）。不把山画成龙形，不画第二盏亮着的灯。
- **HAIR / CAST LOCK**（本页三人同场，逐条写死）：
  - 苏昭 = 炭灰**长外套** + 黑发**低髻** + **右鬓一缕白发** + 清冷不笑；她手里只有那盏铜罩灯。**穿长外套的一定有白发。**
  - 苏雀 = 朱红**短夹克** + **全黑高马尾** + 红雀发夹 + 左眼下小痣 + 笑露虎牙；**没有白发、没有长外套、没有提灯、没有剑**。
  - 陈默 = 藏青冲锋衣 + 灰连帽衫 + 全黑短发（散发，无髻）+ 左腕旧红绳 + 空白工牌；**没有白发、没有长外套、没有灯**。
  - 参考图第一位是苏昭与陈默的联合身份稿：白发与长外套只归其中穿长外套的那位，红绳只归穿冲锋衣的那位。
- 道具连续性：陈默的保温箱是 P01 起那一只，无 logo、本轮多一道刮痕；苏雀的电瓶车无 logo；苏雀腰侧银剪在鞘里。
- 不画超自然现象：没有发光、没有金雾、没有金线入画；元能罐在本页**不出现**（在苏雀夹克内侧口袋里，画面外）。
- 画面内不出现任何文字：门牌、车身、保温箱、夹克纹样、封条一律留白。
- 配色：凌晨冷蓝 + 山影墨黑；饱和色只给门廊那一盏旧金灯、苏雀的朱红、陈默的红绳。
