# 第一话「最后一单」· P40

**场景**：现代 · 山边别墅一层门厅 · 同夜（接 P39，一分钟后；本段落收束页）

**页旨**：苏雀抢在苏昭之前把「黑森林」三个字说出来——她是从满网转的那段视频里认出来的，苏昭一个字没告诉过她。苏昭那一拍沉默，是这一话里她第一次被人抢先。陈默看看这个又看看那个，全场只有他什么都不知道。钩子落在最后一句：苏昭说「不是视频」。

## 绘制备注

- **分格版式（恰好 2 格）**：全页只有一条斜格线——从顶边约 42% 处切到左边约 34% 处，把左上角切出一格楔形；其余整页是第二格（大 splash，向右、下、上三边出血），内部**不许再出现任何横线、竖线或斜线**。Total regions = 2。主格是第 2 格。
- 逐格人物数：第 1 格只有苏雀的一张脸（四分之三侧）；第 2 格有 3 人各一次——苏昭侧脸与停在半空的一只手、苏雀坐在长凳上的全身、陈默站在最外侧。**苏雀在本页出现两次（第 1 格特写 + 第 2 格全身），两处必须是同一个人、同一身朱红短夹克、同一只红雀发夹；第 2 格里的她只有一个头。** 全页不许有第四个人、不许镜像、不许窗玻璃里映出任何人。
- **HAIR / CAST LOCK**：苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发**（全页唯一白发）+ 不笑；苏雀 = 朱红**短夹克** + 黑色高领 + **全黑高马尾** + 红雀发夹 + 左眼下小痣 + 鞘里银剪，**没有白发、没有长外套、没有提灯、没有剑**；陈默 = 藏青冲锋衣 + 灰连帽 + **短黑发** + 左腕红绳 + 空白工牌。谁容易被抢特征就把谁的定妆稿放参考图第一位。
- **收束口径**：苏昭「我没说黑森林」之后**不承认、不否认、不解释**；她的落点是那只停在半空的手。苏雀的得意只到虎牙那一格，第 2 格里她已经察觉语气不对。**「不是视频」是全页最后一句话，之后不给任何解释。**
- 陈默的表情口径：他的懵是**跟不上**，不是蠢——嘴微张、眼神在两人之间、身体还保持端碗的姿势，碗歪、汤快到沿；最多一根极小的汗线，不许画卡通大汗滴、不许翻白眼、不许下巴脱臼。
- 灯：全页只桌上那盏铜罩灯亮着（与 P39 同一处），窗外山黑——**不给任何光点、不给金线、不给龙形**。
- 那张空白纸条在桌上只允许**一张**，无字；茶壶与三只杯子沿用 P12 的口径（第三只杯子早就推好了）。
- 场景以 `comic/ch01/p39.jpg` 成图为准（同一张长桌、同一排纸扎、同一面空白挂轴、同一扇敞着的院门）。
- 画面内不出现任何文字。
- 配色：夜墨 + 单侧旧金灯 + 朱红一点；不出现饱和金。

- 偏差①：陈默没有「头转到一半」，他低头看着碗。他的懵从「跟不上」变成「插不进话」，本页台词照样落得住，接受。

- 偏差③：苏昭腰上那条褪色朱红腰绳延续 P36 起的画法，本页一致。
