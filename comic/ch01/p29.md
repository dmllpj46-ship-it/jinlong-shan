# 第一话「最后一单」· P29

**场景**：现代 · 山边别墅院门外 · 清晨（接 P28，两三个小时之后，天已经亮了）

**页旨**：苏雀走之前留一句话。她不是长辈，也不是姐姐——她是这座山上唯一能替苏昭出山的那双眼睛，所以这句话**只有她配说**：把那个人给我护好。苏昭答得极轻，轻到像她已经答应过别人很多次。

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 46% 处；线**左侧**由一条斜切线分成上下两格（约 44% / 56% 页高），该斜线起止都只在左半列内部，不得越到右半页；线**右侧**是一整格不间断的满高纵格，内部不许再出现任何横线或斜线。Total regions = 3。主格是第 3 格右列满高。
- 逐格人物数：第 1 格只有苏雀 1 人；第 2 格只有一只手与半截手臂（**不给脸、不给第二双手**）；第 3 格只有苏昭 1 人（苏雀在画面最下方只给一个极小的背影轮廓，不给脸）。全页不出现第四个人、镜像或分身。
- **HAIR / CAST LOCK**（逐条写死）：
  - 苏雀 = 朱红**短夹克** + **全黑高马尾** + 红雀发夹 + 左眼下小痣 + 虎牙；**没有白发、没有长外套、没有提灯、没有剑**。
  - 苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发** + 不笑；只有她可以站在院门内侧。
  - **穿长外套的一定有白发；穿红夹克的一定是全黑高马尾。**
- 道具：她的移动照明是一支**黑色手电**，本页是白天，手电不出现；纸雀只允许从便利店纸袋口探出**一只**。苏昭手里**没有瓶**——昨晚那两只瓶一只在她内袋、一只在苏雀夹克内侧，本页都不画出发光。
- 场景以 `assets/locations/bie-shu.png` 与 `comic/ch01/p24.jpg` 成图为准：压扁的铁皮屋檐、只绞住一面墙的爬藤、锈铁艺院门与门柱上那块**空白**门牌、碎石车道。白天版：门廊那盏灯**熄着**，全页没有任何点亮的灯。
- 山脊那一线光是**晨光照出来的岩层亮面**，不是金脉发光，不许画成龙形、不许画成灯点。
- 画面内不出现任何文字：门牌、纸袋、车壳、夹克纹样、挂轴一律留白。
- 配色：清晨冷白 + 石灰墙 + 墨黑山影；饱和色只给苏雀的朱红、她发夹的红、陈默那扇窗里没露出来的暗。
