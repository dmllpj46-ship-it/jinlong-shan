# 第一话「最后一单」· P19

**场景**：现代 · 城西货仓内部 · 通道尽头 · 同一夜

**页旨**：老鼠怪冲出来，直取陈默。这一页是变异鼠的**首次正脸**——它不是巨物，它只有猫那么大，但它扑过来的样子比巨物更吓人；陈默吓破胆，苏雀的手已经在剪子上。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 34% 处；线**以上**由一条斜切线分成左右两格（46% / 54%），该斜线起止都在这条上带内部，不得越到下半页；线**以下**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线。Total regions = 3。主格是第 3 格底通栏。
- 逐格人物数：第 1 格**没有人**，只有那只爪与一段脊背；第 2 格只有苏雀（全身三四分面）+ 陈默的肩与前襟；第 3 格只有陈默（倒地）+ 苏雀的一条手臂 + 一只鼠怪。
- **一只，永远一只**：全页只允许一只变异鼠，一个头、一条连续的脊椎；尾巴不得接触或压住头部。禁止第二只、禁止幼鼠、禁止群鼠。
- 变异鼠按 `assets/creatures/bian-yi-shu.png`：脏灰短毛贴皮、脊背一道秃皮带皮下暗金细纹、弓成高峰的背、可数的肋骨、裂到耳根的嘴、两颗过长门齿、浅金小圆眼（**普通圆瞳孔，不发光**）、一只前爪特别粗且掌垫开裂、过长的白尾中段打了个折、尾尖缠着一小条空白纸带。体型只有猫那么大，不许画成狗、不许画成巨鼠、不许画成怪兽。
- 尺度差：主格里鼠怪的身长要明显小于陈默的小腿——它是「小东西造成的巨大恐惧」，不是巨兽页。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹 + 左眼下小痣 + 虎牙；**没有白发、没有长外套**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳 + 空白工牌 + 磨旧白球鞋。
- **HAIR / CAST LOCK**：穿朱红短夹克的一定是全黑高马尾；穿藏青冲锋衣的一定是全黑短发、左腕红绳；倒地那位一定是穿冲锋衣的。
- 光的规则：唯一光源是地上那只甩出去的手电（冷白）与门外漏进来的钠黄；苏雀**不带任何提灯**（纸骨灯是苏昭的道具）；鼠怪身上不许有任何自发光，皮下金纹是**暗的、不闪**。
- 暴力尺度：少年漫画级。本页无血、无伤口、无肢解；恐惧全靠动作与表情。
- 画面内不出现任何文字：纸箱、货架、手机、灯罩、封条一律留白。
