# 第一话「最后一单」· P73 / 073

**场景**：现代 · 昭记铺内 · 午后，接 P72

**页旨**：钱与价。李锦鸿把一沓厚钞推过来，**手是平的**——陈默读出的对比是「他推钱的手，比扶人的手稳」。苏昭**不解皮筋，只从上面拿一张**，剩下的推回去：「阵不贵。」然后她不接钱先问三件事，问的全是**次数与来路**：多久了、谁先提的阵、她信不信。最后一个回答前的那半拍停顿（「……信。」）是本段第一颗种子——儿子其实不确定母亲信不信。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 22% 与 60%；只有中带（22–60%）内部由一条近竖、略斜的格线切成左 46% / 右 54%，斜线起止只在本带内部；上带与下带内部不许再切。Total regions = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**只有两只手**（李锦鸿推钱的手、苏昭搭罗盘的手），零脸；第 2 格**只有两只手**，零脸；第 3 格**恰好两个人**——李锦鸿半张脸、苏昭只到下颌与衣领（**不给苏昭整脸**）；第 4 格**恰好两个人各一次**——苏昭（下半张脸 + 手）、李锦鸿（四分之三侧全身）。**那沓钱全页只有一沓 + 被抽走的一张**，不许画成两沓。
- **钱的口径（正典沿用）**：钞票一律**皮筋捆着的无字纸钞**——无头像、无数字、无面额、无国徽、无真实人民币纹样。苏昭只收现金；本页她**只拿一张**，这是她的价，不是客气，**不许任何角色解释为什么是一张**。
- **问的顺序就是判断**：三问「多久了 / 谁先提的阵 / 她信不信」——她问的是次数与来路，不是病情（承 P62 口径）。**禁止**她问生辰、八字、医院名字、药名。
- **那半拍停顿**：「……信。」之前的省略号是演出来的——李锦鸿答前**眼神向下半拍**。不许加旁白解释。
- **HAIR / CAST LOCK**：鬓角灰 + 炭灰大衣 + 素银表的是**李锦鸿**；右鬓白 + 低髻 + 炭灰高领长外套的是**苏昭**（本页只到下半张脸与手）；陈默与李母**本页不入画**（陈默只以心声存在）。
- 参考图链计划：① `assets/characters/su-zhao.png` ② `assets/characters/li-jin-hong.png` ③ `comic/ch01/p72.jpg`。
- 配色：午后暖灰 + 炭灰 + 纸钞的米白 + 罗盘旧铜；饱和色只给李母围巾那一角驼色（第 3 格虚焦）。
- 画面内不出现任何文字（钞票、纸袋、罗盘盘面一律留白）。
