# 第一话「最后一单」· P13

**场景**：现代 · 山边别墅一层门厅 · 同一清晨（接 P12）

**页旨**：苏雀摊开她的活——城西货仓里一只老鼠吃了元能，长成了不该长的东西。她要苏昭出手；顺便让读者知道，这个扎高马尾的姑娘不是便利店小妹，她一直接私活，是个驱魔人。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 40% 处；线**以上**是一整格不间断的通栏，内部不许出现任何竖线或斜线；线**以下**由一条斜切线分成左右两格（46% / 54%），该斜线起止都在这条下半带内部，不得越到上半页。Total regions = 3。主格是第 1 格顶通栏。
- 逐格人物数：第 1 格只有**一只手与袖口**（苏昭的手），不许出现任何脸、不许出现苏雀的手、不许出现第二个人；第 2 格只有苏雀一个人正脸；第 3 格只有苏昭一个人正脸 + 陈默**半张脸与一只袖子**在背景楼梯上。
- **变异鼠未定妆**：本页不出现任何清晰的老鼠形象。只允许：照片里的爪痕、拖痕、撞弯的货架、塌掉的纸箱，以及照片边缘一个**没有细节的黑色剪影**（无眼、无齿、无毛、无正脸）。不许画成怪兽、不许发光、不许画第二只。
- 照片是**空白相纸上的灰调影像**：画面里不出现任何可读文字、日期戳、水印。
- 苏雀按 `assets/characters/su-que.png`：全黑高马尾 + 红雀发夹 + 左眼下痣 + 虎牙 + 朱红短夹克 + 腰侧银剪与纸符链；**没有白发、没有长外套**。
- 苏昭按 `assets/characters/su-zhao.png`：深墨长外套 + 低髻 + 右鬓一缕白发；**绝不穿红夹克、绝不扎高马尾**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳；只在第 3 格背景露半张脸，手里一碗面。
- 室内以 `comic/ch01/p12.jpg` 为准：老木长桌、桌角没糊完的纸扎竹骨（竹骨 + 白纸团，**不许骷髅、不许肋骨、不许人脸**）、空白挂轴、后方木楼梯、黑窗外山影、桌上一盏铜罩灯。
- 桌面不许出现钞票捆、不许出现第二盏灯。
- 不画超自然现象；元能只以台词存在，画面不给光效。
- 配色：清晨冷白室内；饱和色只给苏雀的朱红与桌角灯的旧金。
