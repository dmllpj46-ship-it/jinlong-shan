# 第一话「最后一单」· P45

**场景**：现代 · 慕白的民宿 · 深夜

**页旨**：一页没有人说正事，但读者拿到本段最要紧的一个画面：**慕白一个人在准备进林子的那件事**。同时把陈默的感官第一次变成叙事工具——他在山上住过一个月，已经习惯了山体里那一声闷响，而镇子太安静，他睡不着。

## 绘制备注

- **分格版式（恰好 3 格）**：一条**贯通全高**的垂直格线落在页宽 46% 处；线以右是一整格不间断的满高纵格（主格），线以左由一条斜切线分成上下两格（52% / 48%），斜线起止只在左带内部，不得越到右格。Total regions = 3。
- 逐格人物数：第 1 格只有慕白一个人（**一个**，不许有第二张脸、不许镜中像）；第 2 格只有陈默一个人躺着；第 3 格只有**一只布鞋**，没有人。全页苏雀不进画面（她睡着了，这一页不给她镜头）。
- **地图口径**：手绘的等高线式老地图，线条是铅笔与淡墨，**上面不许出现任何可读的字、数字、坐标或图例**；它的形状要读得出「一条山脉 + 一片林子 + 一条路 + 一块用虚线围起来的区域」，但不许画成现代卫星图或旅游导览图。
- **慕白口径**：同 P42（**`assets/characters/mu-bai-v2.png`**，v1 作废）。本页他坐着俯身，至少给出：谢顶与四周那一圈花白、圆框眼镜（镜片反着灯，看不见眼睛）、苔灰绿对襟短褂、肩上的毛巾、左手木珠串。**不许给他任何法器、符纸、罗盘、道袍**；他不是法师，他做的事是「看路」。
- **陈默口径**：短黑发、灰蓝工装夹克（脱了搭在椅背上，他只穿里面那件旧 T 恤睡）、左腕旧红绳**睡觉也不摘**——这是他的标志物，必须出现在交叠的手腕上。
- 光：**全页唯一光源是第 1 格那盏带锥形灯罩的旧台灯**。第 2 格只有窗外那一条极弱的月光边（不许画成灯光、不许室内亮）；第 3 格门缝下**绝对不给光**——这条是本页的钩子，一旦漏光就废。
- 台词口径：慕白那句心声「再晚半个月。」是**全页唯一一句和时间有关的话**，不解释是什么的半个月（雪、封路、禁区的季度巡线都算，读者自己排）。往后写慕白，允许他说半句，禁止他说完。
- 场景：堂屋与二楼走廊以 P43、P44 成图为准（木梁、白灰墙、方凳、门后钥匙木板、走廊尽头那扇锁着的门）。
- 画面内不出现任何文字。
- 配色：夜戏冷墨 + 台灯暖黄一小圈 + 木褐；不出现金色、不出现朱红（苏雀不在场，她的夹克色也不许出现）。
