# 第一话「最后一单」· P22

**场景**：现代 · 城西货仓内部 · 尸体旁 · 同一夜（战斗之后）

**页旨**：陈默第一次亲眼看见「元能」被从一具尸体里抽出来、装进一只撕了标签的玻璃瓶。他终于震惊——不是因为怪物，是因为**这套流程有人做过很多次，而且做得很熟练**。

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 46% 处；线**左侧**由一条斜切线分成上下两格（44% / 56% 页高），斜线起止都在这条左列内部，不得越到右半页；线**右侧**是一整格不间断的满高纵格，内部不许再出现任何横线或斜线。Total regions = 3。主格是第 3 格右列满高。
- 逐格人物数：第 1 格只有苏雀的两只手 + 尸体（**不给她的脸、不给全身**）；第 2 格只有陈默（蹲姿、半张脸）+ 苏雀的一句画外音；第 3 格只有苏雀的手与瓶 + 陈默的半张脸 + 鼠怪尸体的半截脊背与尾巴。
- **一只，永远一只**：全页只允许这一具尸体，一个头、一条连续脊椎，尾巴不得接触头部；禁止第二只、禁止群鼠、禁止任何活鼠。
- 元能的画法（本页是正篇第一次「入瓶」）：抽离时是**一缕丝**，不是虫、不是黑气、不是烟雾团；入瓶后蜷成**一小圈**，只允许一个极小的头，圈身不超过瓶底三分之一。瓶外允许一层薄雾与三粒金屑，**不许发光成光球、不许照亮整个仓**。
- 道具连续性：玻璃瓶 = P07 那只、P16 苏昭塞进陈默口袋的那只，**标签已撕、瓶身空白**；木塞是苏雀随身的小木塞；小木勺是昭记那把。银剪仍插在鼠怪下颌。
- 变异鼠尸体按 `assets/creatures/bian-yi-shu.png`，塌下去、毛色回灰、眼散焦不发光；体型猫那么大。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹；**没有白发、没有长外套**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳 + 空白工牌 + 磨旧白球鞋。
- **HAIR / CAST LOCK**：捏金丝的那双手一定连着朱红短夹克与全黑高马尾；递瓶子的那位一定是藏青冲锋衣、全黑短发、左腕红绳。
- 光的规则：饱和金只允许出现在三处——瓶里那一圈、陈默瞳孔里的反光、左腕红绳。其余画面保持混凝土灰与墨黑。
- 画面内不出现任何文字：瓶身、标签残胶、纸箱、货架、木勺一律留白。

- 偏差③：主格里的鼠尸画成**完整一具**（脚本只要求露半截脊背与尾巴），地面光斑读作甩出去的手电；本页与 P19/P21 都**没有任何提灯**——照明口径已统一为黑色手电 + 门外钠黄，脚本的灯光备注已同步改正。
