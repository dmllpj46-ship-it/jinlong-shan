# 第一话「最后一单」· P75 / 075

**场景**：现代 · 山脚 · 李家小院 · 后天上午，晴

**页旨**：法事页，画成**手艺**不画成法术。苏昭摆阵用的全是物件：罗盘、拉直的棉线、撒的米、陈默上午糊的那盏纸灯。她给李锦鸿的唯一指令是「站着。陪她。」——**阵的真正功能由这句口令说出来，但谁都不许把它讲成道理**。本页同时埋下主线的第一颗道具级种子：廊下**一只空白图纸卷袋 + 一顶黄色安全帽**，全段只入画这一次，**任何角色不许看它、碰它、提它**（李锦鸿的钱接采金集团 / 拆锁工程，往后回收，本段一个字不解释）。李母在全页最后一格**笑了一下**——全段她唯一一次笑。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 20% 与 68%；上带与中带内部不许再切；只有底带内部由一条近竖、略斜的格线切成左 46% / 右 54%，斜线起止只在本带内部。Total regions = 4。主格是第 2 格中部通栏 splash（48%，本段最大单格）。
- 逐格人物数：第 1 格**恰好三个人各一次**（苏昭、陈默、李锦鸿）；第 2 格**恰好四个人各一次**（苏昭蹲、陈默跪、李母坐、李锦鸿站）——**俯角小人不许复制**；第 3 格**只有两只手**，零脸；第 4 格**恰好一个人**——李母（李锦鸿只到搭椅背的一只手）。
- **法事＝手艺（硬口径）**：**禁止**法阵光效、咒语字、符文凭空燃烧、金雾、光柱、瞳心金圈、罗盘指针疯转、任何「能量逸出」。米是**几条直线**，棉线是**拉直的一根**，罗盘指针**不动**。火苗是普通火苗。纸灯是竹骨 + 白纸团，**禁止人脸、骸骨意象**。
- **主线道具（只此一次）**：空白图纸卷袋 + **黄色安全帽**（无字、无 logo、无徽章），放在第 2 格右下角廊下。**任何角色不许看它、碰它、提它；不许给特写格；不许旁白点破。** 图纸一律空白不可读。往后回收前不许再入画。
- **李家口径（新场景，三十里内）**：山脚新建的小院——白灰墙、铁门、水泥地、藤椅、廊下；**不是**苏昭的别墅（不许出现长桌、纸扎竹骨堆、空白挂轴、油布断水、那排玻璃瓶），**不是**慕白的民宿（不许出现石水槽、晾衣绳、钥匙木板、八仙桌）。苏昭与陈默是**上门**，带进来的物件只有纸扎竹骨、纸灯、罗盘、棉线、米袋。
- **HAIR / CAST LOCK**：右鬓白 + 低髻 + 炭灰长外套的是**苏昭**（本页俯角小人 + 手，**不给正脸**）；短黑发 + 灰蓝夹克 + 左腕红绳的是**陈默**；灰鬓角 + 炭灰大衣的是**李锦鸿**；针织帽 + 再生灰发 + 靛蓝布扣衫 + 驼色围巾 + 手背淤青的是**李母**。
- 参考图链计划：① `assets/characters/li-mu.png`（第 4 格她的脸是本页戏眼，第一位）② `assets/characters/li-jin-hong.png` ③ `comic/ch01/p74.jpg`（锁苏昭与陈默的本段造型）。
- 配色：上午晴光、白灰墙 + 水泥灰 + 靛蓝 + 驼色 + 一点纸灯暖黄 + **安全帽的工程黄**（全页唯一饱和黄，只给那一顶）；无金、无夜。
- 画面内不出现任何文字（图纸、安全帽、门牌一律留白）。
