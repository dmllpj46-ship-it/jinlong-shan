# 第一话「最后一单」· P21

**场景**：现代 · 城西货仓内部 · 通道尽头 · 同一夜（战斗页二 · 收束）

**页旨**：这是第一话目前最大的一格。它要同时给出两件事：**杀死了它**，和**杀死它的人看起来一点也不开心**。少年漫画的爽点给画面，代价给表情。

## 绘制备注

- **分格版式（恰好 3 格）**：两条横格线**贯通整页宽度**，分别落在页高 18% 与 70% 处；第一条是斜的（从左 16% 斜到右 20%），第二条是直的。**全页不允许任何竖格线**，三条带各自是一整格不间断的画面，带内部不许再出现任何竖线或斜线。Total regions = 3。主格是第 2 格中通栏，也是第一话目前最大的一格。
- 逐格人物数：第 1 格只有苏雀的一只白球鞋与地面；第 2 格只有苏雀（半跪全身）+ 一只鼠怪，**陈默不在本格，连手都不给**；第 3 格只有苏雀（胸像）+ 鼠怪尸体的半截脊背与尾巴。
- **一只，永远一只**：全页只允许一只变异鼠，一个头、一条连续脊椎；尾巴不得接触头部。禁止第二只、禁止群鼠、禁止幼崽。
- 变异鼠按 `assets/creatures/bian-yi-shu.png`：脏灰短毛、弓背、可数肋骨、裂到耳根的嘴、两颗过长门齿、浅金小圆眼（此时**失焦、不发光**）、过长白尾中段打折、尾尖缠空白纸带；体型只有猫那么大。死后身体塌成一小团，毛色回落到普通灰。
- 暴力尺度：少年漫画级。**允许**一摊暗色血、外翻的门齿、张开的嘴；**禁止**肢解、内脏、断肢、血浆喷溅、伤口特写。剪子穿过的部位画在**下颌与地面/钢脚之间**，不画贯穿身体的剖面。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹 + 左眼下小痣；银剪是她的，**不是武器库里的剑**；**没有白发、没有长外套**。
- 陈默全页不出场（只在第 3 格画外音），他的存在由苏雀的视线方向承担。
- 光的规则：唯一光源是苏雀手里那支**黑色手电**（冷白，落在地面成一圈光斑）与门外漏进来的钠黄；苏雀不带任何提灯；金屑是画面里唯一的过亮金色，只允许出现在鼠怪颈后那一小把。
- 打斗版式硬要求：主格 ≥50% 页高、三边出血、尺度差（鼠怪在苏雀膝下只占一小块）；反应格（第 3 格）排在主格之后。
- 画面内不出现任何文字：符纸、纸箱、货架、地面一律留白。

## 成图记录

`comic/ch01/p21.jpg`（1024×1536，450 KB）。两次生成：

- v1：三条全宽横带（18% / 52% / 30%）成立，但银剪被画成**两件**——苏雀手里一把、腰侧鞘里又一把；且击杀的落点不清楚，读起来像「她举着剪刀站着」。
- v2：加入单件规则（THE SCISSORS EXIST EXACTLY ONCE，在她两只手里；腰侧鞘必须是空的），并把击杀写具体——剪刀穿过鼠的下颌、把它钉在货架底脚的铁座上，身体还悬着一弧，地上一小摊深色血。接受 v2。

- 本页是全章最大单格：中带宽 52%、横贯整页，是「通栏主格压水平力」的用法（剪刀的力是水平的）✓；第一条带带线斜切，无竖格线 ✓。
- 陈默整页缺席（他的位置在上一页被吓瘫，这一页不给他镜头）✓；无第三个人、无分身 ✓。
- 暴力尺度：只有下颌一处穿刺 + 一小摊血，无断体、无喷血、无内脏，符合少年向刊物口径 ✓。
- 偏差：鼠的尸体在成图里仍偏大（承 P19 的尺度偏差），且尾巴多出一个结扣状的凸起——与定妆稿的「打结的空白纸胶带」同源，视为一致。
- 教训：**同页出现同一件标志物两次**是这一批最常见的错法（P21 剪刀、P22 罐子）。凡是手里拿着的道具，提示词都要额外写一句「对应的鞘 / 挂点必须是空的」。
