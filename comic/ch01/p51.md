# 第一话「最后一单」· P51

**场景**：现代 · 黑森林深处 · 上午（布阵刚完，陈默站在空地上出声之后）

**页旨**：异兽第一次给读者看清正脸——**是一只变异的野狼**，但这一页的恐怖不来自它有多强，而来自它的**比例不对**：肩线低于臀线、身体过长、脊下有不发光的暗金筋。陈默在心里认出了「狼」，同时立刻否定这个答案。本页不砍、不咬、不见血——只让它走出来。

## 绘制备注

- **分格版式（恰好 3 格）**：两条**贯通全宽**的水平格线分别落在页高 22% 与 72% 处，把页面切成上、中、下三条横带，三带内部**一律不再切任何格线**（没有斜切、没有竖线）。Total regions = 3。主格是第 2 格中通栏（占页高 50%）。
- 逐格人物/生物数：第 1 格只有那只狼的**后半段与腿**，无任何人；第 2 格**恰好一只狼 + 一个陈默**（陈默只在右下角，背影，很小）；第 3 格只有陈默的颈与下颌。全页不许出现第二只动物，不许出现苏雀、慕白、手下的任何身体部分（慕白只有画外音）。
- **变异野狼口径（v2.5 定妆，`assets/creatures/bian-yi-lang.png` 为唯一依据，参考图必须第一位）**：一只被元能撑坏的**普通动物**，不是妖、不是龙、不是魔物。硬性形态：肩线低于臀线（后高前低的斜背）、躯干过长、四肢偏短、尾巴粗且打结下垂、毛结块挂湿针叶、皮下暗金筋纹**暗淡哑光、绝不发光**、眼睛是浅草黄的**普通圆瞳孔，不发光、无竖瞳、无红眼**。一页只允许出现**一只**，全页只能有一个连续的躯干。
- **禁止项**：禁止给它翅膀、角、鳞、额外肢体、多个头；禁止画成赤蟒或任何蛇形；禁止任何龙形、龙纹、龙睛；禁止它张口喷出光、能量、火焰；禁止发光的眼齿爪；禁止把它画得像狼人与兽人。它流血的方式是普通动物的方式（本页不见血）。
- **暴力口径（少年向）**：本页无伤口、无血、无撕咬。恐怖只靠比例与安静。
- **陈默口径**：短黑发、灰蓝工装夹克、左腕旧红绳、手里一根带皮毛刺的木棍；**没有烧伤疤、没有长发、没有道袍、没有沈珩的脸**。他这一页**不使用任何元能**——身上不许出现金色光线。他站在包围圈中间，脚没动。
- **HAIR / CAST LOCK**：本页只有陈默一个人，仍要锁死：他是**年轻男性、一头浓密短黑发**；不许把他画成谢顶花白的老人、不许画长发、不许加道袍。狼的定妆稿放参考位第一位，防止它被别的参考图带成蛇或狮。
- **无人机口径**：本页它可以在远处树缝上方作为一个小黑点存在，或不出现；若出现，仍然无标识、无屏幕、不发光、不拍第一视角。
- 光：林下**散射灰光**，主格里狼的背部受一点天光、腹部沉进黑；陈默在画面右下，只给轮廓亮边。全页不出现点亮的灯、除了狼皮下的哑光暗金筋以外**不出现任何发光体**。
- 场景：黑森林深处以 `comic/ch01/p50.jpg`（密针叶树黑竖纹、湿腐叶、锈网、空白警示牌）成图为准；本页是同一块空地边缘。
- 画面内不出现任何文字：警示牌空白、无任何标语、无任何字幕条。
- 配色：松墨绿黑 + 腐叶褐 + 雾灰 + 狼毛的脏灰褐与骨白 + 暗金筋（哑光）；陈默的灰蓝。**主格的背景压到最暗，让狼是唯一的中高调块面。**

- 规则 14 三项校验：**格数** 3 格合格——三条贯通全宽的横带（22% / 50% / 28%），无斜线无竖线；**复制** 合格——第 1 格只有后腿与结尾、第 2 格整狼一次 + 陈默极小背影一次、第 3 格只有陈默的喉与下颌，全页一只狼；**串味** 合格——狼无翅无角无鳞无蛇身、眼睛是普通圆瞳不发光、皮下金线哑光；陈默短黑发 + 灰蓝夹克 + 木棍，身上无金。
- **形态钩子合格**：主格用**正侧身**走位，肩低臀高、身长腿短、头压得低的「比例不对」一眼可读；第 1 格先只给后半段（结尾 + 后腿压进烂松针），把「狼不会长成这样」的疑点铺在前面。
- 已接受偏差：第 1 格的铁丝网只到画面上缘一小段；第 3 格的下颌特写没画出「咽回去的一声喊」的口水/喉结动势，靠台词补。按规则 6 收下。
