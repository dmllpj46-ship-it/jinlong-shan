# 第一话「最后一单」· P25

**场景**：现代 · 山边别墅一层门厅 · 凌晨（接 P24，一夜之后）

**页旨**：苏雀把整场击杀讲成一段评书，手比脚划；苏昭从头到尾没问那只老鼠有多大、有多快、藏在哪——她只问了一句「他人有没有事」。这一页的落点不是打斗复盘，是**这两个人在意什么**。

## 绘制备注

- **分格版式（恰好 3 格）**：整页只有两条**贯通全宽**的水平格线，分别落在页高 18% 与 70% 处；第一条带线（18% 处）在带内斜切，第二条带线（70% 处）是直线。全页**没有任何竖格线**，任何一条斜线都不得越出它所在的带。Total regions = 3。主格是第 2 格中带。不许切出第四格、不许内嵌小格、不许留窄条。
- 逐格人物数：第 1 格只有苏雀 1 人（苏昭、陈默不入画）；第 2 格只有苏雀 + 陈默 2 人；第 3 格只有苏昭 1 人。全页合计不出现第四个人、镜像或分身。
- 室内以 `comic/ch01/p10.jpg`、`comic/ch01/p11.jpg` 成图为准：一层门厅一张老木长桌、桌角一排没糊完的纸扎竹骨、墙上一幅空白挂轴、角落立着油布裹的断水、木楼梯在后方、黑窗外是山影。本页窗外**不给灯**，全页只桌上那一盏亮着。
- **HAIR / CAST LOCK**（苏昭 / 苏雀 / 陈默 特征相近，逐条写死）：
  - 苏昭 = 炭灰**长外套** + **低髻** + **右鬓一缕白发** + 不笑；只在第 3 格出现，坐着，手里没有剪刀、没有符纸。
  - 苏雀 = 朱红**短夹克** + **全黑高马尾** + 红雀发夹 + 虎牙；她在比划，**手里只有竹篾和空气**，绝不出现剪刀实体、绝不出现提灯、绝不出现白发与长外套。
  - 陈默 = 藏青冲锋衣 + 灰连帽 + 全黑散发 + 左腕红绳 + 空白工牌；只出现在第 2 格，站在后面。
  - **穿长外套的一定有白发；穿红夹克的一定是全黑高马尾；穿冲锋衣的一定有红绳。**
- 道具：第 2 格那根竹篾是桌角纸扎骨架上抽出来的，**不是银剪**；银剪在本页只允许待在苏雀腰侧鞘里，画面里不出现第二把。
- 不画超自然现象：没有发光、没有金雾、没有符纸自燃、没有回忆闪回画面。
- 画面内不出现任何文字：挂轴、杯身、夹克纹样、窗外招贴一律留白。
- 配色：室内旧金灯 + 墨黑阴影；饱和色只给苏雀的朱红、陈默的红绳、灯焰的一点金。
