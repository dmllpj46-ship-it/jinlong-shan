# 第一话「最后一单」· P17

**场景**：现代 · 山下城西侧工业区 · 城西货仓外 · 夜里（接 P16 下山）

**页旨**：这一单是**秘密**请的——老板不敢让任何人知道仓里有什么，所以驱魔人这个职业没有招牌。陈默第一次看见「苏雀的工位」：一口封着的仓，和一个只在半夜出现的人。

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 54% 处；线**左侧**是一整格不间断的满高纵格，内部不许再出现任何横线或斜线；线**右侧**由一条斜切线分成上下两格（各约 46% / 54% 页高），该斜线起止都在这条右列内部，不得越到左半页。Total regions = 3。主格是第 1 格左列满高。
- 逐格人物数：第 1 格只有苏雀 + 陈默两人（远景，都不给正脸细节）；第 2 格只有老板的背影 + 苏雀的手与腰侧，**没有第三个人、没有司机的脸**；第 3 格只有苏雀（三四分面）+ 陈默（背三四分之三侧，抱保温箱）。
- 主格必须画出尺度差：铁皮墙与檐口占满画面上部三分之二，两个人在下方只占约十分之一页高。
- 场景以 `assets/locations/huo-cang.png` 的**外侧**为准：波纹铁皮墙、铁皮顶桁架、卷帘门、横拉的空白封条、铁链、水泥地、钠灯。画面里不出现任何招牌、门牌、编号。
- 老板是**未定妆角色**：只允许背影、肩、手、袖口与车钥匙；禁止正脸、侧脸、五官、清晰发型。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹 + 左眼下小痣 + 腰侧银剪与纸符链；**没有白发、没有长外套**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳 + 空白工牌 + 磨旧白球鞋；保温箱是空的、无 logo。
- **HAIR / CAST LOCK**：穿朱红短夹克的一定是全黑高马尾；穿藏青冲锋衣的一定是全黑短发、左腕红绳。两人都是黑发，红绳只属于冲锋衣那位。
- 变异鼠在本页**不出现**，连剪影也不给；只允许水泥地上那道从门缝方向延伸出去的长拖痕。
- 不画超自然现象：没有发光、没有金雾、没有法阵、没有咒语字。
- 画面内不出现任何文字：封条、信封、车、门牌、夹克纹样一律留白。
- 配色：工业区的钠黄 + 沥青黑 + 铁皮冷灰；饱和色只给苏雀的朱红与陈默的红绳。
