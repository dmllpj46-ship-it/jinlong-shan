# 第一话「最后一单」· P50

**场景**：现代 · 黑森林深处（禁区内部，非游客区）· 上午，密针叶林下的散射灰光

**页旨**：包围圈在读者眼前**被一双手搭起来**——四段钢丝、木桩、三个人位、一架在树缝上面的无人机，中间站着陈默。这一页要把「战术」讲清楚到读者能自己复述，同时把恐惧只留给一个人：陈默。他手里唯一的武器是一根木棍，而他刚刚才知道自己要**出声**。

## 绘制备注

- **分格版式（恰好 4 格）**：两条**贯通全宽**的水平格线分别落在页高 46% 与 78% 处，把页面切成上、中、下三条横带；只有**中间那条带**内部由一条斜切线分成左右两格（46% / 54%），该斜线的起止只在这条带内部，不得越到上带或下带；上带与下带内部不许再切任何格线。Total regions = 4。主格是第 1 格顶部通栏（占页高 46%）——本页主格在**上方**，与 P48/P49 的主格在下方错开。
- 逐格人物数：第 1 格——陈默**一个完整的人**，加上另外**三个只到腿或手的局部**（一双黑鞋、一只戴手套的手、苏雀的半截马尾与一只手）；第 2 格只有慕白的手与鞋；第 3 格只有苏雀一个人（陈默只到下巴与肩）；第 4 格只有陈默一个人。全页不许出现慕白的正脸、不许出现两名手下的正脸（他们是那双手套）、不许有第五个人。
- **黑森林口径（v2.2，硬约束）**：现役军事禁区。画面里能出现的只有：密针叶树的黑竖纹、锈铁丝网、水泥墩上的一块**空白**警示牌、混凝土掩体口或路缘、湿腐叶地面、倒木、晨雾/林下散射光。**不卖票、无检票口、无售票亭、无导览牌、无观光车、无气球摊、不画石阶、不画断龙台、不画任何游客设施、不画警示牌上的字。**
- **无人机口径（v2.5）**：一架深灰四旋翼，塑料壳、旧裂纹、胶带缠绕；**无品牌字样、无 logo、无屏幕、无 HUD、无录像红点、无取景框、不画第一视角画面、不发光、不投射任何光线**。本页它只悬在树缝之间，是一个远处的黑点，不是主角。禁止画成科幻飞行器或鸟。
- **陈默的元能天花板（v2.5）**：本页他**一点元能都不用**——不发光、不掐诀、不画金线。他手里只有那根木棍。他站在包围圈中间这件事只让他害怕，不让他变强。
- **慕白口径（v2.3，`assets/characters/mu-bai-v2.png`）**：矮胖、约 163 cm、谢顶四周花白、圆框眼镜、双下巴；苔灰绿对襟布扣短褂 + 米白内衫 + 布腰带 + 深灰长裤 + 肩灰毛巾 + 左手木珠 + 腰上旧黄铜钥匙串（含空白木牌）。本页他**只给手、鞋与毛巾一角**，正脸留给下一页之后的反应格。禁止一切道士视觉语言：无道袍、无须发、无发髻、无符纸（他自己身上没有）、无罗盘、无剑、无朱砂。**注意：符纸在苏雀手里，不在慕白手里。**
- **苏雀口径**：全黑高马尾、红色雀形发夹、朱红短夹克、胯侧银剪皮套、手指间是**空白符纸**与一支**黑色手电**。禁止：白发、长外套、油布断水剑、纸骨灯笼。
- **包围圈的物理口径**：四段钢丝 + 木桩/钢钎 + 撬棍 + 麻绳，全部是**手动工具**；无电子围栏、无铁笼、无网枪、无麻醉针、无枪械。钢丝在画面里必须是**连续的、能从一端读到另一端的一条线**，不许断成看不出关系的碎片。
- **HAIR / CAST LOCK**：短黑发、灰蓝工装夹克、左腕旧红绳的是陈默；全黑高马尾 + 红雀夹 + 朱红短夹克的是苏雀；穿苔灰绿对襟短褂的一定是谢顶花白戴圆框眼镜的矮胖老人。谁也不许抢谁的发色与外套。
- 光：林下**散射灰光**，无阳光直射、无光柱；人物受光从画面左上，树影给黑竖纹网点；地面腐叶最暗。全页不出现点亮的灯（苏雀的手电**没有开**）、不出现金色。
- 场景：黑森林外缘以 `comic/ch01/p46.jpg`（锈网、新铁丝、湿腐叶）成图为准；本页是林子更深处，铁丝网只留一段边缘。
- 画面内不出现任何文字：警示牌空白、符纸空白、无人机无字样。
- 配色：松墨绿黑 + 腐叶褐 + 雾灰 + 钢丝银灰 + 苔灰绿（慕白）；一点朱橘只给苏雀的夹克；陈默的灰蓝。
