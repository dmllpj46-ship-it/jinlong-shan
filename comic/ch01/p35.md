# 第一话「最后一单」· P35

**场景**：现代 · 山边别墅一层门厅 · 天刚亮（闭门培训满一个月后的第三天）

**页旨**：读者先拿到那段视频——三死一逃、模糊到不能当证据的一段——然后由苏昭的眼睛把它钉住：那不是野狗。整页一个字不解释。

| 1 | 顶部通栏 splash，上、左、右三边出血，占页高约 54%（主格） | 抖动的手机竖拍画质。黑森林：密针叶林斜插进画幅，一支手电的白光在树干上甩出拖影，一道倒了半边的锈铁丝网横在画面下角。画面正中偏下——**一个低伏而过分长的黑影**正从两棵树之间穿过，只给剪影：肩线低过臀线、背脊上一道**过亮的反光**、四肢落地的姿势不对。它前面有一个人正在跑，只给背影、腿和甩起的一只手，**不给脸、不给正身**。整格压噪点网点、边缘发糊、地平线倾斜，读起来像一段被反复转发的模糊视频。 | 音效：（沙沙的压缩噪点）<br>（画外一声很远的、不像狗的叫） |

## 绘制备注

- **分格版式（恰好 3 格）**：一条**贯通全宽**的水平格线落在页高 54% 处；线以下由一条斜切线分成左右两格（44% / 56%），该斜线的起止都只在这条下带内部，不得越到上半页；线以上是一整格不间断的通栏 splash，内部不许再出现任何竖线或斜线。Total regions = 3。主格是第 1 格顶通栏。
- 逐格人物数：第 1 格只有**一个奔跑者的背影**（无脸、无正身）+ **一个黑影**；第 2 格只有一只手 + 一部手机；第 3 格只有苏昭的下半张脸。全页只苏昭一个人（拆成手与下半脸两处），不许有第二张脸、不许镜像、手机屏幕里不许有自拍人像。
- **变异异兽口径（未定妆，规则 8）**：**不许给正脸**，不许给清晰的头、牙、眼、爪、毛色细节。它只允许是**一段过长的低伏黑影 + 背脊上一道过亮的反光 + 一个不像狗的落地姿势**，边缘被视频噪点吃掉。不画成狼、不画成犬、不画成蟒，也不画成任何已定妆生物；不与赤蟒、金龙同页；不许发光、身上不许画金线纹理——那道反光只是手电打在湿毛皮上的**过亮反光**。
- **探险者未定妆**：只允许背影、腿、甩起的手、被树枝挡住的一半身子；任何一格都不许给他们脸。死了的三个人不进画面——不给尸体、不给血、不给担架、不给搜救。
- 视频画质语言：倾斜的地平线、运动模糊、压缩噪点网点、边缘发糊、像被裁成一竖条；但**不画手机 UI、不画播放条、不画弹幕、不画点赞数、不画任何字幕**。
- **HAIR / CAST LOCK**：苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发** + 不笑；她没有剪刀、没有纸骨提灯、没有剑。本段苏雀与陈默都不在场。
- 光：第 1 格唯一的光源是那支甩动的手电；第 2、3 格是窗外的白天光 + 桌上那盏铜罩灯，**全页只有这一盏灯亮**。苏昭脸上的亮是屏幕光，不是特效，瞳心不泛金。
- 场景：门厅以 `comic/ch01/p10.jpg`、`comic/ch01/p11.jpg`、`comic/ch01/p33.jpg` 成图为准（同一张长桌、同一排没糊完的纸扎、同一面空白挂轴）。**黑森林是另一片林子，不在金龙山的画面里**：铁丝网、混凝土、退役的军用痕迹——不是石阶，不是断龙台，不是恶龙潭。
- 画面内不出现任何文字。
- 配色：林子墨黑 + 手电冷白 + 一点钠黄；过亮的反光全页只允许一处；不出现饱和金。

- 异兽口径校验（规则 8）：黑影是纯墨剪影——过长的低伏躯干、肩线低于臀线、背脊一条过亮反光、四肢落地姿势不对；**无眼、无齿、无头细节、无毛色、无发光、无金线**；不给正脸。奔跑者只给背影与甩起的手，**无脸**；死了的三个人不入画。
- 人物校验：全页只苏昭一人（第 2 格她的手、第 3 格她的脸，同一个人）；第 1 格没有她；无镜像、屏幕里没有人像。
- 光校验：第 1 格唯一光源是甩动的手电；第 2、3 格全页只桌角那一盏铜罩灯亮；手机屏是一片不可读白亮，无 UI。
- 偏差①：第 3 格给到了整张脸（脚本要求只切下半张脸）。她的眼睛正落在屏幕上，「看了三遍」反而更立，接受。
- 偏差②：第 2 格她的手指按在屏幕面上、手机平放桌上（脚本是指腹压在侧边），同一件事，接受。
- 偏差③：林子的手电光束画成两道明确的白光楔形，比脚本里的「甩动拖影」干净；噪点网点与倾斜地平线都在，视频感成立，接受。
