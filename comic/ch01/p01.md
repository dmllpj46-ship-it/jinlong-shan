# 第一话「最后一单」· P01

**场景**：现代 · 金龙山景区广场 · 昭记铺前 · 日头偏西

**页旨**：金龙山早就成了景区，只有她还守在广场边那间看风水的铺子里。一页立起「五百年，她把山门口守成了一门生意」。

## 绘制备注

- **分格版式（恰好 4 格 = 三行「通栏 / 双格 / 通栏」，整页铺满，多一格都不许有）**：主格是第 3 格（她的脸与手相）；第 1 格通栏负责「游人如鲫」的密度，人群要密、要小、要横向铺开。
- 现代场景：墨线 + 网点 + 赛璐璐，不画照片感、不画 3D。游客衣着当代、色彩灰冷，人群脸孔一律模糊处理，不给可辨认的正脸配角。
- 苏昭按 `assets/characters/su-zhao.png`：右鬓白发、低髻素木簪、炭灰长外套、月白内搭、清冷不笑；断水收在铺内，不入画。
- 门口那盏是纸骨引魂灯，灯柄系褪色朱砂绳；本页它是唯一的光源暖色。饱和金只给灯焰与红绳。
- 画面内不生成任何文字：招牌、导览牌、黄历、手机屏全部留白或抽象笔画。
- 金龙山按场景锚点：千阶一侧无栏杆、雾、锈铁门与褪色导览牌是现代加上去的。
