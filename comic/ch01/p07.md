# 第一话「最后一单」· P07

**场景**：现代 · 山门镇边缘的自建房 · 老妇家 · 夜将尽

## 绘制备注

- **分格版式（恰好 5 格 = 四行「通栏 / 双格 / 窄通栏 / 通栏」，整页铺满，多一格都不许有）**：主格是第 5 格的双人 + 推钱 splash；第 2、3 格是同一个动作的两拍，必须左右并列、由斜切格线分开。
- 施法不画光柱、不画法阵、不画咒语字；只有两指、一缕丝、一只瓶。暴力尺度上限到「弓背、蜷脚趾」为止，不画血、不画呕吐、不画抽搐特写。
- 瓶中之蛇只给**一个极小的头 + 一圈**，不得读成两条。
- 苏昭按 `assets/characters/su-zhao.png`；女生与老妇按各自定妆稿；女生在第 4、5 格恢复整齐（马尾重新拢好、拉链拉正）。
- 零钱、瓶身、围裙、墙上纸条一律留白不可读，不出现真实人民币图案。
- 配色：室内冷青灰白；饱和金只给那缕丝、瓶内、灯焰三处。
