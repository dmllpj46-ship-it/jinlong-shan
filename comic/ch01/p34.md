# 第一话「最后一单」· P34

**场景**：现代 · 山下城 · 24 小时便利店与她店外的街 · 同夜（本段落收束页）

**页旨**：苏雀收束这一段。她什么都能感觉到一点——老古董起得太早、那只不该有的瓶、新徒弟教得太狠——她就是不肯往下想。她也是横跨了五百年的人，可她**拒绝长大**：想明白了，就得变成苏昭那种人。这一页是她把话头掐死的瞬间。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 42% 处；线**以上**由一条斜切线分成左右两格（46% / 54%），该斜线起止都只在这条上带内部，不得越到下半页；线**以下**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线。Total regions = 3。主格是第 3 格底通栏。
- 逐格人物数：第 1 格只有苏雀 1 人（顾客**只出画外音，不入画、不给手、不给影**）；第 2 格只有她的一只手 + **半张脸**（同一个人，不许多出一张完整的脸）；第 3 格只有苏雀 1 人。全页不出现第二个人、不许有镜像、玻璃门里**不许反射出她**、街上**没有人**。
- **HAIR / CAST LOCK**：苏雀 = 朱红**短夹克** + 黑色高领内搭 + **全黑高马尾** + 红雀发夹 + 左眼下小痣 + 腰侧纸符链 + 鞘里的银剪；**没有白发、没有低髻、没有长外套、没有纸骨提灯、没有剑**。她的照明是一支**黑色手电**，本页是店里冷白灯管，手电不出现。
- **苏昭与陈默整页不在场**：不以剪影、不以回忆、不以照片出现。第 2 格那两句心声是他们唯一的在场方式。
- 折纸痕：只允许在**右腕内侧**一道，极淡，不画成伤口、不画成纸片翘边、不把整条手臂画成纸偶。
- 山脊口径：与 P23 区分——P23 从货仓屋脊看过去时山腰有苏昭那盏针尖大的灯；本页从山下城里看的是**另一侧的城市山面**，所以**山脊上不给任何光点**，也不画金线、不画龙形。
- 现代场景禁令：商品、价签、烟盒、纸袋、手机屏幕、店招**一律留白**，无字、无数字、无 logo；不画照片感、不画 3D。
- 画面内不出现任何文字。
- 配色：便利店冷白 + 沥青墨黑 + 湿反光；饱和色只给苏雀那一身朱红与她的红鞋带，纸雀的纸黄作次要点。
