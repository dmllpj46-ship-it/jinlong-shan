# 第一话「最后一单」· P27

**场景**：现代 · 山边别墅一层门厅（长桌桌头与门框）· 凌晨（接 P26）

**页旨**：陈默问出了全场最外行的那个问题——存着干嘛。苏昭给了他这一行最老实的答案：元能是最原始的东西，人叫它「气」；懂得运用就千变万化，不懂得运用，就把一只老鼠变成刚才那种东西。**这一页是全段的说理页，但道理必须由「拿着瓶子的人」说出来，不许画成讲解板。**

## 绘制备注

- **分格版式（恰好 3 格）**：一条竖格线贯通整页高度、落在页宽 54% 处；线**左侧**是一整格不间断的满高纵格，内部不许再出现任何横线或斜线；线**右侧**由一条斜切线分成上下两格（各约 46% / 54% 页高），该斜线起止都只在右列内部，不得越到左半页。Total regions = 3。主格是第 2 格左列满高。
- 逐格人物数：第 1 格只有陈默 1 人；第 2 格只有苏昭 1 人（**没有第二双手、没有她自己的镜像、窗外没有人影**）；第 3 格只有苏雀 1 人。全页 3 人，各占一格，不许串格。
- **瓶子数量**：全页只有**两只**瓶——苏昭举着的那只里有金圈，苏雀转着的那只里也有金圈（各自的一半）；陈默手边的那只是 P22/P23 用过的、现在**空着**。三处瓶身必须能一眼分清，不许多出第四只、不许同一只瓶在两个格里都出现完整内容。
- 元能画法：瓶里只有**一小圈**金线，圈上只允许一个极小的头；本页**不发光晕、不外溢**，苏昭脸上的光是灯与玻璃的反光，不是特效。她的瞳心不许画成运功状态。
- 室内以 `comic/ch01/p10.jpg`、`comic/ch01/p11.jpg` 成图为准：老木长桌、长凳、桌角纸扎竹骨、空白挂轴、油布裹的断水、门框与黑窗外山影。全页只桌上那盏铜罩灯亮着，窗外不给灯。
- **HAIR / CAST LOCK**：
  - 苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发** + 不笑；只有她可以站在那盏灯前。
  - 苏雀 = 朱红**短夹克** + **全黑高马尾** + 红雀发夹 + 左眼下小痣；**没有白发、没有长外套、没有提灯**。
  - 陈默 = 藏青冲锋衣 + 灰连帽 + 全黑散发 + 左腕红绳 + 空白工牌。
  - **穿长外套的一定有白发；穿红夹克的一定是全黑高马尾；坐长凳的一定是穿冲锋衣的那位。**
- 画面内不出现任何文字：挂轴、瓶身、夹克纹样、门框春联位一律留白。
- 配色：室内旧金灯 + 墨黑阴影；饱和色只给瓶里那一圈金、苏雀的朱红、陈默的红绳。
