# 第一话「最后一单」· P12

**场景**：现代 · 山边别墅 · 门前碎石路与一层门厅 · 陈默住进来的第二天清晨

**页旨**：苏雀来了。苏昭连头都没抬——她师妹每个月总要来几趟，取灯油，骂她两句。第一次见到这个红夹克姑娘的陈默，以为自己走错了片场。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 38% 处；线**以上**由一条斜切线分成左右两格（44% / 56%），该斜线起止都在这条横带内部，不得越到下半页；线**以下**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线。主格是第 3 格底通栏。
- 苏雀按 `assets/characters/su-que.png`：全黑高马尾 + 红雀发夹 + 旧铜铃发圈、左眼下小痣、笑露虎牙、朱红短夹克（褪色抽象符纹）、黑高领、黑工装裤、白球鞋红鞋带、腰侧银剪与纸符链；**没有白发、没有长外套**。
- 苏昭按 `assets/characters/su-zhao.png`：深墨长外套 + 低髻 + 右鬓一缕白发；**绝不穿红夹克、绝不扎高马尾**。
- 苏昭「不意外」必须画在动作里：第 2 格她低头不抬眼，但油壶已经推好；第 3 格她仍不抬头，只多摆了一只杯子。
- 三人同框只允许出现在第 3 格；第 1、2 格各只有一个人，且不重复出现同一个人。
- 不画超自然现象；纸雀是死的折纸，不许自己动、不许发光。
- 纸扎只画竹骨架 + 白纸团，不许骷髅、肋骨、人脸；桌面不许出现钞票捆。
- 画面内不出现任何文字：纸袋、纸符、夹克纹样、电动车车身、门牌一律留白。
- 配色：清晨冷白 + 苏雀那一身朱红是本页唯一的饱和色；饱和金只给桌上那盏灯。
