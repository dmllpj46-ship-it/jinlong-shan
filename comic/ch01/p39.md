# 第一话「最后一单」· P39

**场景**：现代 · 山边别墅一层门厅 · 同夜（苏雀进门之后半小时）

**页旨**：任务只有一句话和一个地名，其余全是空白。她给的口径越短，读者越清楚这不是一个普通单子。注意——**这一页苏昭不说「黑森林」三个字**，她只说地名；那段视频是谁的、林子在哪里，全部留给 P40。

## 绘制备注

- **分格版式（恰好 3 格）**：整页只有两条**贯通全宽**的水平格线，分别落在页高 20% 与 70% 处；第一条线（20% 处）在带内斜切，第二条线（70% 处）是直线。全页**没有任何竖格线**，任何一条斜线都不得越出它所在的带。Total regions = 3。主格是第 2 格中带。
- 逐格人物数：第 1 格只有苏昭的一只手；第 2 格只有 3 人（苏昭 + 苏雀 + 陈默，各一次）；第 3 格只有苏雀的一只手与手腕。**不许出现第四个人、第四只手、同一个人的两张脸、任何镜像**；第 2 格里每个人只有一个头。
- **HAIR / CAST LOCK**（三人同页，逐人写死）：苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发** + 不笑，站着靠窗；苏雀 = 朱红**短夹克** + 黑色高领 + **全黑高马尾** + 红雀发夹 + 左眼下小痣 + 腰侧纸符链 + 鞘里银剪，坐在长凳上；陈默 = 藏青冲锋衣 + 灰连帽 + **短黑发** + 左腕红绳 + 空白工牌，站着端碗。硬约束：**穿长外套、有白发的只有苏昭；穿朱红短夹克、扎高马尾的只有苏雀；有红绳、端碗的只有陈默**。
- **台词纪律**：苏昭在本页只给地名、给「你们俩去」、给「见一个人」、给钱和纸条。**不许她说出黑森林里是什么、不许说元能、不许说视频、不许说她怎么知道、不许解释她为什么不去**（呼应 P14「我不去」，那一页她同样一个字没解释）。
- 现金口径：皮筋捆着的一沓**无字纸钞**，无头像、无数字、无面额、无国徽、无真实人民币纹样。
- 空白纸条：无字、无纹、无地图、无地址。
- 折纸痕：只允许苏雀**右腕内侧**一道，极淡，不画成伤口、不画成纸片翘边、不许把整条手臂画成纸偶。
- 灯：夜里门厅，**全页只桌上那盏铜罩灯亮着**，门外院墙上不许多出第二盏；碗面的热气是白的，不许发光；瞳心不泛金。
- 场景以 `comic/ch01/p10.jpg`、`comic/ch01/p11.jpg`、`comic/ch01/p33.jpg` 成图为准（同一张长桌、同一排纸扎、同一面空白挂轴）。
- 画面内不出现任何文字。
- 配色：夜墨 + 单侧旧金灯 + 苏雀那一身朱红作唯一饱和色。
