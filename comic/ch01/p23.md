# 第一话「最后一单」· P23

**场景**：现代 · 城西货仓门口 · 起封条之后 · 后半夜（本段落收束页）

**页旨**：苏雀把「元能」这件事讲给陈默听——这是全篇第一次由角色之口把世界观说出来。她说得很随便，像讲行业常识；陈默听到的却是「这世上有这种东西」。最后一页的落点：她把瓶子塞回他手里，说了和苏昭一模一样的那句话。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 48% 处（**斜的**，从左 46% 斜到右 50%）；线**以上**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线；线**以下**由一条斜切线分成左右两格（52% / 48%），该斜线起止都在这条下带内部。Total regions = 3。主格是第 1 格顶通栏。
- 逐格人物数：第 1 格只有苏雀（坐，全身）+ 陈默（坐地，全身），都不给正脸特写；第 2 格只有苏雀（胸像），**陈默不在本格，连手都不给**；第 3 格只有陈默（半身）+ 苏雀的一只手与半截袖口。
- 场景以 `assets/locations/huo-cang.png` 的**外侧**为准：波纹铁皮墙、铁皮顶檐口、拉下的卷帘门与那条空白封条、水泥地、木托盘、手推液压车停在边上。钠灯是唯一光源。
- 远景的山脊只给黑色轮廓，**不许画成龙形**；山腰那粒灯是全场唯一一点暖金，也是「苏昭还在山上」的记号。
- 变异鼠在本页**不出现**：尸体已经不在画面里，只允许台词提到「刚才那种」。
- 玻璃瓶 = P07 / P16 / P22 那只，标签已撕、瓶身空白，瓶里那一圈元能**只允许一个极小的头**，圈身不超过瓶底三分之一；不许照亮整张脸。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹 + 左眼下小痣 + 虎牙；**没有白发、没有长外套**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳 + 空白工牌 + 磨旧白球鞋。
- **HAIR / CAST LOCK**：坐纸箱凳、举瓶子的一定是朱红短夹克 + 全黑高马尾；靠卷帘门坐地的一定是藏青冲锋衣 + 全黑短发 + 左腕红绳。
- 配色：钠黄 + 沥青黑 + 铁皮冷灰；饱和金只给瓶里那一圈、山腰那粒灯、陈默腕上的红绳。
- 画面内不出现任何文字：封条、瓶身、纸箱、工牌、夹克纹样一律留白。
