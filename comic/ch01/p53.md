# 第一话「最后一单」· P53

**场景**：现代 · 黑森林深处 · 包围圈第二段（二号桩）· 上午

**页旨**：收口。狼进圈、被钢丝缠住、被围攻、死掉。杀它的人不是陈默，甚至不是慕白——**是苏雀一剪**，因为她才是干这个的。陈默在这一页的位置是跪着、手还抬着、金线将断：他在场，但他不是终结者。这一页要给的是**包围圈合上**这件事本身，不是任何一个人的英雄镜头。

## 绘制备注

- **分格版式（恰好 3 格）**：两条**贯通全宽**的水平格线分别落在页高 18% 与 74% 处，把页面切成上、中、下三条横带，三带内部**一律不再切任何格线**（无斜切、无竖线）；主格内部的动势全部靠人物与钢丝的走向完成。Total regions = 3。主格是第 2 格中通栏（占页高 56%，是本段八页里最大的单格）。
- 逐格人物/生物数：第 1 格只有狼的**腿与一段躯干** + 戴手套的两只手，无脸；第 2 格**恰好一只狼 + 苏雀 + 两名手下 + 陈默**，共五个人形、一只兽，各出现一次，不许第六个人、不许慕白入画、不许苏雀出现两个动作分身（剪切动作只做一次）；第 3 格只有躺着的狼 + 苏雀的一只鞋 + 陈默的膝盖与手。两名手下在整段里仍然**一律不给正脸**。
- **击杀构图禁令（v2.5，硬约束）**：**不许复用 P21（城西货仓杀变异鼠）的构图**——那一页是「银剪从下往上贯穿下颌」的近景竖构图。本页主体是**包围圈合上**：横向宽构图、狼被两段钢丝缠住翻身、四个人的力从画面两侧向中央拉、剪切只是中央偏左的一个动作点。两页并排看必须明显不同。
- **变异野狼口径（v2.5，`assets/creatures/bian-yi-lang.png` 为唯一依据，参考图第一位）**：斜背（肩线低于臀线）、躯干过长、四肢偏短、粗尾打结下垂、毛结块挂湿针叶、皮下暗金筋纹哑光不发光、浅草黄普通圆瞳孔。一页一只、一个连续躯干、一个头。禁止：翼、角、鳞、多头、蛇形、龙形、喷光、发光的眼齿爪。
- **暴力口径（少年向）**：全页只有**一个破口**（下颌，苏雀的银剪）与**一小摊暗色血**（不超过一只鞋的面积）。禁止：断肢、开膛、暴露的骨与内脏、喷血、血泊、头颅分离、皮肉剥落。死亡用「静止 + 瞳孔散了 + 不再起伏」表达，不用伤害细节表达。
- **陈默的定位**：跪着、手抬着、金线正在断成几粒——他**不给出致命一击**，也不站起来救人。他手里仍是那根木棍。不许给他任何龙纹、龙形、金色铠甲、眼睛发光、气场爆发。
- **苏雀口径**：全黑高马尾、红色雀形发夹、朱红短夹克、胯侧银剪皮套（剪切时剪在手里，皮套空着）；她的照明是一支**黑色手电**（可在腰侧，不开）。禁止：白发、长外套、油布断水剑、纸骨灯笼。**不许把她画成腾空两次的两个人。**
- **无人机口径**：可以在主格上方树缝里作为一个远处的深灰小黑点存在，仍然无标识、无屏幕、不发光、不拍第一视角。
- **HAIR / CAST LOCK**：朱红短夹克 + 全黑高马尾的是苏雀；灰蓝工装夹克 + 短黑发跪着的是陈默；深色软底工装 + 帽檐 + 口罩 + 手套的两个人是手下，**一定蒙面、一定无正脸**；穿苔灰绿对襟短褂的矮胖老人是慕白，本页他**只允许出现在画外音里**。谁也不许抢谁的外套与发色。
- 光：林下散射灰光为底；主格中央（狼与苏雀）最亮，四角压暗成包围感；金色只剩陈默掌心那几粒将灭的余亮。全页无点亮的灯、无光柱、除那几粒以外无发光体。
- 场景：黑森林深处以 `comic/ch01/p50.jpg`–`comic/ch01/p52.jpg` 成图为准；木桩、钢丝、腐叶沟与树距必须与 P50 布阵时一致（读者要能认出这是同一个圈）。
- 画面内不出现任何文字、无字幕条。
- 配色：松墨绿黑 + 腐叶褐 + 狼毛脏灰褐 + 钢丝银灰 + 苏雀的一点朱橘 + 极小面积的暗红（血）；主格中央提亮、四周压到最黑。
