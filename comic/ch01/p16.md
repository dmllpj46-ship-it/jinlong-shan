# 第一话「最后一单」· P16

**场景**：现代 · 山边别墅门口与门前山路 · 同一清晨（接 P15，本段落收束页）

**页旨**：陈默什么都不知道——不知道货仓在哪、不知道那只老鼠是什么、不知道自己刚被两个女人当成一枚棋子商量完了。但他上了车。打工人不需要理由，需要的是「已经有人把路线排好了」。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 40% 处；线**以上**由一条斜切线分成左右两格（46% / 54%），该斜线起止都在这条上带内部，不得越到下半页；线**以下**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线。Total regions = 3。主格是第 3 格底通栏。
- 逐格人物数：第 1 格只有苏雀 + 陈默（他只露半张脸与肩胸，不给全身）；第 2 格只有苏昭 + 陈默的同一侧肩与口袋（不给他的脸）；第 3 格只有两个人各骑一辆车，俯视，都不给正脸。不许出现第三个人、镜像、分身。
- 主格必须画出尺度差：山脊占画面上方约一半，两辆电动车在下方小得像两只虫子——这是「人被山牵着走」的一格。
- 第 3 格保留山形轮廓（以 `assets/locations/bie-shu.png` 为准：两层石屋 + 锈铁门 + 碎石车道 + 一盏暖灯；屋后山脊压下来），但**不把山画成龙形**，全页只允许别墅那一盏灯亮着。
- 苏昭按 `assets/characters/su-zhao.png`：深墨长外套 + 低髻 + 右鬓一缕白发；**绝不穿红夹克、绝不扎高马尾**。
- 苏雀按 `assets/characters/su-que.png`：朱红短夹克 + 全黑高马尾 + 红雀发夹 + 腰侧银剪与纸符链；**没有白发、没有长外套**。
- 陈默按 `assets/characters/chen-mo.png`：藏青冲锋衣 + 灰连帽衫 + 左腕旧红绳 + 空白工牌 + 磨旧白球鞋；保温箱是空的、无 logo。
- 道具连续性：第 2 格的玻璃瓶 = P07 那只撕了标签的小瓶，看上去是**空的**（瓶里那圈元能不可见）；第 1 格的纸条折两折、空白无字。
- 不画超自然现象；不许画鼠、不许画蟒、不许画发光。
- 画面内不出现任何文字：院门门牌、纸条、夹克纹样、车身、保温箱一律留白。
- 配色：清晨冷白 + 山影墨黑；饱和色只给苏雀的朱红、陈默的红绳、窗里那一点旧金灯。
