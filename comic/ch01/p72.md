# 第一话「最后一单」· P72 / 072

**场景**：现代 · 昭记铺内 · 午后，接 P71

**页旨**：苏昭第一次给正脸，而她做的唯一一件事是**看**。她一眼读出老妇活不过两个月——**这句只走心声，只给读者**，不许她说出口、不许她对李锦鸿说。她判断的方式仍然是老规矩：**数次数**——「药石无灵」四个字李锦鸿说了三遍，她数的是这个，不是病情（承 P62「她只问次数」）。陈默在本页注意到流程不对：**她没问生辰**。看风水的人不问生辰，因为她不需要。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 20% 与 66%；上带与中带内部不许再切；只有底带（66–100%）内部由一条近竖、略斜的格线切成左 46% / 右 54%，斜线起止只在本带内部。Total regions = 4。主格是第 2 格中部通栏 splash（46%）。
- 逐格人物数：第 1 格**恰好两个人**——李锦鸿（下半张脸 + 手）、李母（只到肩与帽）；第 2 格**恰好一个人**——苏昭正脸一次；第 3 格**只有两只手与一只袋**，零脸；第 4 格**恰好一个人**——陈默（侧后身 + 半张脸），苏昭只到画框边缘一角衣料、**不给第二张脸**。
- **看病的画法（硬口径）**：苏昭这一眼**没有任何法术特效**——无瞳心金圈、无金雾、无视线光、无叠印、无回忆格。判断全走心声。**禁止**她把「两个月」说出口，**禁止**任何角色在本页说出「癌」「末期」「死」字（李锦鸿只说「药石无灵」）。
- **次数口径**：「药石无灵，他说了三遍」是苏昭心声，**数字只许出现在这一句心声里**；李锦鸿的台词里不许带数字。
- **HAIR / CAST LOCK**：右鬓一缕白 + 低髻 + 素木簪 + 炭灰高领长外套的是**苏昭**；鬓角灰 + 炭灰大衣的是**李锦鸿**（本页只到下半张脸）；针织帽 + 驼色围巾 + 红布袋的是**李母**（本页只到肩与手）；短黑发 + 灰蓝夹克 + 左腕红绳的是**陈默**。**白发只属于苏昭**，不许漏到任何人头上。
- **道具白名单**：空白医院纸袋与空白纸、红布抽绳袋、凉茶杯、罗盘、竹骨。**禁止**可读病历、化验单数字、手机屏幕文案、品牌 logo；纸袋与纸**一律全白**。
- 参考图链计划：① `assets/characters/su-zhao.png`（本页她占主格正脸，第一位）② `assets/characters/chen-mo.png` ③ `comic/ch01/p71.jpg`（锁铺内光与李锦鸿 / 李母的本段造型）。
- 配色：午后暖灰 + 炭灰 + 月白 + 靛蓝 + 驼色；主格半明半暗，暗部用网点不用厚涂。
- 画面内不出现任何文字。
