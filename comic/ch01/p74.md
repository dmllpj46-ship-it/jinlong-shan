# 第一话「最后一单」· P74 / 074

**场景**：现代 · 昭记铺内 · 午后，接 P73

**页旨**：她答应。全页的重量压在两个字上——「我接。」苏昭接了一单**治不了的活**，而且接得太平静；陈默在旁边第一次看见这件事，他的两句心声是读者唯一的解释入口：「她接了一单治不了的。」「她没说不治。」她给的内容仍然是老规矩：**结论先给、条件后给、理由不给**——「后天上午。我去。」「你跟着。搬东西。别说话。」李锦鸿的忠孝在本页到顶：他深深弯下腰去（**不跪**），母亲坐在凳上伸手拍他的手背（**她哄他**）。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 20% 与 66%；上带与中带内部不许再切；只有底带内部由一条近竖、略斜的格线切成左 46% / 右 54%，斜线起止只在本带内部。Total regions = 4。主格是第 2 格中部通栏 splash（46%）。
- 逐格人物数：第 1 格**恰好两个人**——李锦鸿（弯腰、只到后脑）、李母（只到一只手与围巾），苏昭只到衣角；第 2 格**恰好一个人**——苏昭正脸一次；第 3 格**恰好一个人**——陈默；第 4 格**只有两只手**（苏昭推纸条的手、陈默接的手），零脸。
- **「我接」的口径**：她**不许说**「治不了」「能治」「放心」「会好」；两个字就是全部。**禁止**怜悯的笑、点头、叹气、拍肩。李锦鸿**不许跪、不许哭**；弯腰的幅度到最深的一次鞠躬为止，脸不入画。
- **纸条口径（正典沿用）**：裁白的空白纸条**全页只有一张**，无字无纹无地址；它压在那一张钞上。派活文书的老规矩不变，只是这一次目的地在山脚三十里内。
- **陈默没看懂**：他的两句心声是**观察**不是结论；**禁止**他想明白苏昭为什么接（她五百年的账不许在本段被任何人拼出）。
- **HAIR / CAST LOCK**：右鬓白 + 低髻 + 素木簪 + 炭灰高领长外套的是**苏昭**；短黑发 + 灰蓝夹克 + 左腕红绳 + 指尖浆糊的是**陈默**；灰鬓角 + 炭灰大衣的是**李锦鸿**（只到后脑）；针织帽 + 驼色围巾的是**李母**（只到一只手）。
- 参考图链计划：① `assets/characters/su-zhao.png`（主格正脸，第一位）② `assets/characters/chen-mo.png` ③ `comic/ch01/p73.jpg`（李锦鸿与李母靠上一页成图锁）。
- 配色：午后暖灰 + 炭灰 + 月白；主格的光从门侧来，半脸在网点暗部；无金。
- 画面内不出现任何文字。
