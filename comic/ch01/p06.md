# 第一话「最后一单」· P06

**场景**：现代 · 山门镇边缘的自建房 · 老妇家 · 夜

## 绘制备注

- **分格版式（恰好 3 格 = 顶部通栏 + 下排「小格 / 满高主 splash」，整页铺满，多一格都不许有）**：主 splash 是第 3 格；第 2 格只给一张闭眼侧脸，是呼吸位。
- **赤蟒形体禁令（AGENTS.md 规则 13）**：第 3 格全页只允许**一个蛇头 + 一截连续颈**，无翼、无角、无四肢、不盘身、不出现第二条或第二个头；虚影是半透明金雾，不是实体。
- 元能的视觉语言沿用蟒祟：金屑、过亮的金色、耳鸣感的细线；不画虫、不画黑气、不画邪教符号。
- 苏昭按 `assets/characters/su-zhao.png`；女生按 `assets/characters/nv-hai.png`（散乱妆发状态）；老妇按 `assets/characters/lao-fu.png`。
- 第 3 格里女孩与蟒影不同框于「现实层」——蟒影只从女孩身后浮起，边缘化开；不要画成女孩骑在蛇上。
- 墙上纸条、玻璃、瓶身全部留白不可读。
