# 第一话「最后一单」· P31

**场景**：现代 · 山边别墅院子与门厅 · 一个月的闭门培训（蒙太奇页）

**页旨**：一个月。不写他变强，写他**挨打**——金线是他自己捻出来的，可手上的茧、腿上的抖、那碗凉透的面，是这三十天长的。苏昭教得极狠，也极沉默：她从不解释为什么这么赶。

## 分镜

| 格 | 尺寸与位置 | 画面 | 台词 / 音效 |

| 1 | 顶部**通栏主格**，占页高约 48%，带线斜切，左、右、上三边出血 | 清晨的院子。屋后山脊压在三倍于房子的高度上，天只亮了一条边。陈默在院子中央扎马步，两条胳膊平举，每只手腕上各搭一只盛了半口水的小粗瓷碗，水面晃出一圈一圈同心圆；他的腿在抖，冲锋衣后背湿了一大片。廊下阴影里苏昭坐着，膝盖上横着油布裹的断水，只给侧脸轮廓与那缕白发；她脚边放着一只空簸箕。碎石车道、爬藤、铁皮屋檐都在。 | 苏昭：「水洒了，重来。」<br>陈默（心声）：「第一天。」 |

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 48% 处，这条线在带内**斜切**；线**以上**是一整格不间断的通栏主格，内部不许再出现任何竖线或斜线；线**以下**由一条竖格线分成左右两格（46% / 54%），该竖线起止都只在下半页内部，不得越到上半页。Total regions = 3。主格是第 1 格顶通栏。
- 逐格人物数：第 1 格只有苏昭 + 陈默 2 人（苏昭在廊下阴影里只给侧脸轮廓）；第 2 格只有**陈默的一只手与半条手臂**，**不给脸、不给第二双手**；第 3 格只有陈默 1 人（苏昭只出画外音，**不许在格子里出现她的身影或影子**）。全页不出现第三人，苏雀不在场。
- **时间跨度只用画面元素说，不许用文字说**：第 1 格＝天只亮一条边（第一天清晨）；第 2 格＝夜里一盏灯 + 指节缠布（第十七夜）；第 3 格＝正午白光 + 断成两截的木棍 + 廊下凉透的一碗面（一个月之后）。三格的光向、色温、地面干湿必须明显不同。
- **HAIR / CAST LOCK**：
  - 陈默 = 藏青冲锋衣 + 灰连帽 + **全黑散发** + 左腕红绳 + 空白工牌；年轻男人，**不许低髻、发簪、白发、长外套**；本页他的变化只允许体现在**姿态、汗、缠布的指节**，不许换装、不许长留海、不许加疤。
  - 苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发**；只在第 1 格出现，坐着，**手里没有瓶、没有剪刀、没有提灯**，断水裹着油布横在膝上，**不许拔出来**。
  - **穿长外套的一定有白发；穿冲锋衣的一定是全黑散发。**
- **器械口径**：全页只允许**旧木棍**——无护手、无剑格、无绑绳，断口是毛的；不许画成一把真正的剑。第 3 格地上那两截 + 手里那一根 = 同一类木棍，不许多出第四根、不许出现金属兵器。
- 元能画法：第 2 格只有**一缕丝绕出一圈就断**，不许有光柱、光晕、漩涡、雾；金是画面唯一的过亮色，且**只允许出现在那一缕丝上**。
- 碗与面：粗瓷碗、无字、无花纹；面是一碗清汤白面，不许画成料理照。
- 画面内不出现任何文字：符纸、手机、碗底、院墙、夹克纹样一律留白。
- 配色：清晨冷青 / 夜里的旧金灯 / 正午的白；饱和色只给陈默的红绳、那一缕金、苏雀留在 P30 的那只纸袋的纸黄（远处虚焦）。

- roll 记录：首roll三项校验全部通过，未重roll。陈默三格皆全黑散发（顶格站桩、底左格只有手、底右格擦汗），无白发、无低髻；苏昭只在顶格出现，长外套 + 低髻 + 右鬓白发，油布裹的断水平放在膝上未拔；底右格廊下空着，她的身影与影子都没有进格。
- 时间口径校验：三格光向明显不同——顶格天只亮一条边（清晨冷青）、底左格一盏铜罩灯 + 指节缠布（夜）、底右格平白硬光 + 断口的木棍 + 一碗凝了膜的面（正午）。三十天全靠画面说，页面没有一处文字。
- 元能校验：底左格只有一缕极细金线绕出一圈就断，断头软软落下；无光柱、无光晕、无漩涡、无雾，全页的金色只在那一缕丝上。
- 偏差①：顶格两只粗瓷碗是端在他摊开的手掌里，不是搭在手腕上；腿在抖、后背汗湿、水面同心圆都在，读起来更难，接受。
- 偏差②：顶格苏昭给到的不只是侧脸轮廓，侧脸带一点眼与眉，仍未给正脸、未给表情。
- 偏差③：底左格指节布上的血点渲染成一小片红，脚本要「一小点深色、不给特写」；面积偏大但没有特写构图，接受。
- 偏差④：底右格那碗面落在地上（他脚边）而不是廊下，竹筷也在碗边；「廊下那个位置空着」仍然成立，只是凉面归了地面。同时地上的断棍多出一小截（三截而非两截），未出现第四根、未出现金属兵器。
- 偏差⑤：48% 处那条横线出来是直的，带内斜切没有兑现；格数、主格、出血三项都在，接受。
