# 第一话「最后一单」· P54

**场景**：现代 · 黑森林边缘 → 龙潭镇北土路 · 傍晚（同一天收束）

**页旨**：两件「收工」的事并排做完——苏雀**收元能**（和 P22 货仓那一页完全同一个动作，读者要认出来），镇上的人**收家伙**（盘钢丝、盖帆布）。然后一行人低调回镇：不报警、不拍照、不解释，车灯都不开。最后一页留给读者一个判断：慕白从头到尾没说出那两个字，是因为他知道说了也没用——而陈默第一次**看见**了元能可以被拿走。

## 绘制备注

- **分格版式（恰好 4 格）**：两条**贯通全宽**的水平格线分别落在页高 24% 与 58% 处，把页面切成上、中、下三条横带；只有**中间那条带**内部由一条斜切线分成左右两格（46% / 54%），该斜线的起止只在这条带内部，不得越到上带或下带；上带与下带内部不许再切任何格线。Total regions = 4。主格是第 4 格底部通栏（占页高 42%）——主格回到下方，与 P50/P51/P53 错开。
- 逐格人物数：第 1 格只有苏雀一个人（蹲着，狼只给后半段躯干与尾巴，无人另入画；手下只到一只手套）；第 2 格只有陈默的一只手与半张低头的脸；第 3 格只有两双手（手下）+ 慕白的半边脸与一只镜腿 + 苏雀不入画；第 4 格**恰好四个人**的背影，各一次，不许第五个人、不许镇上有正脸的围观者（路人只许剪影或不出现）。
- **收元能口径（与 P22 呼应，硬约束）**：动作必须是「木柄勺 + 两指抽出一根细金线 + 收进一只**撕掉标签的透明玻璃瓶**」，与 `comic/ch01/p22.jpg` 同一套道具与手法；瓶子立在狼身旁的地上，不发光、不冒烟、不倒。金线是**细的、安静的**，不许画成光束、电弧、能量柱。
- **变异野狼口径（v2.5，`assets/creatures/bian-yi-lang.png`）**：本页它是**尸体**，只给躯干后半 + 打结下垂的粗尾 + 一部分肩背；暗金筋纹已经**褪成灰**、不再有任何亮度；下颌只有 P53 那一个已存在的小破口。禁止：复活、抽动、睁眼、第二只、发光、龙形、蛇形。
- **低调回镇口径（v2.5，本页的收束语气）**：无警车、无救护车、无任何制服、无对讲机、无警戒线、无记者、无手机拍摄、无车灯、无喇叭；镇子只以「没有字的石牌坊剪影 + 留白招牌 + 半拉卷帘门」出现。**不许任何人问他们身上沾了什么**，也不许任何台词解释元能。
- **无人机口径**：被帆布盖住、或作为被盖的东西一角存在；无标识、无 logo、无屏幕、无录像点、不飞行、不发光。
- **慕白口径（v2.3，`assets/characters/mu-bai-v2.png`）**：矮胖约 163 cm、谢顶四周花白、圆框眼镜、双下巴；苔灰绿对襟布扣短褂 + 米白内衫 + 布腰带 + 深灰长裤 + 肩灰毛巾 + 左手木珠 + 腰上旧黄铜钥匙串（含空白木牌）。第 3 格只给一侧镜腿与半边脸颊，轮廓必须还是矮、圆、垂腮。禁止一切道士视觉语言。他的「数人」是他本页唯一一次展示镇上的规矩：**他记的是吃饭的人数，不是伤亡。**
- **HAIR / CAST LOCK**：全黑高马尾 + 红雀夹 + 朱红短夹克 + 银剪皮套的是苏雀（无白发、无长外套、无剑、无提灯）；短黑发 + 灰蓝工装夹克 + 左腕旧红绳的是陈默（无疤、无长发、无道袍）；穿苔灰绿对襟短褂的一定是谢顶花白戴圆框眼镜的矮胖老人；两名手下**一律无正脸**（帽檐、口罩、手套、背影）。
- 光：第 1–3 格是林下最后的散射灰光；第 4 格是黄昏——天边一层灰橘，人物全部压成深色剪影，**没有任何点亮的灯、没有车灯**；金色只在第 1 格那根被抽出的金线和第 2 格正在散开的掌纹上，其余全页不许有金色。
- 场景：狼倒下的林子边缘以 `comic/ch01/p50.jpg`–`comic/ch01/p53.jpg` 成图为准；土路与镇口以 `comic/ch01/p41.jpg`（镇口、水泥砖、半拉卷帘门、留白招牌）与 `comic/ch01/p49.jpg`（出发时的同一条路）成图为准——**回程必须是同一条路的反向**，读者要认得出来。
- 画面内不出现任何文字：牌坊无字、招牌留白、瓶身无标签、警示牌空白。
- 配色：腐叶褐 + 松墨绿黑 + 黄昏灰橘 + 皮卡旧漆蓝灰 + 一点朱橘（苏雀）+ 玻璃瓶的透明冷灰；主格整体偏暗，只留天边一条亮带。
