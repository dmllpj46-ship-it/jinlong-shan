# 第一话「最后一单」· P30

**场景**：现代 · 山边别墅一层门厅 · 清晨（苏雀走后半小时）

**页旨**：苏昭做了一个决定——她不再只是把人留在身边等。她开始往他身上放东西。陈默的第一反应不是狂喜，是「这不合理」：他上个月还在为一笔三块钱的配送费跟客户吵，现在有人要教他法术。

## 绘制备注

- **分格版式（恰好 3 格）**：一条横格线贯通整页宽度、落在页高 42% 处；线**以上**由一条斜切线分成左右两格（46% / 54%），该斜线起止都只在这条上带内部，不得越到下半页；线**以下**是一整格不间断的宽 splash，内部不许再出现任何竖线或斜线。Total regions = 3。主格是第 3 格底通栏。
- 逐格人物数：第 1 格只有陈默 1 人；第 2 格只有**两只手**（苏昭的手，不给脸、不给身体）；第 3 格只有苏昭 + 陈默 2 人。全页不出现第三人——**苏雀已经下山，本页不在场**。
- **HAIR / CAST LOCK**：
  - 苏昭 = 炭灰**长外套** + 月白内搭 + **低髻** + **右鬓白发** + 不笑；她站着，手里只有那根旧木棍，**没有瓶、没有剪刀、没有提灯**。
  - 陈默 = 藏青冲锋衣 + 灰连帽 + **全黑散发** + 左腕红绳 + 空白工牌；他是年轻男人，**不许出现低髻、发簪、白发、长外套**。
  - **穿长外套的一定有白发；穿冲锋衣的一定是全黑散发。**
- **道具口径（新增，往后要延续）**：苏昭教的是**武功与运用**，所以陈默这一段的器械只允许**一根从门后拿的旧木棍**——没有护手、没有剑格、没有绑绳，不许画成一把真正的剑。断水仍然油布裹着立在墙角，**本页不许她拔剑**，也不许它出现在她手里。
- 符纸一律**空白**：无字、无朱砂纹、无符号；手机屏幕不可读，无 app 界面、无数字、无 logo。
- 室内以 `comic/ch01/p10.jpg`、`comic/ch01/p11.jpg` 成图为准；白天版门厅**不点灯**，全页唯一光源是院门那道晨光。
- 不画超自然现象：本页**没有任何发光、没有金线、没有符纸自燃**——元能要到 P31 才第一次出现在他手上。
- 配色：清晨冷白 + 木褐 + 墨黑阴影；饱和色只给陈默的红绳与苏雀留在长凳上的那只纸袋的纸黄。
