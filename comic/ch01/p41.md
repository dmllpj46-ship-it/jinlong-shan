# 第一话「最后一单」· P41

**场景**：现代 · 山下城→龙潭镇的盘山大巴与镇口 · 上午到中午（离开山边别墅的第二天）

**页旨**：现代线第一次真正离开城市。读者要在这页拿到两件事——龙潭镇是一个**靠旅游活着、淡季空得能听见风**的偏远镇子；以及黑森林不是景区，是**镇子旁边一块不许进的军事禁区**。全页不解释任务，只给路、镇子和一句行话。

## 绘制备注

- **分格版式（恰好 4 格）**：三条贯通全宽的水平格线，分别落在页高 52% 与 82%；52% 与 82% 之间由一条斜切线分成左右两格（46% / 54%），该斜线的起止只在这条中带内部，不得越到顶格或底格。Total regions = 4。主格是第 1 格顶通栏。
- 逐格人物数：第 1 格只有车窗反光里的**一张脸**（苏雀）+ 前排椅背，不许出现第二个人；第 2 格只有一个骑三轮的**背影**；第 3 格只有苏雀与陈默两个人；第 4 格**没有人**。
- **黑森林口径（v2.2 修订）**：它是龙潭镇旁边的**军事禁区**，不是景区——不卖票、不设检票口、没有游客设施，只有铁丝网、水泥墩、留白的警示牌与林子里露出来的混凝土掩体口。翻围栏进去的人是**自己进去的**。第 4 格是本页唯一一处黑森林的方向，只给路、网与牌子，**不许出现任何动物、黑影、血或尸体**。
- **龙潭镇口径**：偏远的旅游镇。视觉语言是「旅游镇淡季」——半拉的卷帘门、空荡的观景步道、没人收的晾晒、一整排不可读的招牌。不画城市霓虹、不画高楼、不画车流。所有招牌、路牌、警示牌一律留白不可读（规则 5）。
- **HAIR / CAST LOCK**：苏雀 = 全黑高马尾 + 红色塑料雀形发夹 + 朱红短夹克 + 银剪皮套挂胯侧 + 虎牙，**没有白发、没有长外套、没有提灯、没有剑**；陈默 = 短黑发、灰蓝工装夹克、左腕旧红绳、双肩包，**没有沈珩的烧伤疤、没有长发、没有道袍**；本页慕白不进画面。
- 光：顶格是车窗外的白天硬光 + 车内阴影；中带是镇口的散射日光（阴天边缘）；底格是林口的低反差灰。全页不出现任何金色、不出现灯。
- 场景：大巴内景无锚点，按「没 logo 的旧长途客车」画（塑料座椅、编织袋、头枕套、无广告）；镇口以本页成图为文字锚点的补充依据（`assets/characters/design-bible.md` 地理·龙潭镇）。
- 画面内不出现任何文字。
- 配色：松针墨绿 + 水泥灰 + 卷帘门褪蓝 + 一点钠黄（远处镇上的灯，只允许一格有）。
