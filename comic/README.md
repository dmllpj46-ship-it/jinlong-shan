# Comic pages

Finished pages go here as `chNN/pNN.jpg` (2-digit chapter, 2-digit page), e.g. `ch01/p01.jpg`.

格数由本页的beat决定，不固定为四格（见下方模板）。Follow `assets/characters/design-bible.md` for every character and location in frame. Page notes (panel breakdown, dialogue, deviations) sit next to the image as `pNN.md`.

Page images carry no lettering; dialogue and SFX live in the `pNN.md` scripts and get added at the lettering stage.

P33 已经把全书最大的那张牌摊给读者了：**陈默是沈珩九块元神里主魂那一块的转世，苏昭五百年的主线是九合一**。往后写这一段的每一页都记住三件事——陈默一无所知（他只信了「天生的元能体质」）、苏雀一知半解且不许她想明白、苏昭只讲真话但永远缺一块。赤蟒在 P33 之后仍然不许提前露面。

P35–P40 加进来两条新的硬口径：**渗出点每往外挪一次，就是锁往里松了一寸**，而这句判断只允许苏昭自己在心里说（P36 那句「漏得越来越远了」是上限，不许她告诉苏雀、陈默或任何第三方）；**龙潭镇与山腹的恶龙潭是两处地方**，镇子那口水塘没有锁、没有断链、没有赤蟒，任何一页都不许互相指代。黑森林那只异兽在 v2.5 之前正篇只给剪影、痕迹与声音——P35 那段模糊视频是这个口径的产物，定妆之后**也不许回头把 P35 重画成正脸**。

P47–P54 立起本段自己的五条口径：**变异野狼（`bian-yi-lang`）已定妆，恐怖来自比例不来自强度**——肩线低于臀线、躯干过长、四肢偏短、尾巴粗厚中段打结、浅草黄的普通圆瞳孔（绝不发光、无竖瞳）、脊下暗金筋纹不发亮；它不说话、不施法、只追与撞，全段只出现一只。**暴力有上限**：陈默那一下只晃眼不伤身，线一断就什么都没有；致命的永远是苏雀那一剪，血只给「不超过一只鞋」的一小摊深色，不给伤口特写、不给内脏。**慕白的两名手下没有定妆，因此一律不给正脸**（帽檐、口罩、手套、背影、半侧），无枪无刀无法器、不提名、不参与讨论；每格人数要写死「恰好 N 个 + 点名」，防止切出第三个人。**那架无人机是工具不是角色**：深灰四旋翼、无标识无 logo 无屏幕无 HUD、不发光，全段最多两架、永远收桨或被帆布盖住。**新铁丝的钩子在 P50 由读者自己接上**（缺口就是缆收出去的那一头，所以有人常从外面补围栏），任何角色与旁白都不许说破；慕白全程没说「狼」这个字，陈默的心声是唯一一次替读者问出来。

P41–P46 立起本段自己的四条口径：**黑森林是现役军事禁区**，不卖票、无检票口、无售票亭与导览牌，画面里只有锈铁丝网、水泥墩上的留白警示牌与混凝土掩体口，死了的三个人是自己翻围栏进去的；**龙潭镇是偏远的旅游镇且没有信号**，视觉语言是淡季——半拉卷帘门、一整排不可读的招牌、没人收的晾晒，所有招牌路牌警示牌一律留白；**慕白是镇上的民宿老板，不是高人**，一切道士视觉语言禁止，他的人脉只由钥匙、毛巾、搪瓷缸和一张手绘路读出来，且他的台词允许只说半句、禁止说完；**民宿不是苏昭的山边别墅**，两间房子不许串味，民宿夜戏一页只允许屋里一处光源，P45 走廊尽头那扇门的门缝下绝对不给光。P46 那道崭新的铁丝是本段最后的钩子——「有人常来补围栏」由读者自己得出，任何角色和旁白都不许说破。
