# 第二话「上宾」· P40 / 040

**场景**：现代 · 山边 · 昭记铺子 · 深夜

**页旨**：**她想起一个人。** 柜台上还摆着李家那场之后送来的回礼——一只**没有拆的红封（通身无字）**。苏昭把它挪正，然后说出名字：「李锦鸿。」理由全是可数的：他认识的人比我们多、他欠我一场还没还、他信我的价钱。陈默心里那句是「她说的是价钱。」「不是人情。」

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **24%** 与 **64%**；底带由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；中带（第 2 格）是一整格、左右出血，内部不切。TOTAL PANELS = 4。主格是第 2 格（40%）。
- 逐格人物数：第 1 格**一只手、零脸**；第 2 格**恰好一个**（苏昭正面中景，**不许**大特写、不许美颜、不许发丝散落）；第 3 格**恰好一个**（陈默半侧）；第 4 格**恰好一个**（苏雀侧脸，眼睛不入画）。
- **回礼口径（硬）**：只有**一只没拆的素红封**——**通身无字、无店名、无烫金、无缎带印字、无封条字**；**不许**礼盒堆、不许贵重物品外露、不许摆件、不许任何带字的信封或贺卡。它是 P06「上宾」那笔人情的实物，**摆着，但没有人去拆**。
- **她为什么想起李锦鸿，理由必须可数**：他认识的人比我们多 / 他欠我一场还没还 / 他信我的价钱。**不许**说「他有钱」「他有背景」「他和那边有关系」；**一个字都不许提**采金、集团、拆锁、工程队、施工方——这条暗线仍只由读者自己接（ch01 P75 廊下那只空白图纸卷袋与黄色安全帽）。
- **「他欠我一场。」「还没还。」** 两句分开、说得平；**不许**带笑意、不许带算计的表情。
- **苏昭不许在这一页安排细节**（钱、方式、时间都不给），只说人名与理由；具体的「暗着来」全部留给下一格（P41 的电话）。
- **陈默的两句心声只给读者**：「她说的是价钱。」「不是人情。」——**不许**任何人接；**不许**他表现出对李锦鸿的反感或怀疑。
- **光**：深夜，室内一盏灯，另一盏灭（`dark tube, no glow, no light spill`）；红封是全页**唯一暖色**（**不许**第二个红色物件、**不许**苏雀的发夹与它撞色——她这一页发夹可以不进入画面）。
- **桌面与墙**：素灰墙、什么都不贴；柜台上只有红封、旧木托、一页纸、一只旧茶缸、一部扣着的手机（只给背面）。**禁**账本、名片、文件、报纸、日历。
- **HAIR / CAST LOCK**：苏昭＝**头发 100% 全黑**（**不许**白发、白发带、银丝）、低发髻、闭合深灰长外套；苏雀＝全黑高马尾扎紧 + **深炭蓝近黑**短夹克（**NOT red / maroon / orange / brown**），若发夹入画则**红夹是唯一红**；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳、无疤。
- 画面内不出现任何文字。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- prompt 首段固定：`VISIBLE HALFTONE DOT SCREENTONE — flat cel shading — crisp black ink linework — professional Japanese shonen fantasy manga page`；并写 `NOT webtoon, NOT painterly, NOT semi-realistic skin`。
