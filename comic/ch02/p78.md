# 第二话「上宾」· P78 / 078

**场景**：现代 · 黑森林深谷 · 地下基地深处 · 傍晚（接 P77）

**页旨**：**军事基地。** 定性落在这一页：这是一座**当年日本军队留下的地下军事基地**（新世界观事实）——被现代那家公司（李锦鸿的合作方）从上面**挖穿**了。三人站在基地深处一小块开阔地上，旧军械环绕、手电照不到尽头，薄金雾从**最里头**飘来。苏雀把话说死；慕白只给数得到的（风从最里头来）；陈默问"那这底下到底还有啥"，**没人接**。**收在问题上——最里头是什么、和赤蟒/封印什么关系，本段一个字不揭。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **20%** 与 **66%**；顶带一整格通栏；中带一整格通栏主格（46%）；底带由一条**近竖斜线**切 **52 / 48**（只在本带内部）。TOTAL PANELS = 4。主格是第 2 格中带通栏（三人立于基地深处）。
- 逐格人物数：第 1 格**零人**；第 2 格**恰好三个**（苏雀·陈默·慕白）；第 3 格**恰好一个**（慕白半侧）；第 4 格**恰好一个**（苏雀半侧，陈默只画外）。**只有这三人，不许第四人、不许军械后多一个人影。**
- **军事基地定性（硬，本段最重要）**：这是**当年日本军队入侵中国时留下的地下军事基地**（新世界观事实）；**现代日方公司知情、是从上面挖穿它来的**（承 P77 苏雀心声）——但**"为什么冲它来""最里头是什么"本段一个字不给**。
- **不揭三颗雷（硬）**：**严禁**出现赤蟒、封印、金脉本体、那个方口门洞后面、基地最里头任何东西；尽头只给"照不到的更黑 + 薄金雾"。
- **慕白口径**：只说数得到、看得见的（「风从最里头来。」「往里，我没走过。」）——他守这道口子多年，但**不许**他说破自己是什么、不许他讲元能/年代/日本；他"没走过"是真的（他守口子、不深入）。
- **苏雀收口（硬）**：「一座基地。日本的。当年的。」「被上头那家，挖穿了。」——只到定性；**不说「元能」「封」「赤蟒」**；那句「老古董，知道这儿吗。」**只由心声**，不许她问出口、不许旁白答。
- **陈默问一句没人接**：「那这底下……还有啥?」被晾着——**不许**他放线、不许他说"报警/叫人来/我要往里"。
- **元能视觉语言**：薄金雾 + 耳鸣，克制；**禁**泛滥/光柱/法阵。**免疫口径**：三人没事、不写不适。
- **HAIR / CAST LOCK**：苏雀全黑高马尾扎紧 + 红夹（唯一红）+ 深炭蓝短夹克；陈默短黑发 + 灰蓝夹克 + 红绳 + 旧木棍；慕白苔灰绿短褂 + 圆框眼镜 + 旧布鞋。
