# 第二话「上宾」· P31 / 031

**场景**：现代 · 龙潭镇 · 黑森林下行 → 谷口 · 上午转正午

**页旨**：**下去。** 从围栏缺口往里走，风先没了，然后是光没了，最后是谷口那一线天亮。慕白第一次走进林子（此前他只到林线外头），他给的全是路程——多远、多久、风在哪一段停。**本页不给谷里任何东西，只给一个入口的漏斗与一线天。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **58%**；只有中带内部由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**零个人**（只有三行脚印与两根光锥，**不许出现人影、不许出现第四行脚印**）；第 2 格**恰好一个背影**（慕白）；第 3 格**一个半**（苏雀一只手 + 陈默一条手臂，**两人都不给脸**）；第 4 格**恰好三个背影**（慕白在左前、苏雀居中、陈默在右后），**不许第四人、不许林子里多一个影子**。
- **谷口只给入口**：漏斗状的凹处、纯黑、边缘参差、内部**什么都不给**——不许发光、不许有形体、不许有眼睛、不许有建筑机器人影。它与 P28 屏里、P30 远景那个口子是**同一个**，本页只许「近、大、黑」，尺度靠三人与漏斗的高差。
- **光**：谷外是上午的白灰硬光，进林子就只剩手电光锥；**手电是普通白光**，光锥窄、边界硬、不许泛光成雾、不许画出光柱的体积光。一线天光是**唯一的天光**，落在碎石上，不落在人脸上。
- **慕白**：他**第一次进林子**，但他的走法像一个走惯了山路的人——不看树、只看脚下；**不许**给他灯笼、罗盘、符纸，**不许**给他「高人领路」的姿态（他走得不快，不回头招呼）。参考一律 `mu-bai-v2.png`，**绝不许 v1**。
- **装备**：三个人各一只普通白光手电（苏雀那只小、陈默那只大）；背在陈默身上的是那只旧编织袋（**无标识**）。**禁**头盔、护目镜、夜视仪、攀岩绳、军品、无人机随行。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩上灰毛巾、旧布鞋。
- 画面内不出现任何文字：树干无刻痕、袋子无字、手电无标。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- 画风：可见网点 `halftone dot screentone` + 平涂赛璐璐 + 黑墨线；**不是**写实、不是厚涂、不是韩式网漫。
