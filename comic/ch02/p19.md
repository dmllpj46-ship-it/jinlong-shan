# 第二话「上宾」· P19 / 019

**场景**：现代 · 山门镇 · 昭记铺内 · 当天深夜（从堂口回来）

**页旨**：**她一次都没打开。** 苏雀把那只旧帆布包放上柜台，苏昭不问过程，先把掌心整只压在包里的布上——「凉。」「它凉得不合规矩。」然后她把袋子放进柜台底下那只旧木箱、扣上搭扣：「先搁我这儿。」苏雀问「不上山?」，她答「不上山。」陈默站在门边，心里记一句「她一次都没打开。」

**这一页只做三件事**：验（不用眼睛）、收（不上山）、以及让读者记住**它从此不会再裸露**。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **26%** 与 **58%**；只有中带内部由一条**近竖斜线**切 **48 / 52**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**恰好三个**（苏昭、苏雀、陈默）；第 2 格**零脸**（一只手掌 + 布）；第 3 格**零脸**（两只手 + 木箱 + 半截衣角）；第 4 格**恰好两个**（陈默全身、苏昭在深处低头）。
- **白玉的口径（硬，v3.2 沿用）**：它已经在 P16–P17 被素布裹住、装进帆布包带走，**从此不许再裸露**。本页第 2 格只允许出现「布下面的一个轮廓」——**不许画玉面、不许画金纹、不许画玉的光泽**；任何人都不许直接碰它。
- **「凉」这一下的分寸**：苏昭不是用手艺验，是用**手**验；她的表情上限是**眼皮不动、手停住**，禁惊讶、禁皱眉、禁倒抽气。
- **不上山的理由一个字都不给**：只留「不上山」三个字。**不许**任何角色说「山」「锁」「金脉」「元能」「离山越近越危险」这类解释。
- **旧木箱**：柜台底下、深褐旧木、铜搭扣、掉漆、无字无锁（**不许**画锁孔里的钥匙、不许画符、不许贴纸）。
- **昭记的口径**：铺内固定只有这些——木柜台、账本（页是空白的）、玻璃柜里的纸扎与罗盘、墙上空白挂轴、门口那盏不灭的纸灯；**招牌、黄历、门牌一律留白不可读**。
- **HAIR / CAST LOCK**：苏昭＝全黑低髻 + **只在发髻里几根细白**（右鬓那一缕，**不是白发带**）+ 闭合深灰长外套（不许露白衬衫领）；苏雀＝全黑**高马尾扎紧在头顶** + 红雀发夹（**全页唯一红**）+ 深炭蓝短夹克（NOT red/orange/maroon）+ 银剪；陈默＝短黑发**全黑一根白都不许** + 灰蓝夹克 + 左腕旧红绳。
- 画面内不出现任何文字。
