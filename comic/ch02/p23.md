# 第二话「上宾」· P23 / 023

**场景**：现代 · 昭记铺内 · 天没亮前

**页旨**：**派工只给三样可数的事。** 「找三样。」「谁在挖。」「挖多深。」「挖出来的，往哪儿去。」苏雀问「找着了呢」，她答「别动。回来告诉我。」陈默问慕白知道不知道，她答「他等着。」「他知道的比我多。」——最后那沓无字纸钞推过柜台，只有一句「去吧。」陈默心里记：「她答了。等于没答。」

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **60%**；只有中带内部由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好三个**（苏昭 + 苏雀 + 陈默）；第 2 格**恰好一个**（苏雀半侧 + 纸条）；第 3 格**恰好一个**（陈默半侧）；第 4 格**恰好两个**（苏昭的手与下颌 + 陈默接钱的手，**两份手不许画成同一个人**）。
- **派活的文书（硬，v2.1 沿用）**：只有两样——**一张空白纸条**（无字、无图、无地址）与**一沓皮筋捆着的无字纸钞**（无头像、无数字、无面额、无国徽、无真实钞纹）。**不许**出现手机、微信、文件袋、信封、地图、照片、门禁卡。
- **三样任务是本页唯一的「方法」**：谁在挖、挖多深、挖出来的往哪儿去——**只许这三句**，不许加第四条、不许解释为什么是这三样。
- **「别动」是硬命令**：苏雀问「找着了呢」，答案只有「别动。回来告诉我。」六个字加一个逗号，**不许**补「小心」「注意安全」「有事打电话」。
- **陈默的两问必须真的问出口**：这是 P39「你没有要问的」的再一次翻面——但苏昭**仍然不给完整答案**，「他知道的比我多」是全部。
- **光**：门内是纸灯剩下的暖（很弱），门外是天没亮的灰蓝；两色交界落在门框上。
- **HAIR / CAST LOCK**：苏昭＝全黑低髻 + 只在发髻里几根细白 + 闭合深灰长外套；苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳。
