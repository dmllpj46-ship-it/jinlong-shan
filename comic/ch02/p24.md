# 第二话「上宾」· P24 / 024

**场景**：现代 · 昭记门口 / 山路 / 龙潭镇镇口 · 天亮前

**页旨**：**再探。** 出门时苏雀只交代两件事：「到了镇上，先别开口。」「那边的人认得我这张脸。不认得你。」以及一句：「还有——别在镇上问那句话。」陈默问「哪句」，她答「你自己心里那句。」镇口天光未亮，石牌坊**没有字**，两束车灯照在水泥砖路上，路边那栋两层木屋门口站着一个矮胖老头的背影——院门里没有招牌。陈默只在心里记两句：「这条路我走过一趟。」「上次是她带我走的。」

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **24%** 与 **58%**；只有中带内部由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**恰好三个**（两个背影 + 门内半个肩）；第 2 格**零脸**（嘴与下颌 + 一只手）；第 3 格**恰好一个**（陈默半侧）；第 4 格**恰好三个**（车里两点轮廓 + 门口慕白背影，**慕白只出现这一次**）。
- **镇口的口径（硬，v2.2 沿用）**：龙潭镇是**偏远的旅游镇**——水泥砖路、自建房、卷帘门半拉、一排**留白的招牌**；镇口一块**没有字的石牌坊**。**所有招牌、路牌、警示牌、门牌一律留白不可读**；**不许**出现景区售票亭、导览图、灯笼、彩旗、广告灯箱、霓虹。
- **「龙潭」不是山腹那个恶龙潭**：本页不许出现任何水塘特写、不许出现锁链/符布/烧化的痕迹、不许让任何人把它跟金龙山连起来。
- **慕白只给背影**：矮胖、谢顶一圈花白、苔灰绿对襟布扣短褂、肩上灰毛巾、腰上一串旧黄铜钥匙含一块**空白木牌**；**不给正脸、不给眼镜反光、不给任何「高人在此」的姿态**（他就是站在自家门口的房东）。**禁止**道士视觉语言。
- **两句话的分寸**：苏雀的交代**不许**带威胁、**不许**带笑意；「你自己心里那句」之后**立即切格**，不许她再解释。
- **陈默的心声是本页唯一的情感落点**：他**来过**（ch01 P41–P44，慕白带过路），所以这里是「走过一趟」而不是「第一次听说」。**不许**让他惊讶、**不许**让他问「这是什么地方」。
- **光**：昭记门口一盏纸灯的暖；路上冷灰；镇口是**天亮前的灰蓝**，车灯是画面里唯一硬光，**不许**把天画亮。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；苏昭（第 1 格门内半个肩）＝闭合深灰长外套、全黑低髻。
- 画面内不出现任何文字。
