# 第二话「上宾」· P62 / 062

**场景**：现代 · 黑森林 · 窄道 · 白天（接 P61）

**页旨**：**第一下。** 头一只初级异兽从腐叶里窜出来、扑向最前的手下——**那是全书第一次有枪响**：枪口抬起、一团**风格化**的枪口焰（速度线与星芒，不写实），小兽在半空被打偏、干净落地，**不见血特写、不见内脏、无人受伤**。但苏雀的眼睛不在兽上，在**那支枪**上——她读出：他们带了家伙。

## 绘制备注

- **分格版式（恰好 4 格）**：一条**贯通全高的竖线**在页宽 **46%** 处把页面切成左右两列；**右列一整格满高**（主格，54% 宽，上/右/下三边出血）；**左列由两条只在左列内部的水平线**切成三格（0–33% / 33–66% / 66–100%），水平线**不得越到右列**。TOTAL PANELS = 4。主格是右列满高纵格（垂直力：扑与抬枪）。
- 逐格人物/异兽数：第 1 格**恰好一个手下（无脸）+ 陈默一个背影 + 恰好一只小兽**；第 2 格**恰好一只小兽**（零人）；第 3 格**恰好一个**（苏雀）；第 4 格**恰好两只小兽 + 慕白一只手**。**异兽总数本页 ≤ 4 只，逐格数死，不许同格三只以上、不许镜像分身。**
- **变异幼狐口径（新，v3.10 定妆 `bian-yi-you-hu`）**：**初级异变的小型犬科/狐类**——比 ch01 那只狼**小一号、比例正常**（肩与臀大致齐平，**不许**再画成肩低于臀的错位大狼）；**普通圆瞳、pale 稻草黄、绝不发光、无竖瞳**；嘴略长、普通小齿（**不是变异鼠的骨白长门齿**）；脊背几道**哑光暗金纹**（不发光、不成符纹/阵/龙形）；毛挂湿松针。**成群、快、弱**——恐怖来自**数量和快**，不来自体型与强度。
- **持械与暴力上限（硬，v3.10）**：枪是**打退小兽的工具**——枪口焰一律**风格化**（冷白星芒 + 放射速度线），**禁**写实枪火、禁弹壳飞溅特写、禁瞄准镜 HUD、禁任何人的脸被枪指着。**无人受伤**；小兽被打偏/倒下**干净**——**禁**血、禁伤口特写、禁内脏、禁断体。苏雀一方**不动枪**。
- **苏雀读出（硬）**：「他们带了家伙。」只由她一句心声承担；**不许**她当场质问泰哥、不许她点破是谁备的（那是李锦鸿的手，留给 P65–P66）。
- **陈默定位**：只观察、只被慕白带半步；**不许**他放线、不许他抢功、不许他喊打。
- **黑森林口径**：密针叶黑竖纹、湿腐松针、手电白光楔形；**禁**门洞/谷底/那个口子/任何内部/车辆/建筑。
- **HAIR / CAST LOCK**：苏雀全黑高马尾 + 红夹（唯一红）+ 深炭蓝短夹克；陈默短黑发 + 灰蓝夹克 + 红绳 + 旧木棍；慕白苔灰绿短褂 + 圆框眼镜 + 旧布鞋；手下便帽口罩手套 + 长枪，**无正脸**。
