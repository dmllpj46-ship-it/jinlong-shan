# 第二话「上宾」· P39 / 039

**场景**：现代 · 山边 · 昭记铺子 · 深夜

**页旨**：**为什么不能自己去问。** 苏昭把这件事拆成三个问题（谁出的钱、谁派的工、撤的时候谁下的令），然后一句一句把这三种问法否掉：**不是问不出口，是一开口，镇上第二天就知道昭记在打听。** 本页不给答案，只把路堵死，让「另找一个人」成为唯一出路。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **24%** 与 **60%**；中带由一条**近竖斜线**切 **50 / 50**，斜线只在本带内部、不上下越行；底带一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好三个**（苏昭站、陈默与苏雀坐，侧影，不特写脸）；第 2 格**恰好一个**（陈默半侧）；第 3 格**恰好一个**（苏雀侧脸，眼睛不入画）；第 4 格**恰好一个背影**（苏昭，**脸不许入画**）。
- **三个问题必须逐条念出**（谁出的钱 / 谁派的工 / 撤的时候谁下的令）——这是苏昭的说话方式：**她从不问「为什么」，只问「谁」和「多少」**。
- **否掉的理由要可数**：「我们这张脸，在山里是脸。」「搁到那种桌子上，是招牌。」——用的是**身份**，不是神秘力量；**不许**说「山门不让我们查」「上面有人」「有规矩」「不方便」这类含糊话；**不许**提山、锁、金脉、元能、阵。
- **苏昭不许在这一页给出「找谁」的答案**——那是下一格（P40）的事。她这一页的最后一格是**背身站在门口**，把门堵住而不是推开。
- **台词不许写成演讲**：四句短句一组，句间留白；**不许**加解释性长句、不许加「你知道吗」这类口语。
- **光**：深夜，外面纯黑、卷帘边缘一条极细的反光；室内只一盏灯，另外一盏灭着（`dark tube, no glow, no light spill`）。墙是素灰、什么都不贴。
- **桌面口径**：一页纸、一只旧茶缸、一部扣着的手机（**只给背面**、屏幕不入画）；**不许**账本、名片、地图、文件、报纸、日历、任何带字物件。
- **HAIR / CAST LOCK**：苏昭＝**头发 100% 全黑**（**不许**白发、白发带、银丝）、低发髻、闭合深灰长外套、无簪无饰；苏雀＝全黑高马尾扎紧 + 红雀发夹（**全页唯一红**）+ 深炭蓝近黑短夹克（**NOT red / maroon / orange / brown**），银剪不在手上；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳、无疤。
- 画面内不出现任何文字。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- prompt 首段固定：`VISIBLE HALFTONE DOT SCREENTONE — flat cel shading — crisp black ink linework — professional Japanese shonen fantasy manga page`；并写 `NOT webtoon, NOT painterly, NOT semi-realistic skin`。
