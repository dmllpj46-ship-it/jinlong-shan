# 第二话「上宾」· P37 / 037

**场景**：现代 · 山边 · 昭记铺子 · 夜

**页旨**：**把两样东西摆上柜台。** 陈默与苏雀从龙潭镇回来，先汇报。他们只带回来两样：手机里的十七张照片，和一页画出来的速记——**谷里那些东西，一件都没带回来**。苏昭从头到尾没问机器，只问那扇门。**收在她那句「再说一遍那扇门」上。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **24%** 与 **60%**；中带由一条**近竖斜线**切 **50 / 50**，斜线只在本带内部、不上下越行；底带一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好三个**（苏昭在柜台后、陈默与苏雀在柜台外，侧影，不特写脸）；第 2 格**一只手**（苏雀的，**零脸**）；第 3 格**恰好一个**（陈默半侧，眼睛不入画）；第 4 格**恰好一个**（苏昭，正面中景，**不许大特写脸、不许美颜**）。
- **带回来的只有两样**：一部手机 + 一页纸。**不许**出现任何实物证物（不许螺栓、不许石屑、不许炮孔残片、不许机器的零件、不许装在袋子里的锈铁）——P36 的「别动它」在这一页要守住。
- **本子口径（硬）**：纸上只有**几根直线与两个小圈**；**零字、零数字、无比例尺、无指北针、无图例、无坐标格**。这是 `ABSOLUTE NO-TEXT RULE` 的又一例（P26 的图曾印出过 `NOW` 类字）。
- **手机口径**：手机**扣着**放在柜台上，**只给背面**（一块空白的旧机身、一个摄像头、无标、无壳）；**屏幕完全不入画**。
- **苏昭不看照片**：这一页她**没有伸手**去拿手机，也没有翻那页纸；她只问门。翻照片是下一格（P38）的事。
- **柜台上的东西**：一盏灯、一部扣着的手机、一页纸、一只旧茶缸、柜台后一只抽屉半开。**不许**出现账本、名片、文件、报纸、日历、任何带字的物件；墙上**素灰、什么都不贴**。
- **光**：全页只有一盏灯亮，另一盏是灭的（`dark tube, no glow, no light spill`）；铺子里其余部分靠灯的反光，暗部不许死黑，网点要看得见。
- **陈默的三句是汇报，不是主张**：「门框上没有门。」「只有一个框。」「螺栓四个，都在。」——说得平、不带情绪；**不许**说「有鬼」「不干净」「是基地」「是工程队」。
- **苏昭只问可数的事**：她一个字不问机器、不问人、不问元能；只问那扇门**是不是方的、角是不是直的**。心底那一句只给读者：「她问的不是门。」
- **HAIR / CAST LOCK**：苏昭＝**头发 100% 全黑**（**不许**画白发、白发带、银丝、鬓角挑白）、低发髻、闭合的深灰长外套、无簪无饰；苏雀＝全黑高马尾扎紧 + 红雀发夹（**全页唯一红**）+ 深炭蓝近黑短夹克（**NOT red / maroon / orange / brown**）、银剪不在手上；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳、无疤。
- 画面内不出现任何文字：手机背无标、纸上无字、墙上无贴、抽屉里无纸。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- prompt 首段固定：`VISIBLE HALFTONE DOT SCREENTONE — flat cel shading — crisp black ink linework — professional Japanese shonen fantasy manga page`；并写 `NOT webtoon, NOT painterly, NOT semi-realistic skin`。
- 画风：可见网点 + 平涂赛璐璐 + 黑墨线；夜间室内，冷灰为主、唯一暖色是那盏灯与苏雀的发夹。
