# 第二话「上宾」· P70 / 070

**场景**：现代 · 黑森林 · 谷底裂缝前 → 谷沿一线天（有信号处）→ 李锦鸿窗前 · 下午（接 P69）

**页旨**：**带他们出去。** 苏雀当场要泰哥把他的人撤出深谷。泰哥**做不了主**——他的人、他的活，得问东家。**谷底没有信号**（P32 硬设定），苏雀只能爬到谷沿那道一线天、有信号的地方给李锦鸿打。李锦鸿**不同意叫停**：他人已经投进去了、他要的是"往里的那点东西"。苏雀不跟他吵，只把谷底的情况摆给他：**你的人开始往下沉。**

## 绘制备注

- **分格版式（恰好 4 格）**：一条**贯通全高的竖线**在页宽 **54%** 处切成左右两列；**右列一整格满高**（主格，54% 宽，上/右/下三边出血）；**左列由两条只在左列内部的水平线**切成三格（0–33% / 33–66% / 66–100%），水平线不得越到右列。TOTAL PANELS = 4。主格是右列满高纵格（苏雀在谷沿打电话）。
- 逐格人物数：第 1 格**恰好一个**（苏雀半侧）；第 2 格**恰好一个正脸**（泰哥）**+ 两个无脸手下**；第 3 格**恰好一个**（李锦鸿，不给正面特写）；第 4 格**恰好一个**（苏雀半侧）。
- **信号口径（硬，承 P32）**：**谷底完全没信号**——打电话必须**在谷沿/坡顶有信号处**；手机屏幕**只给一片亮白或只给机背**，**严禁**信号格、界面、时间、运营商、任何字、"无服务"提示框。不许画"听筒里的声音"对话框。
- **两套口径（硬）**：对**李锦鸿**只许**工程/民俗口径**（「往里那点东西」「你的人往下沉」），**一个「元能」「泄露点」「封」字都不许对他说**；李锦鸿**不同意叫停**（他要的是那处挖掘里的东西，顺藤摸瓜线继续）——**不许**任何角色说破他的算盘，只由苏雀那句「你的人已经有人在往下沉了」把风险摆平。
- **泰哥口径**：不报名字、不自报家门、只认付钱的（「我做不了主。得问东家。」）；**禁**他说「元能」「山」「基地」。**手下无正脸**、无血腥。
- **苏雀主打（硬）**：撤人的话从她口里出；她**不跟李锦鸿吵**、不解释原理、不说"元能"；她的判断只到"站不住/往下沉"这种看得见的。
- **HAIR / CAST LOCK**：苏雀全黑高马尾扎紧 + 红夹（唯一红）+ 深炭蓝短夹克；泰哥短黑发 + 颧骨旧疤 + 橄榄工装夹克 + 长枪斜背；李锦鸿四十上下 + 短黑发 + 深色西装无花纹；手下无脸。
