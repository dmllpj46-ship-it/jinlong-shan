# 第二话「上宾」· P45 / 045

**场景**：现代 · 李锦鸿的别墅 · 走廊尽头与私人书房 · 同一个下午

**页旨**：**门没有牌。** 他把两个人带进最里面一间：门上一块空着的名牌位、走廊全冷白、屋里只亮桌上那一盏台灯。桌上摊着一沓打印纸——**表格的线还在，格子里的字没有了**。他对着那沓纸说出这一章最重的一句：「我下面一家公司。」「挖山的，是我的人。」

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **24%** 与 **62%**；中带由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；底带一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（38%）。
- 逐格人物数：第 1 格**零人**；第 2 格**恰好一个**（李锦鸿，侧身让门）；第 3 格**零人**；第 4 格**恰好三个**（李锦鸿、苏昭、陈默）。**全页没有第四个人**。
- **书房口径（本段新增，硬）**：这是新房子的最里面一间，**固定元素只有这些**——深色木门 + 门上一块**空着的名牌位**（无字无编号）、深色长桌、桌上**一沓打印纸 + 一只杯子 + 一盏台灯**、书架（书脊**全部素色无字**）、窗外山那边一片散光、地面是木地板（走廊才是大理石）。**禁**奖牌、奖状、合影相框、挂画、书法、地图、地球仪、法人证书、营业执照、保险柜、酒柜、电视、电脑、平板、任何带字的墙饰。
- **那沓纸是本页唯一的证据，也是唯一的字风险（硬）**：纸上是**表格的横线与竖线**，**格子里全部空着**——没有一个字、没有一个数字、没有编号、没有公章、没有签名、没有比例尺；**不许**装订成册、**不许**出现页码。它的意思是「行还在，名字没了」，读者要能一眼看见「空」。
- **他的话（硬）**：只有「我下面一家公司。」「挖山的，是我的人。」——**不许**他给公司名字、**不许**给职务、**不许**说城市、**不许**说「集团」「采金」「工程队」「秘密基地」，也**不许**他说「元能」。
- **她的反应（硬）**：本页她**一句台词都没有**，只有两句心声（「他把手压在桌上。」「他在等我说一句。」）；**不许**她点头、**不许**她皱眉、**不许**她当场表态——表态留给 P47。
- **陈默在本页不说话**：只站在半步之后，手垂着；**禁**他放线、**禁**他上前看纸、**禁**他替她开口。
- **光**：全页只有一处暖光——桌上那盏台灯；走廊与窗外都是冷白；**不许**第二处暖光、**不许**台灯照满全屋、**不许**灯泡发光晕。
- **HAIR / CAST / COLOR LOCK**：苏昭＝**头发 100% 全黑**、低发髻、闭合深灰长外套；陈默＝短黑发、灰蓝夹克、左腕旧红绳、无疤；李锦鸿＝四十上下、俊朗、短黑发、深色西装无花纹，**领口松开一点**（本页他第一次不像在会客）。
- 画面内不出现任何文字（名牌位空、书脊素色、纸面空格）。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
