# 第二话「上宾」· P13 / 013

**场景**：现代 · 城北旧货运站后方 · 兴义会堂口 · 当天夜里

**页旨**：**人先到，屋里那四个人一页都不给。** 这一页只做三件事：进门（两个跟班留在巷口）、门边并排摆着的四双鞋、里屋那扇关着的门。鬼九只说可数的事——四个都在里头、白天睡、十二点前后自己坐起来。**全页没有一声呻吟、没有一个病人、没有一处发作**：读者的恐惧只来自那扇门缝里什么都没有。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 24% 与 60%；只有中带内部由一条近竖斜线切 44 / 56，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好四个人**（两个跟班背影 + 苏雀 + 陈默，都很小、分开站位）；第 2 格**零人**（只有四双鞋）；第 3 格**恰好一个人**（鬼九，半张脸）；第 4 格**恰好两个人**（苏雀 + 陈默）。
- **四双鞋是这一页唯一的人物证据**：四双、并排、鞋头朝里、旧胶底，不许画成靴子、皮鞋、拖鞋；**不许**在这一页出现任何躺着或坐着的人、不许画被褥、不许画病容、不许画抽搐。
- **里屋口径（硬）**：门关着，门缝下**没有一线光**；不许把门打开、不许给门内的任何画面、不许给声音（只能由台词说「都在里屋」）。
- **堂口固定元素（沿用 P12）**：卷帘门（半拉）、水泥地、供桌、香炉、空白牌位、红漆长凳。**禁止**武器、刀枪棍、赌桌、筹码、成捆现金、纹身墙、造像、旗、灯笼、任何带字的牌匾与对联；**禁止**雾、鬼影、手印、抓痕、符文、血迹。
- **光**：夜里，只有巷口一盏远景路灯的冷白与卷帘门缝透进来的一线；门内全暗。**无金、无香火、屋内一盏灯都不亮。**
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾 + 红雀发夹 + **深炭蓝短夹克**（NOT red/orange/maroon，全页唯一红元素是发夹）；陈默＝短黑发 + 灰蓝夹克 + 左腕旧红绳；鬼九＝寸头灰多黑少 + 左眉尾旧疤 + 深灰双排扣呢大衣 + 黑高领。**陈默头发全黑，一根白都不许有**。
- 画面内不出现任何文字（鞋、门、牌位、墙面一律留白）。
