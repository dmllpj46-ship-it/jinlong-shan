# 第二话「上宾」· P36 / 036

**场景**：现代 · 龙潭镇 · 谷底 · 洞口与机器间 → 谷口 · 下午

**页旨**：**拍完就走，别动。** 陈默先说话：这里的东西不是他们能收的，先拍照取证、回去跟苏昭商量，不要妄动。苏雀与慕白都点头。于是拍、记、退——全页没有一个人伸手去碰那些机器。**收在三人的背影与洞口那一线天光上。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **24%** 与 **58%**；中带由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**一个半**（陈默半侧 + 手机，**屏幕不许入画**）；第 2 格**一个**（苏雀，**只给侧脸与手，眼睛不入画**）；第 3 格**恰好三个**（陈默、慕白、苏雀，**给脸但不许特写**）；第 4 格**恰好三个背影**（**不许第四人、不许林里多一个影子**）。
- **拍照口径（硬）**：手机**背面朝读者**，只给机身背面与摄像头；**屏幕一律不入画**——不许出现取景框、快门图标、网格线、照片缩略图、电量、时间。**不许**出现相机、单反、三脚架、无人机航拍。
- **本子口径（硬）**：纸上只有**几根直线与轮廓**，**零字、零数字、无比例尺、无指北针、无图例**；笔迹要好读成「速记」而不是「图纸」。这是 `ABSOLUTE NO-TEXT RULE` 的又一例（P26 的图曾印出过 `NOW` 类字）。
- **不许有人碰机器**：全页没有任何一只手套/指尖压在设备上；慕白把手从履带上**拿开**的动作是本页的题眼——他做到了「别动」。
- **陈默的三句是本页的骨头**：「这儿的问题，不是我们能收的。」「拍完，回去跟老古董讲。」——说得平，不带英雄气；**不许**说「报警」「报告政府」「叫人来」「封起来」，**不许**说「我要下去看看」。苏雀只答一个字「对。」；慕白只答「我等着。」（他在镇上等，不是跟着回去）。
- **慕白最后两句**：「这谷，我住几十年。」「头一回不想再来。」——他说得像记账，**不许**带颤音、**不许**成为煽情；**不许**任何人接。
- **洞口在最后一格只许一个四方的黑**：远、小、纯黑、内部不给任何东西；**不许**发光、不许有形体、不许有眼睛，也不许画出 P35 那些机器（它们已经在坡下）。
- **光**：下午的斜光把坡脚照亮、把谷口的天光压成一条；三人的背影在光里是黑的三块；脚印仍在，没有被新的痕迹覆盖。
- **装备**：两只普通白光手电、旧编织袋（无标识）、一部旧手机（无壳无标）、一小本无字纸、一支铅笔；**禁**头盔、护目镜、夜视仪、军品、相机、三脚架。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩上灰毛巾、旧布鞋。
- 画面内不出现任何文字：手机背无标、纸上无字、本子封面空白、机器无漆字。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- 画风：可见网点 `halftone dot screentone` + 平涂赛璐璐 + 黑墨线；**不是**写实、不是厚涂、不是韩式网漫。
