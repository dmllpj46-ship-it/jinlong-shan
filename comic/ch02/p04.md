# 第二话「上宾」· P04 / 004

**场景**：现代 · 李锦鸿别墅 · 客厅 · 十四天后 · 上午

**页旨**：**不加解释的兑现**。跳过十四天，只用一个动作说完全部：她自己站起来了，手里端着一杯水。全页没有一个人哭、没有一个人说「神了」；李锦鸿的手机还举在半空忘了看——这比任何惊叹都重。苏昭在门内很远的地方看着，**她的脸不给表情**：这屋里的好转是她做的，而且只有她知道，这也是往后每一页她都必须背着的重量。

## 绘制备注

- **分格版式（恰好 3 格，降一档）**：一条贯通全宽的水平格线落在页高 40%；上带为一格（不许再切）；下带由一条**只在带内**的近竖、略斜的格线切成左 38% / 右 62%。Total regions = 3。主格是顶部通栏（40%）。
- 逐格人物数：第 1 格**恰好两个人**——李母（整身、主位）+ 苏昭（画面深处、只到肩膀，**不许**给她的五官细节、**不许**让她的脸比李母的脸更大）；第 2 格**只有李母的手**（不许带脸）；第 3 格**恰好一个人**（李锦鸿）。
- **不解释的硬口径**：本页**禁止**任何「好转的原因」的视觉暗示——不许出现杯底的旧金、不许出现元能、不许出现瓶、不许出现光。读者已经知道（P03），屋里的人不知道；**这个落差就是本页的全部内容**。
- **禁惊叹**：不许出现哭、跪、抱、合十、竖拇指；李锦鸿唯一的表情是**忘了看手机**这一个动作。
- **衣服与季节不变**：十四天里只许变一样东西——**李母围巾换成同一条驼色的、系得松一点**；其他装束一律锁死（针织帽、靛蓝布扣衫）。窗外那株树可以少一半叶子，**不许**用日历、不许用任何带字的牌子表达时间。
- **HAIR / CAST LOCK**：针织帽 + 驼色围巾 + 靛蓝布扣衫的是**李母**（她身上不许出现左颊痣、蓝布包、压平的银发）；灰鬓角 + 炭灰大衣 + 素银表的是**李锦鸿**；低髻 + 长外套的是**苏昭**（本页只给轮廓，**不许**给白发特写——那缕白在这个远景尺度上不该抢眼）。
- **ANTI-DUPLICATION**：客厅里只许两个人（李母、李锦鸿）+ 门洞里的苏昭；不许出现保姆、护工、第二个老人；椅子只有一张，且是空的。
- 参考图链计划：① `assets/characters/li-mu.png` ② `assets/characters/li-jin-hong.png` ③ `assets/characters/su-zhao.png`。
- 配色：上午的冷白 + 落地窗的天光 + 靛蓝 + 驼色 + 玻璃杯的一点透亮；无金、无暖光、无夜景。
- 画面内不出现任何文字（手机屏幕留白、不许出现任何界面）。
