# 第二话「上宾」· P63 / 063

**场景**：现代 · 黑森林 · 窄道一小块空地 · 白天（接 P62）

**页旨**：**不止一只。** 一波接一波的初级小兽成群扑上来——泰哥的人**成一线压低枪口**打退（多团**风格化**枪口焰沿一条线排开，小兽一排被打偏倒地，**干净、无血、无人受伤**），苏雀在右端用银剪补掉冲近的一只，慕白在左端数。陈默仍不出手。这一页把「几次袭击」推到最高，也把苏雀那句「它们这么小」钉死：**恐怖不在强度，在数量和快。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **20%** 与 **66%**；顶带与中带各一整格通栏（中带是主格 46%）；底带由一条**近竖斜线**切 **52 / 48**，斜线只在本带内部。TOTAL PANELS = 4。主格是第 2 格中带通栏（横向力：一线射击 + 成群小兽）。
- 逐格人物/异兽数：第 1 格**恰好六只小兽**（零人）；第 2 格**恰好四个手下（无脸）+ 苏雀 + 陈默 + 慕白 + 五只倒地幼狐 + 苏雀剪尖一只**（外来人一律无正脸，**不许数出第五个手下**）；第 3 格**恰好一个**（慕白手与半侧）；第 4 格**恰好一个**（苏雀半侧）。**异兽逐格数死，同格不许多出；不许镜像分身。**
- **变异幼狐口径（硬，v3.10）**：初级、小、比例正常、**圆瞳不发光**、**哑光暗金纹**、成群而快；**禁**画成大狼、禁发光、禁第二只狼级的东西、禁符纹/阵/龙形。它们**被打退就倒、不复活、不临死睁眼**。
- **暴力上限（硬）**：枪口焰一律**风格化**（冷白星芒 + 速度线），**禁**写实火焰、弹壳特写、瞄准镜 HUD；小兽倒地**干净**——**禁**血、伤口特写、内脏、断体；**无人受伤**。苏雀的银剪只补一只、一个入肉的点，不见血。
- **慕白口径（硬）**：只说数得到的（「一批。三回。」「小的。」），**禁**「元能」「能量」「为什么这么多」；他**不解释**、脸上**不许出现「洞悉」**。
- **苏雀读出（硬）**：「这么小。这么多。」是她这一页的信息量；**不许**她想出源头、不许她说「元能」、不许她往「封」的方向下结论（那是 P65–P66 电话后的事）。
- **黑森林口径**：密针叶黑竖纹、湿腐松针、手电白光楔形；**禁**门洞/谷底/那个口子/任何内部/车辆/建筑/游客设施。
- **HAIR / CAST LOCK**：苏雀全黑高马尾扎紧 + 红夹（唯一红）+ 深炭蓝短夹克 + 银剪；陈默短黑发 + 灰蓝夹克 + 红绳 + 旧木棍；慕白苔灰绿短褂 + 圆框眼镜；手下便帽口罩手套 + 深色哑光长枪，**无正脸**。
- 画面内不出现任何文字（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
