# 第二话「上宾」· P35 / 035

**场景**：现代 · 龙潭镇 · 谷底 · 洞口侧壁与谷里 · 下午

**页旨**：**他们没收拾就走了。** 洞口侧壁一排炮孔、半截导爆管垂着、碎石扇形落点——这是爆破；谷里散着钻机、空压机、电缆盘、油桶、凝成石头的水泥、两根钢轨，全是**两年上下的锈**。铭牌上的年份由苏雀念出来，画面上一个字都不印。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **20%** 与 **56%**；中带由一条**近竖斜线**切 **52 / 48**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（44%）。
- 逐格人物数：第 1 格**零人**；第 2 格**一只手**（陈默的旧线手套，**只在画面边缘，不许碰壁**）；第 3 格**零人**（只有机器）；第 4 格**恰好三个**（苏雀半侧 + 慕白背影 + 陈默背影），**不许第四人、不许把两名蒙面手下画进来、不许出现穿工装的人**。
- **日期口径（硬）**：铭牌**一块字都不印**——长方形金属片、有锈、有反光，读不出字；年份与月份**只由苏雀念出来**（「二四年三月。」「维修章是二五年九月。」）。这是全书的规矩：证据靠人说，图不印字。
- **机器清单（不许加减）**：履带钻机（锈、履带断一节、钻臂垂着）、空压机（锈、缺一个轮）、电缆盘（电缆还绕着）、两只油桶（倒着）、几袋凝成石头的水泥、两根钢轨。**不许**出现集装箱、板房、卷扬机、发电机组、水泵、警示带、脚手架、汽车、卡车、装载机；**不许**出现尸体、血、弹壳、衣服、鞋、饭盒、烟头等人留下的私人物品（**人是溃逃，不是死在这儿**）。
- **锈的程度是本页唯一时间证据**：两年上下的锈是「薄锈、锈在接缝与低处」；**不许**画成彻底锈穿、锈成一堆、长苔长草。机器上的漆还有残色（暗黄、暗绿），但**漆面无字**。
- **爆破痕迹只许三样**：① 等距的炮孔排（孔口发白）② 半截导爆管（细塑胶管、无字）③ 一处炮窝 + 石屑落点。**不许**画炸药、雷管、引线盘、爆破开关、电缆接点火器；**不许**画成大爆炸后的废墟。
- **苏雀不点元能**：这一页她一个字不提元能，只说「一排」「还在」「不止一处」「都没了」。
- **慕白**：他只说「不是老锈」「两年上下」——这是镇上人看锈的本事，**不是**工程量判断。**不许**他说「工程队」「集团」「盗墓」「采金」。
- **陈默**：「这是炸出来的。」「人走的时候没收拾。」——他只做**观察与记录**，本页不下结论（结论留给 P36）。
- **光**：下午的天光偏斜，从一线天落到机器上，把锈照成暗红；机器的影子很长。**洞里永远黑**，手电光停在洞口一寸处。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳 + 旧线手套；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩上灰毛巾、旧布鞋。
- 画面内不出现任何文字：铭牌空白、机器无漆字、袋子无字、导爆管无标。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- 画风：可见网点 `halftone dot screentone` + 平涂赛璐璐 + 黑墨线；**不是**写实、不是厚涂、不是韩式网漫。
