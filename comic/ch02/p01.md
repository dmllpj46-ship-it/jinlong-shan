# 第二话「上宾」· P01 / 001

**场景**：现代 · 李锦鸿别墅 · 门外车道与玄关 · 当天上午

**页旨**：这一页只做一件事——**把尺度摆出来**。山脚那座新盖的小院（第一话 P75–P76）到这座宅子之间隔的不是路，是价钱。三个人各自的态度就是全页的戏：苏雀在算账、陈默在找地方放那盏纸灯、苏昭已经知道这里跟她没关系。**那盏纸灯是从山脚小院带过来的**（陈默 P75 糊的那盏），全页唯一的暖光，也是往后唯一的暖。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 24% 与 60%；只有中带内部由一条近竖、略斜的格线切成左 42% / 右 58%，斜线起止只在本带内部；上带与下带内部不许再切。Total regions = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好一个人**（苏雀的背影，其余只许出现车，不许出现人）；第 2 格**恰好一个人**（苏雀）；第 3 格**恰好一个人**（陈默）；第 4 格**恰好三个人**（苏昭、陈默、苏雀，各一次）。
- **这座宅子的口径**：浅石材、玻璃、长车道、两辆黑车、大理石地面、整墙鞋柜、超长白沙发、复式楼梯、水晶吊灯（冷白）。**禁止**：长桌、没糊完的纸扎竹骨、墙上空白挂轴、立着油布断水的墙角、撕了标签的玻璃瓶（苏昭山边别墅的五样）；石水槽、晾衣绳、钥匙木板、八仙桌、走廊尽头那扇上锁的门（慕白民宿的五样）；砖雕、照壁、香案、神龛（李家小院的禁项）。**这一页不许出现任何暗示采金集团的东西**——图纸袋与安全帽只在 P75 出现过一次，回收要隔很久。
- **HAIR / CAST LOCK**：长外套 + 低髻 + 右鬓一缕白的是**苏昭**（画面左侧那一缕＝她的右鬓，画面右侧全黑，永远不要两缕）；高马尾全黑 + 红雀发夹 + 短夹克的是**苏雀**（她身上**没有**白发、没有长外套、没有纸灯、没有剑）；短黑发 + 灰蓝夹克 + 左腕红绳的是**陈默**（他**没有**长发、没有疤、没有长衫）。
- **ANTI-DUPLICATION**：门廊下只许一个陈默；玄关里三个人各一次，苏昭的身后不许再多出第四个人；车不许出现第三辆。
- 参考图链计划：① `assets/characters/su-que.png`（最容易被抢特征）② `assets/characters/su-zhao.png` ③ `comic/ch01/p76.jpg`（锁画风与前一天的光）。
- 配色：冷白石材 + 浅灰 + 黑车 + 炭灰 + 靛蓝 + 驼色 + 纸灯一点暖；无金、无夜景。
- 画面内不出现任何文字（车标、门牌、纸箱、鞋柜一律留白）。
