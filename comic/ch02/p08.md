# 第二话「上宾」· P08 / 008

**场景**：现代 · 昭记铺子 · 门厅柜台 · 当天下午

**页旨**：**症状全部靠嘴说，一个字的画面证据都不给**——不给回忆格、不给中邪的人、不给屋里发冷的镜头。读者只能信他的话，也只能跟着苏昭一起问。她的问法与 P62 问慕白时是同一个人：**几个人、什么时候开始、白天还是夜里**，只问可数的事，不问为什么。鬼九最后那一句是整页唯一一次交底，而且他说完就闭嘴——**「那句话我不学。」**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 26% 与 64%；只有中带内部由一条近竖斜线切 46 / 54，斜线只在本带内部；上带与下带内部不切。Total regions = 4。主格是第 4 格底部通栏（36%）。
- 逐格人物数：第 1 格**零人**（只有一只手）；第 2 格**恰好一个人**（鬼九半张脸）；第 3 格**零人**（只有手）；第 4 格**恰好三个人**（苏昭、鬼九、陈默；苏雀**不在这一格**）。
- **不许画的东西（硬）**：不许画任何中邪的人、不许插回忆格、不许画「屋里发冷」的空镜、不许画香、香灰、符、水汽——**这一页全部的信息都在台词里**，画面只承担「一个老大在讲他不愿意讲的事」。
- **苏昭的提问口径**：只问可数的事（几个人、哪天开始、白天还是夜里、他们说什么），**不许问「为什么」「是不是脏东西」「是不是风水」**；她一个字的判断都不下，取罗盘是全页唯一动作，且不说话解释。
- **「那句话」口径**：鬼九先拒一次（「那句话我不学。」），停半拍才交出来（「……『门开着。』」），**交出来之后没有任何人接话**——苏昭不问、陈默不问、苏雀不在这一格。往后任何角色不许复述这三个字。
- **HAIR / CAST LOCK**：苏昭长外套 + 低髻 + 右鬓一缕白；陈默短黑发 + 灰蓝夹克 + 左腕红绳（红绳只露一线，不许画成手串）。
- 光：下午斜光一条切进门厅，落在柜台与罗盘上；其余压灰。**无金、无光效、罗盘指针不许动**。
- 画面内不出现任何文字（罗盘盘面、茶碗、账本一律留白）。
