# 第二话「上宾」· P68 / 068

**场景**：现代 · 黑森林 · 谷底 · 洞口旁的施工场地 · 下午（接 P67）

**页旨**：**转到施工地方。** 洞口那侧没有东西，苏雀把人带到**靠山洞一侧的施工场地**——那排弃置两年的机器还在（钻机、空压机、电缆盘、油桶、凝成石头的水泥、两根钢轨），薄锈。她顺着地上一道**拖痕与裂缝线**往山洞那侧走；慕白摸石头、看风，只说数得到的。这里那股"往外倒"的劲，比洞口那一侧**明显重**。苏雀不说破它是什么。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **68%**；顶带与中带各一整格通栏（中带是主格 46%）；底带由一条**近竖斜线**切 **52 / 48**（只在本带内部）。TOTAL PANELS = 4。主格是第 2 格中带通栏。
- 逐格人物数：第 1 格**几个远处无脸手下背影**（零近景）；第 2 格**恰好三个**（苏雀半侧 + 慕白背影 + 陈默背影/半侧），**不许第四人、不许蒙面手下入主格**；第 3 格**恰好一个**（慕白手与半侧）；第 4 格**恰好一个**（苏雀半侧）。
- **机器清单（不许加减，承 v3.5 ④）**：履带钻机（锈、履带断一节、钻臂垂着）、空压机（缺一个轮）、电缆盘（电缆还绕着）、两只油桶（倒着）、几袋凝成石头的水泥、两根钢轨；**漆面无字**。**禁**集装箱、板房、卷扬机、发电机组、水泵、警示带、脚手架、汽车卡车装载机；**禁**尸体、血、弹壳、衣服鞋、饭盒、烟头（人是溃逃，不是死在这儿）。
- **苏雀不点元能（硬）**：她只说「它往外倒」「这边」，**不许**说「元能」「辐射」「能量」「泄露点」（"泄露点"这个词留到 P69 才第一次出现，且仍只由她说一次）。
- **慕白口径（硬）**：只说数得到、看得见的（「石头这边，风往外走。」「凉。」「不是洞里的凉。」），**禁**「元能」「基地」「工程」「集团」；他摸石头看风是镇上人的本事，不是工程判断。
- **再探口径**：这是他们**第二次到这片施工场地**（P35 来过），严禁写成初见；机器、锈、铭牌空白都沿用 P35 口径（年份仍只由苏雀念、图上不印字）。
- **HAIR / CAST LOCK**：苏雀全黑高马尾扎紧 + 红夹（唯一红）+ 深炭蓝短夹克；陈默短黑发 + 灰蓝夹克 + 红绳 + 旧线手套；慕白苔灰绿短褂 + 圆框眼镜 + 旧布鞋；手下无脸。
- 画面内不出现任何文字：机器无漆字、铭牌空白、袋无字（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
