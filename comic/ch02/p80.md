# 第二话「上宾」· P80 / 080

**场景**：现代 · 黑森林地下日军基地 · 核心实验室中央 · 傍晚（接 P79）

**页旨**：**那种压。** 元能浓到极点。三人**不发病**，却被一种**说不清的压迫感**顶住——像肩上压了东西、耳里一线鸣。他们站得住，但都绷着。苏雀把这一屋子的"重"读死：**泄露的源头就在这间屋子里**。慕白只说数得到的（这屋里比外头重）。**元能最终从哪来，本段不揭。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **68%**；顶带与中带各一整格通栏（中带是主格 46%）；底带由一条**近竖斜线**切 **52 / 48**（只在本带内部）。TOTAL PANELS = 4。主格是第 2 格中带通栏（被压感顶住的三人）。
- 逐格人物数：第 1 格**零活人**（只有骸骨剪影）；第 2 格**恰好三个活人 + 若干干骨**；第 3 格**恰好一个**（苏雀半侧）；第 4 格**恰好一个**（慕白半侧）。
- **压迫感只给体感（硬）**：肩沉、扶台、按胸口、耳鸣、牙关——**严禁**把元能压感画成光柱/电弧/可见能量爆发/金色泛滥；薄金雾是唯一的可见元素，克制。**三人免疫、不发病**（不流鼻血、不捂头、不倒下）。
- **苏雀读出（硬）**：「源头，就在这间屋子里。」（台词）+「我没事。可这东西，真重。」（心声）——只到"源头在这屋"；**本段不揭元能最终来源**（B 口径：源头=实验室/罐，与赤蟒脱钩，见 v3.13）；**严禁**赤蟒/封印/山腹/门后。
- **慕白口径**：只说数得到、感觉得到的（「这屋里，比外头重。」），**禁**「元能」「能量」「为什么」；他按胸口是体感，不是运功。
- **骸骨口径**：延续 P79——干骨、蒙灰、无血肉无腐烂无脸骨特写；当遗址画。
- **HAIR / CAST LOCK**：苏雀全黑高马尾扎紧 + 红夹（唯一红）+ 深炭蓝短夹克；陈默短黑发 + 灰蓝夹克 + 红绳 + 旧木棍；慕白苔灰绿短褂 + 圆框眼镜。
- 画面内不出现任何文字（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
