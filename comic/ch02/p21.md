# 第二话「上宾」· P21 / 021

**场景**：现代 · 昭记铺内 · 同一夜，更晚

**页旨**：**她的判断只给数字，不给道理。** 「一年。第四处。」「一处比一处远。」「那是好还是不好。」「不好。」——苏雀问到这里，苏昭只回一个字。陈默在心里记一句：「她没说是哪四处。」

**这一页是全书第一次由苏昭亲口报出「第四处」**，也是她第一次承认「不好」；但她一个字也不解释，**不许任何人把这四处列出来**。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **20%** 与 **56%**；只有中带内部由一条**近水平斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（44%，本页最大单格）。
- 逐格人物数：第 1 格**恰好三个**（苏昭、苏雀、陈默）；第 2 格**恰好一个**（苏雀半侧脸 + 银剪）；第 3 格**零脸**（桌面 + 一只食指）；第 4 格**恰好三个**（前景两个背影 + 逆光里的苏昭轮廓）。
- **「第四处」的分量（硬）**：这是苏昭第一次亲口报数。她**不许**列出这四处在哪、**不许**说「城西货仓」「黑森林」「内河」「城北」任何一处地名；这四处在画面上只允许以第 3 格那**四道指纹**存在。
- **「不好」只许一个字**：她答完就停，**不许**补句、**不许**解释、**不许**安慰。苏雀也**不许**再追问。
- **四道短横必须是按出来的、不是画的**：食指侧面压桌面、指尖有一点点白；**不许**出现符文、刻痕、符纸、朱砂、墨线。
- **逆光的口径**：第 4 格苏昭**只给轮廓与下颌**——不许给正脸、不许给眼神、不许给她背后的灯加光晕或光柱；纸灯只画成一只纸罩灯，暖光是一圈普通的暖边。
- **HAIR / CAST LOCK**：苏昭＝全黑低髻（逆光下只给发型轮廓，**不许**把发髻画散、**不许**给白发带）；苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳。
