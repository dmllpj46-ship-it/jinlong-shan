# 第二话「上宾」· P03 / 003

**场景**：现代 · 李锦鸿别墅 · 客厅 · 上午近午（接 P02）

**页旨**：**全段唯一一次真正的动作在这一页**，而且只有读者看得见。苏昭把身子转过去，挡住所有人的视线，指间落下一线极细的元能，沉进那杯水里——水**不留光**、不起雾、不泛金，只有杯底看得见一线细丝，随即散尽。她把杯子递给李母，说的是「凉茶」。李母只说了两个字：「温的。」（元能水是温的，这是她唯一能察觉到的异样，也是往后唯一的伏笔。）苏雀在门框那边看了那杯水**多半秒**——不是知道，是记下了。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 34% 与 66%；只有中带内部由一条近竖、略斜的格线切成左 50% / 右 50%，斜线起止只在本带内部；上带与下带内部不许再切。Total regions = 4。主格是顶部通栏（34%）——**戏眼在那一滴上，所以主格给顶部**。
- 逐格人物数：第 1 格**恰好一个人**（苏昭，侧身，只见肩背与手，不见脸）；第 2 格**没有人**（只有杯子与桌面）；第 3 格**恰好一个人**（苏雀）；第 4 格**恰好一个人**（李母）+ 苏昭**只到袖口**。
- **这是全段唯一一次「兑现」**：一线元能沉进水里 → 给李母续命半年、不能起死回生。**禁止**任何解释性画面：不许回忆闪回、不许虚影、不许出现瓶、不许出现龙形与金脉、不许她在这一页之后提这件事。
- **水的口径（硬）**：水**不变色**、**不发亮**、**不起雾**、**不倒映金光**；唯一可见的异样是**杯底一线极细的哑光旧金**，且已经散了一半；第二格如果画成「一杯发光的液体」，整页作废重出。
- **李母只说「……温的。」**：这是她能察觉到的全部；她**不许**说出「这不是茶」「你放了什么」。往后任何角色不许复述这两个字。
- **苏雀只许「记下」**：她看那杯水多半秒，**不许**伸手、**不许**皱眉质问、**不许**在后面的页里说出来（她心里存着，往后才用）。她说的「这水——」被苏昭用「凉茶」截断。
- **HAIR / CAST LOCK**：长外套 + 低髻 + 右鬓一缕白的是**苏昭**；高马尾 + 红雀发夹 + 短夹克的是**苏雀**（她身上没有白发）；针织帽 + 驼色围巾的是**李母**。
- **ANTI-DUPLICATION**：不许出现两个苏昭的手；第 4 格不许再多出第二个人端着杯子。
- 参考图链计划：① `assets/characters/su-zhao.png` ② `assets/characters/li-mu.png` ③ `comic/ch01/p76.jpg`。
- 配色：冷白室内 + 炭灰 + 靛蓝 + 驼色；一线哑光旧金是**全页唯一的金**，且极细；无暖光（纸灯不在本页）。
- 画面内不出现任何文字。
