# 第二话「上宾」· P09 / 009

**场景**：现代 · 昭记铺子 · 门厅柜台 · 当天下午

**页旨**：**保票不是资格证明，是一句话把一个人认下来**。鬼九看陈默面生，迟疑只给半秒——他不是不信陈默，他是不信一个没名没姓的人能站在自己兄弟出事的那间屋里。苏昭的回答只有四个字：「我的人。」她**不夸他**（不许说「他有本事」「他学过」），她只说「他站在那儿，我放心」。而真正让鬼九松口的是苏雀往前半步：**这趟她主事**——他认的是这个。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 20% 与 58%；只有中带内部由一条近竖斜线切 46 / 54，斜线只在本带内部。Total regions = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**恰好一个人**（鬼九的眼与半脸）；第 2 格**恰好一个人**（陈默）；第 3 格**恰好一个人**（苏昭下半脸）；第 4 格**恰好一个人**（苏雀）。**四格四个人，一人一格，不许同格出现两个头。**
- **迟疑的口径（硬）**：鬼九的迟疑**不许画成敌意**——不是瞪、不是手按桌上、不是往后仰；只是**眼睛停住半秒、嘴角往下压一点**。他没说一句「不行」，他只是问了一句「哪路的」。
- **苏昭的保票口径**：只有「我的人。」「他站在那儿，我放心。」两句，**不许夸、不许解释、不许加条件**；她也不看陈默（看的是鬼九），这是她给的面子不是给他的鼓励。
- **苏雀主打的依据**：她往前半步、把手压在腰侧（银剪那一侧），一句话把主次说明——**往后这一段的所有指令从她口里出，苏昭不在场**。
- **HAIR / CAST LOCK**：苏昭长外套 + 低髻 + 右鬓一缕白（画面左侧那一缕，右侧全黑，永远不要两缕）；苏雀高马尾全黑 + 红雀发夹 + 深炭蓝短夹克（**NOT red / orange / maroon**，唯一红元素是发夹）；陈默短黑发 + 灰蓝夹克 + 左腕红绳。
- 光：下午斜光落在苏雀身上（她是这一格唯一被照亮的人），其余压灰。**无金**。
- 画面内不出现任何文字。
