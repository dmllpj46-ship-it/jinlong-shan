# 第二话「上宾」· P32 / 032

**场景**：现代 · 龙潭镇 · 谷底碎石地 · 正午

**页旨**：**一格都没有。** 谷底是一块**平得不像自然**的碎石地，头顶两片坡夹成一线天。手机举高、放下、再举高，屏幕一直是白的；对讲机只有沙。他们三个在山谷里失了所有对外的话路——**这是本段后面所有选择的物理前提**。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **26%** 与 **60%**；中带由一条**近竖斜线**切 **50 / 50**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好三个背影**（不许第四人）；第 2 格**半个**（陈默下半张脸 + 手机，**眼睛不入画、不许大特写脸**）；第 3 格**零脸**（一只手 + 对讲机）；第 4 格**零人**（只有三条影子，**不许给影子主人**）。全页**没有一张完整的脸**。
- **屏幕口径（v3.4 沿用，硬）**：手机屏只许**一片亮白**——没有图标、状态栏、时钟、电量、信号格、播放键、进度条、文件名、任何字母数字，**没有**「无服务」提示框。对讲机**没有屏**、通身无标识无字。第 4 格三部东西的屏幕/面一律空白。
- **谷底的「平」是本页唯一证据**：碎石均匀、像被压过、边上还留着两条很直的低埂；**不许**画成施工工地、不许出现车辙、围挡、标线、文字。读者要只觉得「不自然」，说不出为什么。
- **一线天**：光从画面顶部一条窄缝下来，落在碎石上形成一条亮带；**三个人站在亮带的边上，不站在光里**。亮度不许做成丁达尔光柱。
- **手电**：普通白光，光锥窄、边界硬，反光落在碎石上发亮；不许发光雾、不许光柱。
- **慕白的知识边界（硬）**：他只说「谷底就这样」「上头有信号，下来就没了」——**这是他在谷里几十年的经验，不是原理**。不许他说「干扰」「磁场」「信号被压」「能量」。
- **苏雀不点元能**：她这一页一个字都不提元能，只说「这地平得不对」「沙。什么都没有」。
- **对讲机**是苏雀自己的旧货（ch01 起就有），灰塑壳、无标、天线可拉；**禁**画成警用/军用、禁带屏、禁带字。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩上的灰毛巾。
- 画面内不出现任何文字：石头无刻痕、对讲机无字、手机屏空白。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- 画风：可见网点 `halftone dot screentone` + 平涂赛璐璐 + 黑墨线；**不是**写实、不是厚涂、不是韩式网漫。
