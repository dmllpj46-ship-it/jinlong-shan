# 第二话「上宾」· P56 / 056

**场景**：现代 · 龙潭镇 · 慕白民宿堂屋 → 门廊 · 上午

**页旨**：**定下来。** 慕白只给数得到的条件——多远、走多久、他的人在哪条线外头等；他不说「里」有什么。苏雀把这一趟拍死：她进、陈默进、慕白的人在外线接应。这里有一条**没说破的越界**：山那边那位老古董交代过「告诉他，别进林子」，而这一趟是苏雀自己拍的板——她只留一句「回去再跟她讲。」，不解释、不安慰。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **58%**；只有中带内部由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；顶带与底带各一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**恰好一个**（慕白半侧）；第 2 格**恰好一个**（苏雀正面）；第 3 格**恰好一个**（陈默半侧，苏雀只画外）；第 4 格**恰好三个**（两个背影 + 慕白半侧），**不许第四人、不许走廊里多一个影子**。
- **慕白口径（硬）**：只给数得到的（「一天。」「天亮进去，天黑前外形…」这类），**禁**「能量」「基地」「工程队」「集团」「里有什么」；他只送到线外，本页**不许**他跨进围栏、不许背包。外形以 `mu-bai-v2.png` 为准，禁止一切道士视觉语言、禁止非人感。
- **越界这条不许说破（硬）**：山那边「别进林子」是**苏昭在 P42 定下的边界**（承 v3.6 ⑦「告诉他，别进林子。」苏雀答「他听。」），但**这一趟是苏雀自己拍的板**——只许以她一句心声「她说的是别进林子。」「这一趟是我拍的板。」承担，**不许**她对陈默解释、**不许**慕白提起、**不许**旁白点破；「回去再跟她讲」是拖延不是方案。
- **苏雀主打（硬）**：行动的话全从她口里出；她**不说「元能」**，只说「我进」「你的人在线外头等」这种可数的调度。
- **手机口径（承 P30）**：陈默举着的手机屏幕**只许一片亮白或空白信号格**，**严禁**图标、状态栏、时钟、电量、运营商、任何字；本页不许他真拨出去。
- **手绘路口径**：通身无字，纯墨线等高线 + 圈，第五圈偏外、墨湿；禁一切字、图例、比例尺、指北针、数字。
- **民宿 / 上锁的门（硬）**：走廊尽头那扇门**门缝下绝对不给光**——「那扇门后面没有灯」是旧钩子，漏光即作废。民宿不是别墅，禁串道具。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝近黑短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩灰毛巾。
