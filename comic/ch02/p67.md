# 第二话「上宾」· P67 / 067

**场景**：现代 · 黑森林 · 谷底 · 那个方口门洞前 · 白天（承 P66 往里，接 P31–P36 的现场）

**页旨**：**到深谷，先探洞口。** 依上次慕白那张圈图与无人机断点，一队人回到谷底——**这是再探，不是初见**（陈默、苏雀、慕白都来过，P31–P36）。那个被凿成方口的门洞还在，洞里还是纯黑；手电照进去一步就没。**这一处没有新东西。** 泰哥一伙全程持械散在洞口外，慕白这次跟人一起站进了谷底。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **40%** 与 **70%**；顶带是一整格通栏主格（40%）；中带由一条**近竖斜线**切 **46 / 54**（只在本带内部）；底带一整格通栏。TOTAL PANELS = 4。主格是第 1 格顶部通栏。
- 逐格人物数：第 1 格**恰好三个近景背影 + 几个远处无脸手下**（外来人一律无正脸，**不许数出具体第七人**）；第 2 格**零人**（只有门洞）；第 3 格**恰好一个**（苏雀半侧）；第 4 格**三个近景背影 + 几个无脸手下背影**。
- **再探口径（硬，承 v3.3 ⑧ / P31–P36）**：三人**来过这个谷底、看过这个门洞**，**严禁**写成初见、惊讶、问「这是什么地方」；陈默只一句心声，苏雀一句「上回我们到过」。
- **门洞口径（硬，承 v3.5 ⑧）**：**方口**（上沿平、两侧直、四角直角），**洞里纯黑、手电一步就没**——**严禁**画洞内地貌、深处任何东西、反光、眼睛、门板、招牌、编号；**本段不进这个门洞、不给里面任何东西**（"门后面是什么"这颗雷仍守住）。人工痕迹只许：切齐混凝土边、预埋螺栓、通风管、排水沟、门框空槽。
- **慕白口径（硬）**：只说数得到的（「还是没进去过。」「石头那边，风不一样。」），**禁**「元能」「能量」「基地」「工程」「集团」；他这次站进谷底（v3.10 已解除"不跨线"），但仍是镇上人看石头看风的本事。
- **持械口径（v3.10 延续）**：泰哥一伙全程可见持械（深色哑光长枪端在手里/背肩上），**无正脸、无血腥、无迷彩、无徽记**；本页无战斗。
- **黑森林/谷底口径**：密针叶黑竖纹、湿腐松针、平碎石地、坡壁白色断面、手电白光楔形；**禁**游客设施、车辆、建筑、那个更黑的口子以外的东西。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝近黑短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳 + 旧线手套；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩灰毛巾、旧布鞋；手下便帽 + 口罩 + 手套 + 橄榄工装 + 长枪，**无正脸**。
