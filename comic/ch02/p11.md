# 第二话「上宾」· P11 / 011

**场景**：现代 · 昭记铺子 · 门口与广场 · 当天傍晚

**页旨**：**出门前她给的不是方法，是边界。** 苏昭不送出门——她站在门里，只到衣角与一只手。给陈默的三句全是"不许做什么"：看着、别动手、她让你站哪你就站哪。给苏雀的只有一句「要真是那个，你知道怎么办。」——**「那个」两个字她没解释，陈默也没敢问**，这一句是全书第一次让读者知道：她心里已经有一个猜测，而且她把它交给了别人。陈默在车门边抓了一下腕上的红绳——他紧张时的老动作，不许任何人指出。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 22% 与 60%；只有中带内部由一条近竖斜线切 46 / 54，斜线只在本带内部。Total regions = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好两个背影**（跟班）+ 车；第 2 格**恰好一个人**（苏昭的下半脸）；第 3 格**零人**（只有两只手）；第 4 格**恰好一个人 + 远处一个衣角**（陈默在前景、苏昭在门内深处只到衣角与手，不给脸）。
- **苏昭不送出门（硬）**：她**整页停在门内**，不出门、不下台阶、不挥手；远景里她只占很小一块，不许给表情、不许给眼睛。
- **「那个」口径（硬）**：苏昭说出「要真是那个」之后，**任何人都不许追问**，也不许在这一页把「那个」跟元能、瓶、渗出、堂口风水任何一个词连起来；陈默的心声只允许有一句「『那个』是什么，她没说。」
- **陈默的动作**：抓红绳是**紧张时的旧习惯**（承 P64 他捏着空瓶那类小动作），**不许任何人指出、不许特写强调、不许画成护身符**。
- **HAIR / CAST LOCK**：苏昭长外套 + 低髻 + 右鬓一缕白；苏雀高马尾 + 红雀发夹 + 深炭蓝短夹克（**NOT red / orange / maroon**）；陈默短黑发 + 灰蓝夹克 + 左腕红绳（红绳只许细，不许加坠子）。
- 光：傍晚的斜光偏黄但不许发橙，广场灰蓝调；**无金、无路灯亮起**。
- 画面内不出现任何文字（车牌空白、卷帘门与招牌留白）。
