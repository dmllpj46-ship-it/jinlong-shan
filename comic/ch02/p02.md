# 第二话「上宾」· P02 / 002

**场景**：现代 · 李锦鸿别墅 · 客厅 · 上午近午

**页旨**：一场手艺，也是一场表演。罗盘、一根拉直的棉线、撒成几道分开短横的米、那盏纸灯——第一话 P75 用过的全套东西，搬进这座冷白的宅子里，**看起来反而更像戏**。全页只看苏昭的手；只有读者该记住的是那壶水（P03 才动它）。**李锦鸿第一次被放进「观众」的位子**——苏昭只对他说三个字：你看着。

## 绘制备注

- **分格版式（恰好 4 格）**：一条**贯通全高的竖线**落在页宽 38%（这条线从页顶一直到页底，不许断）；左列满高为**一格**，右列内部再由两条**只在右列内部**的水平格线（页高 24% 与 56%）切成上 24% / 中 32% / 下 44%。Total regions = 4。主格是第 1 格左侧满高纵格。
- 逐格人物数：第 1 格**只有手**（苏昭的手与袖口，不许带脸、不许带第二个人）；第 2 格**恰好一个人**（李母）；第 3 格**恰好一个人**（李锦鸿）；第 4 格**恰好一个人**（苏雀）。
- **法事＝手艺，不是法术**：只有罗盘、一根拉直的棉线、几道分开的短横米、那盏竹骨纸灯、一壶茶与两只玻璃杯。**禁止**：法阵光效、地上的圈与阵图、符纸燃烧、金雾、光柱、瞳心金圈、罗盘指针疯转、任何悬浮与发光的东西。**米必须是几道分开的短横**，绝不围成弧、环、方、星或任何对称图形。
- **「你看着。」是全页唯一给李锦鸿的指令**：苏昭不许对他解释、不许看他第二眼；他说什么都不许有，**这一页他没有台词**（他的话在 P05）。
- **HAIR / CAST LOCK**：长外套 + 低髻 + 右鬓一缕白的是**苏昭**（本页只见袖口，但白发不许出现在任何别处）；高马尾 + 红雀发夹 + 短夹克 + 银剪的是**苏雀**；针织帽 + 驼色围巾的是**李母**（她身上不许出现左颊痣、蓝布包、压平的银发——那是 `lao-fu`）；灰鬓角 + 炭灰大衣 + 素银表的是**李锦鸿**。
- **ANTI-DUPLICATION**：右列三格各一个人，不许出现第二个李母或第二个苏雀；左侧纵格里不许出现任何人的脸或第二双手。
- 参考图链计划：① `assets/characters/su-zhao.png` ② `assets/characters/li-mu.png` ③ `comic/ch01/p76.jpg`。
- 配色：冷白室内 + 木质茶几的暖褐 + 炭灰 + 靛蓝 + 驼色；米是白的；**唯一的暖光是那盏纸灯**；无金。
- 画面内不出现任何文字（罗盘盘面留白、茶壶杯子一律无字）。
