# 第二话「上宾」· P07 / 007

**场景**：现代 · 金龙山景区广场 · 昭记铺前与门厅 · 当天下午

**页旨**：先把「来的是谁」摆出来——**不是砸场子的排场，是一个懂礼数的老大**。兴义会来了一辆车、两个人，都停在门外；鬼九自己进门，进门第一件事是**把帽子摘下来放在柜台上**。苏昭不迎不送，只把柜台上的账本挪开半尺——这两个人之间有过生意，所以不用寒暄。全页不许出现一件武器、一处纹身特写、一句狠话：他的分量全由「只带两个人」「先摘帽子」两件事读出来。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 24% 与 60%；只有中带内部由一条近竖、略斜的格线切成左 40% / 右 60%，斜线起止只在本带内部。Total regions = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好三个人影**（两个跟班背影 + 车里不给脸），街上游客只给远处剪影；第 2 格**零人**（只有手）；第 3 格**恰好一个人**（苏昭半张脸）；第 4 格**恰好三个人**（鬼九、陈默、苏雀各一次）。
- **鬼九的口径（硬）**：约五十出头、**矮壮**（比陈默矮半头，肩厚）、寸头灰多黑少、左眉尾一道旧疤、右眼略眯（旧伤，不瞎）、方脸厚下颌；**深灰双排扣呢大衣敞穿 + 黑高领 + 深色西裤 + 一双擦得亮的旧皮鞋**；左手无名指一只**素金圈戒指**、左腕一只**旧皮带手表**、**右手小指第一节缺**。**禁止**武器（刀、枪、棍、指虎）、**禁止**纹身、**禁止**金链大戒指、**禁止**墨镜、**禁止**任何带字的物件（帽、盒、账本、门牌一律留白）。
- **兴义会的排场口径**：只一辆车、两个跟班；跟班**未定妆**——帽檐压低 + 只给背影与肩，任何一格不给正脸、不给名字、不给动作；不站在门里，只停在门外。
- **HAIR / CAST LOCK**：长外套 + 低髻 + 右鬓一缕白＝**苏昭**（画面左侧那一缕是她的右鬓）；高马尾全黑 + 红雀发夹 + 深炭蓝短夹克＝**苏雀**（无白发、无长外套）；短黑发 + 灰蓝夹克 + 左腕红绳＝**陈默**（无长发、无疤）。
- **ANTI-DUPLICATION**：门外只许两个跟班、一辆车；门厅里三个人各一次，不许在柜台后再多出一个人。
- 光：下午斜光从门外进来，落在柜台一角；室内只有那一小块亮，其余压灰。**无金、无夜景、无香火**。
- 画面内不出现任何文字。
