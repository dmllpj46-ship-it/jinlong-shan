# 第二话「上宾」· P46 / 046

**场景**：现代 · 李锦鸿的别墅 · 私人书房 · 同一个下午

**页旨**：**她只问可数的事。** 三样被删（合同、名单、结算）、什么时候发现的（上个月）、还有谁经手（两个人、一个走了）。她不问为什么、不问是谁、不问图什么；她只翻纸——**纸上每一条横线都在、每个格子都空着，装订夹那一段少了一叠，纸边整齐、没有撕口**。她心里那句是：「不是撕的，是抽出去的。」

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **24%** 与 **64%**；中带由一条**近竖斜线**切 **50 / 50**，斜线只在本带内部、不上下越行；底带一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（36%）。
- 逐格人物数：第 1 格**零人**；第 2 格**恰好一个**（苏昭）；第 3 格**恰好一个**（李锦鸿）；第 4 格**恰好一个**（苏昭，**只有手与袖口**，脸不入画）。
- **本页的视觉证据只有一个（硬）**：装订夹里那一段空。两个孔对齐、夹子还在、**抽走的那一叠留下的是整齐的边与一段空**；**禁**撕口、**禁**碎纸、**禁**垃圾桶、**禁**碎纸机、**禁**涂黑的字块、**禁**马赛克条、**禁**打孔碎屑。读者要能看出「被拿走了」，不是「被撕掉了」。
- **纸面零字（硬，本页最高风险）**：表格线可以有，**格子里一个字符都不许有**——无数字、无编号、无姓名、无日期、无公章、无签名、无页眉页脚、无页码、无水印；**不许**出现「机密」类框印章；**不许**出现表格里的小字号假字（哪怕像字）。
- **她只问三件可数的事**：「删了哪几样。」「经手的人。」——本页**只问这两句**，第三件（什么时候）由他主动给「上个月发现的」；**不许**她问「为什么」「谁下的令」「跟挖山什么关系」。
- **他的答案只有五个短语**：合同 / 名单 / 结算 / 上个月发现的 / 两个，一个上个月走了。**不许**给公司名、职务、城市、人名、年龄、去向；**不许**他说「内鬼」这个词（那是 P47 的事）。
- **陈默只有一句心声**：「纸上什么都没有。」——只给读者，**不许**他出声、**不许**他去碰纸。
- **光**：仍是那一盏台灯；第 1、4 格靠台灯斜光把纸边照白，其余压暗但网点可见；**不许**第二处暖光。
- **HAIR / CAST / COLOR LOCK**：苏昭＝**头发 100% 全黑**、低发髻、闭合深灰长外套；李锦鸿＝四十上下、俊朗、短黑发、深色西装无花纹；陈默（只一声心声，不入画亦可）。
- 画面内不出现任何文字（纸面空格、杯身无标）。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
- prompt 首段固定：`VISIBLE HALFTONE DOT SCREENTONE — flat cel shading — crisp black ink linework — professional Japanese shonen fantasy manga page`；并写 `NOT webtoon, NOT painterly, NOT semi-realistic skin`。
