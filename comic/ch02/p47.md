# 第二话「上宾」· P47 / 047

**场景**：现代 · 李锦鸿的别墅 · 私人书房 · 同一个下午

**页旨**：**他要她替他说一句。** 他说「我下面有人。」「我信不过。」然后给出交易的全部条件：您帮我找这个人，我替您把外头的事办了；这件事，他要第一个说清楚。苏昭只给两样东西——一句「我信你。」，理由是**可数的**（要动这处，你不会用自己的公司）；一条边界（查到人，先别动，告诉我）。她心里那句是：他要的是清白，可他要的是**有人替他说**。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **62%**；**中带是一整格通栏（左右出血），内部不切**；底带由一条**近竖斜线**切 **52 / 48**，斜线只在本带内部、不上下越行。TOTAL PANELS = 4。主格是中带（40%，两人同格、身体关系是本页的戏）。
- 逐格人物数：第 1 格**零人**；第 2 格**恰好两个**（李锦鸿、苏昭）；第 3 格**恰好一个**（苏昭）；第 4 格**恰好一个**（李锦鸿）。**陈默不在本页任何一格**（他站在画面之外半步，**不许**给他一格、**不许**给他脸）。
- **交易口径（硬，本段最重要的一条）**：他给的是**两样换一样**——她找人、他办外头的事；他补一句「这件事，我要第一个说清楚。」，意思是**由她去把这句说出去**。**不许**他说「洗清嫌疑」「证明我不知情」「我发誓」；**不许**他给钱、**不许**他提报酬、**不许**他递卡递信封、**不许**出现任何带字物件。
- **她的答句必须有理由（硬）**：先「我信你。」，紧跟一条**可数**的理由「要动这处，你不会用自己的公司。」——**不许**她说「我感觉得出来」「你不是那种人」「我看人准」这类凭感觉的话；也**不许**她说元能、山、锁、阵眼。
- **边界只两条**：「查到人，先别动。」「告诉我。」——承 v3.6 ⑫ 的口径：**不许**加「小心」，**不许**她给备选做法，**不许**她提山门、报警、上报。
- **她的两句心声只给读者**：「他要的是清白。」「可他要的是有人替他说。」——**不许**任何人接，**不许**他听见，**不许**她露出表情。
- **「坐下了」是本页唯一的动作事件**：他从进门起一直站着（P45、P46），这一格才坐下、手才离开桌面；**不许**他站到最后，也**不许**他起身走。
- **光**：只有那一盏台灯；第 1 格窗外散光偏西（时间在走，但不给钟表）；**不许**第二处暖光。
- **HAIR / CAST / COLOR LOCK**：苏昭＝**头发 100% 全黑**、低发髻、闭合深灰长外套、不是年长妇人；李锦鸿＝四十上下、俊朗、短黑发、深色西装无花纹、领口松着，**禁**烟、雪茄、金链、名表、保镖、油腻感。
- 画面内不出现任何文字（纸面空格、杯身无标、窗外无招牌）。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
