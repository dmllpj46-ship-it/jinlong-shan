# 第二话「上宾」· P58 / 058

**场景**：现代 · 龙潭镇 · 慕白民宿堂屋 · 上午（接 P57）

**页旨**：**泰哥。** 领头人第一次给正脸（定妆 `tai-ge.png` v1）。他不坐主位、进门先看地形、话短而职业；一名手下开口叫他「泰哥」，名字是别人喊出来的，不是他自报的。他把来意摊在桌上：替**东家**把这块地「量清楚」——不给公司名、不点请他的人是谁、不提任何武器。苏雀不接这套，她打量他；陈默在心里记住那副「当过兵」的样子。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **58%**；只有中带内部由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；顶带与底带各一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**恰好两个**（泰哥半侧 + 一名无脸手下）；第 2 格**恰好一个**（泰哥正脸第一次）；第 3 格**恰好一个**（苏雀半侧）；第 4 格**恰好四个**（泰哥、苏雀、陈默只到肩手不给脸、慕白只到半侧），**不许第五人、不许手下入主格**。
- **泰哥外形（硬，v3.9）**：一律以 `assets/characters/tai-ge.png` 为准——四十上下、精瘦结实、约 178 cm、橄榄色拉链工装夹克（无徽无迷彩）、深色工装裤、靴、短黑发、颧骨一道旧疤、神色平、眼神外扫、不笑。**Never-change**：短黑发 + 颧骨旧疤 + 橄榄工装夹克。**绝不给他**：枪、刀、任何武器、holster、战术背心、头盔、迷彩、军徽、军衔、旗、墨镜、金链、纹身、长发、胡子、眼镜。
- **泰哥口径（硬）**：他是**李锦鸿请来的私人勘探队领头**，不是江湖人、不是黑帮、不是官方。**不报名字**（「泰哥」由手下喊出）、**不自报家门**；他的台词只到「替东家把这块地量清楚」「出钱的那个」，**禁**说出「李锦鸿」「采金」「集团」「工程队」「元能」「锁」「山腹」；**禁**任何武器、狠话、威胁。**他的分量靠整齐与沉默读**（先行踩点、看地形、不坐主位）。
- **与鬼九硬性区分**：鬼九是**旧呢帽 + 摘帽 + 礼数**；泰哥是**工装 + 仪器 + 工程队的整齐**。两人本段不同框。
- **苏雀不接这套（硬）**：她只问一句「哪个东家。」，**不许**她当场点破是李锦鸿（那是 P59）、不许她动气、不许她示弱。
- **陈默的定位**：只观察、只一句心声「……当过兵的。」；**禁**他问原理、**禁**他说「我要去」「报警」「叫人来」。
- **仪器口径**：那只测量仪器**盘面无读数、无字、无 logo**；装备箱**通身无标**；只作「专业勘探」的视觉证据，**不许**画成科幻设备或军品。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝近黑短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；泰哥＝短黑发 + 橄榄夹克、**无红**；慕白＝苔灰绿短褂、谢顶花白。
- 画面内不出现任何文字（`ZERO TYPOGRAPHY`，格位称 AREA ONE/TWO/THREE/FOUR）。
