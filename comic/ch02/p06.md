# 第二话「上宾」· P06 / 006

**场景**：现代 · 别墅门外 · 夜里 · 收工

**页旨**：收束页只留给苏昭一个人。她做了所有人都会谢她、但她不能承认的事，**所以她一个字都不说**。全页只留两句轻的：陈默说「她比上次好多了。」察觉得到的是「她答得太快了」（第一话 P76）那一层，但他到这里都还没想明白；苏雀说「那杯水是温的。」——她记下来了，还差一点。最后苏昭一个人站在夜里，手按在左胸（守山印），只给读者两句：「半年。」「……够了。」

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 20% 与 58%；只有中带内部由一条近竖、略斜的格线切成左 46% / 右 54%，斜线起止只在本带内部；上带与下带内部不许再切。Total regions = 4。主格是底部通栏（42%）。
- 逐格人物数：第 1 格**恰好一个人**（陈默的半张侧脸；车里不许露出第二个人的脸）；第 2 格**恰好一个人**（苏雀）；第 3 格**恰好一张下半脸**（苏昭，不许出现第二个人）；第 4 格**恰好一个人**（苏昭，全身在画面内，后面不许有人）。
- **她一个人扛**：第 4 格是全书第一次让读者单独看着她「做完一件不能说的好事」。**禁止**：回望、叹气夸张、眼眶湿、抱紧自己、跪坐。她只垂着眼，手按在守山印上——这是她一贯的动作（承第一话她按守山印的那些夜）。
- **心声只给读者、且只说两句**：「半年。」「……够了。」——**禁止**她在后面任何一页复述、**禁止**任何人听见、**禁止**她解释「够了」是什么意思。这是全书关于元能水唯一一次明说时长。
- **苏雀那半句**：她说的是「那杯水是温的。」**不是**「你放了什么」；苏昭答「凉茶。」之后她**不再追问**，也不许在本页皱眉。她记下了，往后要用。
- **陈默**：「她比上次好多了。」是他能说的全部；他**不许**问「阵真的有用吗」第二次（第一话 P76 已经问过并得到答案），也**不许**在这一页想明白「她答得太快了」。
- **HAIR / CAST LOCK**：长外套 + 低髻 + 右鬓一缕白的是**苏昭**（夜里那一缕白是最亮的一处，但不许发光、不许变成两侧各一缕）；高马尾 + 红雀发夹 + 短夹克的是**苏雀**；短黑发 + 灰蓝夹克 + 左腕红绳的是**陈默**（夜里红绳只剩一点暗红）。
- **ANTI-DUPLICATION**：车门边只许一个陈默；第 4 格身后不许出现任何车灯、人影、狗。
- 参考图链计划：① `assets/characters/su-zhao.png` ② `assets/characters/su-que.png` ③ `assets/characters/chen-mo.png`。
- 配色：夜 + 冷灰 + 车漆的黑 + 炭灰 + 靛蓝一点点；**无金、无暖光、无月光（第一话夜景的规矩）**；她按守山印的那只手是本页最亮的一小块皮肤。
- 画面内不出现任何文字。
