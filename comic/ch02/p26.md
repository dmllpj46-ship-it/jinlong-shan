# 第二话「上宾」· P26 / 026

**场景**：现代 · 龙潭镇 · 慕白的民宿堂屋 · 清晨

**页旨**：**他自己去的。** 上一单之后，慕白没有等苏昭派人——他自己沿围栏外头走了三趟，把每一处「不对」都落在纸上。他数到的第五个圈，画在这一页，墨还新。这一页只有一个信息：**这个镇子上有人一直在数。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **60%**；只有中带内部由一条**近竖斜线**切 **44 / 56**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**零个人**；第 2 格**恰好一个**（慕白，半侧）；第 3 格**恰好两个**（苏雀俯身 + 陈默在身后半步，**陈默不给脸**）；第 4 格**零个人**（只有图与压图的东西）。
- **手绘图的口径（硬，沿用 P48 / P56）**：一张**通身无字**的手绘路——只有墨线的山脊、林线与折线；**不许出现任何地名、村名、路名、比例尺、指北针、图例、坐标、数字、字母**。墨圈**只表示次数与先后**，不表示地点；**不许把圈画在地形特征上让它「指得出来」**（圈的位置要模糊、要落在图的边缘与留白上）。
- **五个圈分两种墨**：前四个是旧的（边缘发灰、墨色偏褐），第五个是新的（黑、湿、边缘还有一笔没收住的拖尾）；**只许这五个**，不许第六个、不许虚线、不许箭头。
- **慕白口径**：外形以 `mu-bai-v2.png` 为准；**不许给他任何道士视觉语言**（无罗盘、无符纸、无朱砂、无铜钱、无香）；他摸图的动作是**劳动的人摸自己的账本**，不是掐诀。台词只说半句，**不许解释他为什么一个人去**。
- **「他自己去的」这一层不许任何人说破**：苏雀那句「一个人走的?」只许是**确认**，不许是敬佩或责备；陈默的两句心声是本页唯一的情感落点，**不许他说出来**。
- **光**：清晨，屋里只有窗外进来的白灰光；台灯**灭着**（这一页不许给它亮）；桌面是唯一被照亮的区域，四角压暗。
- 画面内不出现任何文字：图上无字、墙上无字、桌上无字、纸箱与挂件**全部留白**。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`）。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩上灰毛巾。
- 画风：可见网点 `halftone dot screentone` + 平涂赛璐璐 + 黑墨线；**不是**写实、不是厚涂、不是韩式网漫。
