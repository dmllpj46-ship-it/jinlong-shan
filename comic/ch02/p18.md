# 第二话「上宾」· P18 / 018

**场景**：现代 · 兴义会堂口巷口 · 回程车内 · 当天深夜

**页旨**：**来源落地：龙潭镇。** 鬼九说得很轻：去年秋天去那边玩，路边一个种地的摆在塑料布上卖，三百块，说是挖地挖出来的。陈默追问一句「他没说在哪儿挖的?」，鬼九答「问了。他说地里。」——苏雀当场把话头截断（「行了。」）。回程车里两个人都不说话，只有两句心声：陈默「又是龙潭镇。」；苏雀「地里挖出来的。」「……挖了多深。」**这一页不给任何推论，只给一个地名和一个停顿。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 24% 与 58%；只有中带内部由一条近竖斜线切 46 / 54，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数：第 1 格**恰好四个人**（两个跟班背影 + 鬼九 + 车内一人半边，另一个人不在画面里）；第 2 格**零脸**（只有鬼九的嘴与下颌）；第 3 格**零脸**（只有苏雀的一只手 + 车门框）；第 4 格**恰好两个人**（苏雀 + 陈默，侧脸，很小）。
- **来源的口径（硬）**：地名只说「龙潭镇」，**不许**说镇北、林子、黑森林、山脚、哪条沟、哪个村；价钱只说「三百」，**不许**给票面、**不许**画钞票；「挖地挖出来的」只说一次，**不许**追问到具体位置（陈默问了就被苏雀截断）。
- **截断的时机**：苏雀说「行了。」时**不看鬼九**、也不解释；这一句必须落在第 3 格，不许挪到第 4 格。
- **不给推论**：全页不许任何人说出「龙潭镇出事了」「又是那个口子」「那个镇子有问题」这类话；两处「龙潭镇」只由**陈默的心声**与**苏雀的两句心声**承担。
- **回程页的空间**：车窗外是冷青的路灯与湿沥青（与 ch01 城市口径一致）；车内暗，只有仪表的一点光。**不许**出现第二个地名、不许出现手机屏幕、不许出现任何带字的招牌或路牌。
- **旧帆布包**：深褐色、软、无字、无 logo，袋口用棉绳扎紧（与 P17 同一只）。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾 + 红雀发夹 + 深炭蓝短夹克（NOT red/orange/maroon）；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；鬼九＝寸头灰多黑少 + 左眉尾旧疤 + 深灰双排扣呢大衣 + 黑高领。**两个人都不许有白缕。**
- 画面内不出现任何文字。
