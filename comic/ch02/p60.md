# 第二话「上宾」· P60 / 060

**场景**：现代 · 龙潭镇 · 慕白民宿院门口 → 土路往北 → 禁区围栏缺口方向 · 上午（接 P59）

**页旨**：**整装待发。** 分工只谈可数的：泰哥的队带仪器**开道**、慕白的人**在线外**接应、苏雀与陈默进去**看**。院里两套东西并排——苏雀那只旧编织袋（绳、手电、电池、纱布、水）与泰哥的硬质箱、三脚架，**市井的手艺和职业的仪器第一次同框**。收在出发前最后一格：土路往北，人往那个方向走，慕白的旧布鞋**停在院门外的网侧**、不跨线；远处黑森林压成一道黑墙。**这一段只到「出发」，不进林子、不到谷底、不给那个口子任何东西。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **58%**；只有中带内部由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；顶带与底带各一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（42%）。
- 逐格人物数（**逐格数死，本页最易多切人头**）：第 1 格**零脸**（物 + 几只手）；第 2 格**恰好一个**（苏雀半侧）；第 3 格**恰好一个**（泰哥半侧）；第 4 格**恰好三个近景背影 + 两个远处小背影 + 慕白只到一双鞋**——**外来人一律无脸、不许第七人、不许林子里多一个影子**。
- **只到出发（硬）**：本页**严禁**进林子、到谷口、见那个方口门洞、见谷底机器——那是后续段的事；画面最远只到「土路 + 远处黑墙」，**那个更黑的口子本页不给**（承 v3.4 ⑥「谷里是什么本章一个字不给」，本段仍未到揭的时候）。
- **两套装备同框（新口径，v3.9）**：苏雀的可数手艺（编织袋、绳、白光手电、电池、纱布、水）与泰哥的专业勘探（硬质箱、测量三脚架、成卷线缆、空白仪器）**并置**，是这段唯一要读者看见的对比——**市井 vs 职业**。**不许**任何角色评论这个对比、不许旁白点破；**严禁**给泰哥一方加枪、刀、任何武器、战术装备、迷彩、徽记。
- **慕白不跨线（硬，承 v3.4 ⑨）**：他的旧布鞋停在院门外的网侧、人与那圈铁丝/院门保持一步，**只送不进、不带包**；「鞋我数好了」是他一辈子数人头的规矩，这一页他数的是**要走的人**——**不许**煽情、不许任何人接这句话。
- **苏雀的边界只有两句**（「到谷口，先别下。」「看见什么，先记住，别追。」）——全是「别做」，**不给方法**、不说装备怎么用；**不许**她说「元能」「锁」「山」。
- **陈默的定位**：只一句心声承 P30（「上一次，我们只到林子边上。」），**不许**他兴奋、不许说「我要去」「报警」「叫人来」。
- **禁区 / 镇子口径**：锈铁丝网、水泥墩 + 一块**永远空白**的警示牌、湿腐松针、密针叶树黑竖纹；**不许**景区设施、车辙、弹壳、血迹、动物尸体；所有招牌路牌警示牌留白。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝近黑短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；泰哥＝短黑发 + 橄榄工装夹克、无红；慕白＝旧布鞋、苔灰绿短褂、谢顶花白。外来手下无脸、无红。
