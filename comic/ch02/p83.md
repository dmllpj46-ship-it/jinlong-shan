# 第二话「上宾」· P83 / 083

**场景**：现代 · 黑森林地下日军基地 · 核心实验室 · 傍晚（接 P82）

**页旨**：**那次意外。** 三人把证据拼起来：骸骨 + 爪痕墙 + 焦孔 + 倒翻的设备 + 破裂的罐，全在这一屋里——**几十年前一次意外**：罐里的元能漏出来，**实验人员变了异、自相残**，整个实验室就这么毁了。**不闪回、不给残杀画面**，只让手电扫过这些痕迹、由苏雀说出结论。慕白只数得到的（"都是这一屋的"）。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **44%** 与 **72%**；顶带是一整格通栏主格（44%，证据全景）；中带由一条**近竖斜线**切 **46 / 54**（只在本带内部）；底带一整格通栏。TOTAL PANELS = 4。主格是第 1 格顶部通栏。
- 逐格人物数：第 1 格**恰好三个活人 + 若干干骨**；第 2 格**恰好一个**（苏雀半侧）；第 3 格**恰好一个**（陈默半侧）；第 4 格**恰好一个**（慕白半侧）。
- **不闪回、不画残杀（硬）**：这段"意外"只由**痕迹 + 苏雀的结论**读出——**严禁**画变异过程、画实验人员互殴、画活着的怪物、画新鲜血腥；骸骨/爪痕/焦孔都是**几十年的旧遗迹**（干骨、蒙灰、无脸骨特写）。
- **苏雀说结论（硬）**：「罐漏了。人变了。然后——自己打的。」——这是三人的**推断**（承用户口述：罐体元能泄露→实验人员变异→实验室毁）；**严禁**苏雀或任何人把"元能最终从哪来"讲成道理（B 口径：本段源头=这实验室/罐，与赤蟒脱钩，见 v3.13）。
- **慕白口径**：只数（「都是这一屋的。」），**禁**「变异」「元能」「为什么」。
- **陈默被噎**：一句「那他们……」被苏雀接掉；**不许**他追问原理、不许他说"报警/叫人来"。
- **骸骨口径**：延续 P79——干骨、蒙灰、无血肉无腐烂无脸骨特写；当遗址画。
- **HAIR / CAST LOCK**：苏雀全黑高马尾扎紧 + 红夹（唯一红）+ 深炭蓝短夹克；陈默短黑发 + 灰蓝夹克 + 红绳；慕白苔灰绿短褂 + 圆框眼镜。
