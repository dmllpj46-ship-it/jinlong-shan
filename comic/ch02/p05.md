# 第二话「上宾」· P05 / 005

**场景**：现代 · 李锦鸿别墅 · 玄关与客厅之间 · 同一天近午

**页旨**：回礼整桌摆出来，**苏昭一件不取**，只把陈默糊的那盏纸灯抱走。这一页同时完成两件事：① 李锦鸿把她奉为上宾（他亲自站在桌对面、手掌压着桌面说话，这在他身上是最客气的姿态）；② 他**暗暗想结交**——他没说一句生意，他的眼睛在算这个人值多少钱。**他不收手，因为她什么都不要；越是不要，他越要找门路。**「灯我带走」是全页唯一的动作，也是她给自己留的唯一一件东西。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 22% 与 60%；只有中带内部由一条近竖、略斜的格线切成左 46% / 右 54%，斜线起止只在本带内部；上带与下带内部不许再切。Total regions = 4。主格是底部通栏（40%）。
- 逐格人物数：第 1 格**没有人**（只有物）；第 2 格**恰好一个人**（李锦鸿）；第 3 格**恰好一双手 + 苏雀的半身**（不许出现第二个人在旁边数）；第 4 格**恰好一个人**（苏昭）。
- **她一件不取**：法事钱早结过（第一话 P73 她只抽了一张钞），所以这一桌是纯人情；**她不许拿走任何一样**，包括钱、补品、酒、外套。她抱走的纸灯**属于她自己带来的东西**——这一点不许任何人解释。
- **李锦鸿的「暗暗想结交」只能由动作读**：手掌压桌、身体前倾、站在桌对面不坐下、送客时抢先半步到门边（这些在 P05 与 P06 之间完成，本页只给到前倾与压桌）。**禁止**他掏出名片、**禁止**任何带字的物件、**禁止**他说出「采金」「工程」「矿」这些字，**禁止**他说出「合作」。
- **回礼的器物口径**：锦盒、皮筋捆的无字纸钞、两只素色纸箱、两只**无标白瓷瓶**（不许酒标、不许封口贴）、一件叠好的驼色外套。**画面里一个字都不许有。**
- **HAIR / CAST LOCK**：长外套 + 低髻 + 右鬓一缕白的是**苏昭**（本页侧后三分之一，那一缕白不许画粗、不许变成两侧各一缕）；高马尾 + 红雀发夹 + 短夹克的是**苏雀**；灰鬓角 + 炭灰大衣 + 素银表的是**李锦鸿**（大衣敞穿、白衬衫开领、黑马甲）。
- **ANTI-DUPLICATION**：中带两格各一个人，不许出现第二个商人或第二个苏雀；桌上物件不许出现两份相同的锦盒。
- 参考图链计划：① `assets/characters/li-jin-hong.png` ② `assets/characters/su-que.png` ③ `assets/characters/su-zhao.png`。
- 配色：冷白室内 + 木质长几的暖褐 + 驼色 + 纸灯一点暖 + 白瓷的冷白；无金。
- 画面内不出现任何文字。
