# 第二话「上宾」· P27 / 027

**场景**：现代 · 龙潭镇 · 慕白的民宿堂屋 · 清晨

**页旨**：**飞了四趟。** 他把那架无人机放在桌上，把「没法去」这件事说成账：四趟，两趟没回来。**没掉——是信号先断。** 她问断在哪儿，他的手指落在图上那个新画的圈上，一句话都不多。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **20%** 与 **56%**；只有中带内部由一条**近水平**的斜线切 **46 / 54**，斜线只在本带内部、不上下越行（**斜线不许骑到上下两条横线上**）；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（44%）。
- 逐格人物数：第 1 格**零个人**（只有无人机、包、图）；第 2 格**零脸**（只给慕白的两只手与袖口）；第 3 格**一个半人**（苏雀的嘴与下颌 + 陈默一只手，**两人的脸都不给全**）；第 4 格**零脸**（恰好两只手：慕白的一只、苏雀的一只）。
- **无人机口径（v2.5 沿用，硬）**：深灰四旋翼、塑料壳、收桨、机身一道**胶带缠过的旧裂**；**无标识、无 logo、无屏幕、无 HUD、无录像红点、无取景框、不发光、不投射光线**；云台镜头是**实体部件**（允许）；颜色只有深灰与旧胶带的黄褐。**禁止**科幻设备、机翼、鸟、探照灯、天线阵列、军用涂装。
- **「四趟」必须自己算得清**：四趟出去，三趟断在林子里，两趟断在**同一个点**（其中一趟是掉了；另一趟是断信号后自己回来的）——台词里只出现数字，**不许解释机制、不许说干扰源是什么、不许提频率与波段**。
- **「同一个点」的落法**：他手指按的位置必须是**上一页那个新画的第五个圈**；圈的位置依旧模糊，落在图的边缘与留白上，**不许与地形特征咬死**。
- **慕白的知识边界（硬）**：他不知道元能、不知道锁、不知道山——他只能说**看见的**（几趟、哪儿断、树怎么长）；**不许**他说「能量」「波动」「元能」「阵法」「煞」。
- **光**：清晨的窗光；台灯**仍灭着**；无人机的塑料壳上只许有一点窗光的反白，**不许给它自发光**。
- 画面内不出现任何文字：机身无字、包上无字、图上无字、胶带无字。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`）。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂。
- 画风：可见网点 `halftone dot screentone` + 平涂赛璐璐 + 黑墨线；**不是**写实、不是厚涂、不是韩式网漫。
