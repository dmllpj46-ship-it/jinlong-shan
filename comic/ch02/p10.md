# 第二话「上宾」· P10 / 010

**场景**：现代 · 昭记铺子 · 门厅 · 当天下午

**页旨**：**戒心是怎么放下的——不是本事，是一句真话。** 鬼九问「你怕不怕」，陈默答「……怕。」不解释、不逞强、不补一句「我不怕」。鬼九笑了，笑的是他见过太多不怕的人，那些人都不长命。这一格之后他坐下、帽子搁在膝上——**从站着到坐下，就是戒心解除的全部表演**。两人又聊了几句：问这孩子哪来的，苏昭答「路上。」，鬼九说「路上好啊。」——全段唯一一句像长辈说的话，也是他从「验人」转成「看人」的那一刻。

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 24% 与 60%；只有中带内部由一条近竖斜线切 50 / 50，斜线只在本带内部。Total regions = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**恰好一个人**；第 2 格**恰好一个人**；第 3 格**零人**（只有两只肩与一只手）；第 4 格**恰好三个人 + 门边两个背影**（苏雀、苏昭、鬼九；跟班**只给背影**，且必须在门边、不许进门厅中央）。
- **「放下戒心」的口径（硬）**：只由三件事读——① 他**坐下了**（此前两页他都站着）；② **帽子从柜台挪到膝上**；③ 他**问了一句家常**（这孩子哪捡的）。**禁止**拍肩之外的身体接触、禁止拥抱、禁止「以后有事尽管找我」这类许诺、禁止他说出任何「合作」「生意」「打点」的词。
- **陈默的答句口径**：「……怕。」**只有一个字加省略号**，禁止补「但我不退」「我不怕死」；他答完不许挺胸、不许看苏雀求认可。
- **苏昭的两句**：只答「路上。」，不解释来历、不加一句评价；**她不许笑**。
- 门边两个跟班**未定妆**：帽檐压低、只给背影与肩，不给正脸、不给名字、不参与对话。
- **HAIR / CAST LOCK**：苏昭长外套 + 低髻 + 右鬓一缕白；苏雀高马尾 + 红雀发夹 + 深炭蓝短夹克（**NOT red**）；陈默短黑发 + 灰蓝夹克 + 左腕红绳；鬼九寸头灰多黑少 + 眉尾旧疤 + 深灰双排扣呢大衣。
- 光：下午的光已经斜到门框上，门厅里只剩柜台一圈亮。**无金、无香火**。
- 画面内不出现任何文字（茶碗、帽子、门框一律留白）。
