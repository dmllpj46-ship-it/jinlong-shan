# 第二话「上宾」· P29 / 029

**场景**：现代 · 龙潭镇 · 慕白的民宿堂屋 · 上午

**页旨**：**底下在递。** 四趟，同一个点断——苏雀只用这一点就下了判断，措辞全部是可数的事：「底下有东西在递。」「递得比堂口那件凶。」**她不说「元能」**（那个词在第二话只说给陈默一次）。慕白问「那底下是什么」，她答「不知道。所以才要下去。」他把地图上那个点叫作「谷」，并且先说了最难听的一句：**谷没有名字，我数不到里头。**

## 绘制备注

- **分格版式（恰好 4 格）**：两条贯通全宽的水平格线落在页高 **22%** 与 **60%**；只有中带内部由一条**近竖斜线**切 **46 / 54**，斜线只在本带内部、不上下越行；底带是一整格通栏、内部不切。TOTAL PANELS = 4。主格是第 4 格底部通栏（40%）。
- 逐格人物数：第 1 格**零脸**（嘴、下颌、一根手指）；第 2 格**恰好一个**（慕白正面）；第 3 格**零脸**（两只手与搪瓷缸）；第 4 格**恰好三个人**（陈默半侧为主，右侧两点轮廓是慕白与苏雀，**三点都不是第四个人**）。
- **台词口径（硬，本页最要紧）**：
  - 苏雀**不许说「元能」**（第二话该词只在 P16 出现过一次）；她只能说「有东西在递」「递得比堂口那件凶」——「堂口那件」指那块白玉，**不许解释、不许复述它的样子**。
  - **不许她说「能量波动」「磁场」「辐射」「异常值」**——她是干活的人，不是仪器。
  - 慕白**不许**说「元能」「锁」「山」「阵」；他的台词只能是他数得到的东西（几趟、哪儿断、走多久、数不到里头）。
  - **「谷」这个称呼由慕白给出，只说一次**：「那地方，我们叫谷。」「没有名字。」——**不许**给谷起地名、不许说「无名谷」这种书面说法。
- **「数不到里头」是本页的钥匙**：他守的是**边上**，不是里面；这句必须在第 3 格，且**不许任何人接**（陈默与苏雀都不许追问「为什么」）。
- **陈默的定位**：他在这一页第一次问「要多久」——问的是**路**，不是「那是什么」；他的两句心声承 P24，**不许**他说「我要去」，也不许他显得兴奋。
- **慕白正面格的分寸**：这是他本章第一次被给正面，**不许**画成「高人开口」——肩膀要垮、坐姿要塌、手要交叠在桌上；不许打侧光塑轮廓，不许让他站起来。
- **光**：上午的窗光偏白、偏硬，从画左进来；台灯灭着；桌上的图与缸是受光面，墙面留大片灰。
- 画面内不出现任何文字：图上无字、缸上无字、墙与木梁无字。禁止字母、数字、格号标记（`ZERO TYPOGRAPHY`）。
- **HAIR / CAST LOCK**：苏雀＝全黑高马尾扎紧 + 红雀发夹（全页唯一红）+ 深炭蓝短夹克；陈默＝短黑发全黑 + 灰蓝夹克 + 左腕旧红绳；慕白＝谢顶一圈花白、圆框眼镜、苔灰绿对襟布扣短褂、肩上灰毛巾、左手木珠。
- 画风：可见网点 `halftone dot screentone` + 平涂赛璐璐 + 黑墨线；**不是**写实、不是厚涂、不是韩式网漫。
