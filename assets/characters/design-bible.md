## Locked art direction

Reuse this block verbatim in every image prompt:

World block — reuse verbatim whenever 金龙山 itself is in frame:

> Eastern mountain fantasy, ancient Chinese temple stairs and torn prayer banners, a wingless serpentine dragon implied by the mountain ridgelines, layered pale-gold mist, cinnabar accents, ink-black pines, weathered stone and raw gold

## World canon

### 一句话

山是一条睡着的龙；有人撬走了它颈上唯一不能离体的鳞。

### 七条硬规则

1. **山即龙。** 山脉是龙的脊背，矿脉是血，金雾是呼吸。龙在故事的大部分时间里不许站起来；山体、云、岩层与雾就是它的表演。
2. **百年换鳞。** 每百年一次。旧鳞脱落，山体改道；换鳞之后龙会翻身，翻身即山崩。故事从换鳞前一百天开始，倒计时是天然的压力。
3. **金雾见未来。** 雾里能看见未发生的事，画面用重影、错位与极淡的线表现，不出现任何可读文字。吸雾太久的人先忘名字，再忘脸。
4. **逆鳞不可离体。** 长在龙颈，只有一枚。离体后认持有者为主；持有者能听见龙的心跳，也会被龙一点一点看见。
5. **龙心是一个愿望。** 山顶心火，传说能实现一个愿望。守山一脉的规矩是「不能让任何人碰到」；故事结束前不确认它是否真的灵验。
6. **金鳞离体仍生长。** 金鳞司靠采鳞立国，采得越多，龙病得越重。金鳞是货币、建材、药材，也是伤口。
7. **地图永远过期。** 山每天在动。所有路线、距离、关卡都只是「上一次有人走过时」的样子。

### 势力

| 势力 | 目标 | 代价 | 视觉语言 |
| --- | --- | --- | --- |
| 金鳞司 | 用逆鳞控制换鳞与翻身，保住山下城池 | 把龙当成可以管理的矿；采鳞至龙病 | 鎏金甲片、朱砂官印、等距仪仗、整齐到冷酷 |
| 守山一脉 | 让龙继续睡，任何人不得碰龙心 | 一脉单传，知道真相的人必须留下 | 素麻、旧铜铃、被雾洗白的幡、没有姓名的墓碑 |
| 拾鳞人 | 靠落鳞吃饭，跟着山势搬家 | 熟悉山的脾气，却不熟悉山的秘密 | 补丁短打、拾鳞钩、蛇皮袋、磨损的护腕 |
| 无面香客 | 上山许一个愿 | 走得越深，越记不起自己；最后连脸也留下 | 白布覆面、空白名牒、一步一叩、越来越轻的行李 |

### 地理

- **鳞市。** 山脚的移动城镇，屋顶用落鳞当瓦，集市用金鳞当钱。换鳞之年全城随山势搬迁，街道没有名字，只有编号。
- **千阶。** 从鳞市上山的唯一旧路，石阶一路没进雾里，一侧永远没有栏杆。阶上每隔一段有一面幡，幡上的字早被雾洗掉。
- **龙脊。** 山腰的鳞状岩台，风大，旧寺只剩地基。站在这里能看见山脉像一条盘起来的脊背，但看不见头。
- **龙心。** 山顶的心火，没有庙，只有一只凿在岩石里的石臼。守山人叫它「不能实现的愿望」。
- **山外。** 平原、河道与别的城。山外的人不相信龙，只相信今年的金价。

### 画风与叙事禁令

- **龙的形态**：东方龙——无翼、蛇身、鹿角、鲤鳞、鹰爪、长须。禁止西式有翼巨龙、恐龙、蜥蜴人。
- **金色预算**：一页里饱和金只允许出现在龙气、逆鳞、金鳞三处。官服、铠甲、首饰用低饱和的黄铜或土金，不许抢叙事物的金。
- **山体拟态**：山脊像盘龙，岩层像鳞，河像尾，湖像眼。**在最终揭示之前，不许画出完整的龙头。** 只给局部、剪影、云里的轮廓。
- **建筑**：中国山岳寺观、栈道、石阶、经幡。不要欧式城堡、尖顶教堂、蒸汽朋克机械。
- **人物**：少年漫画的夸张表情与利落动作；禁止写真、厚涂、3D 渲染感。
- **暴力**：少年漫画尺度。可以有血、有断器，但不做猎奇特写。
- **年龄**：未成年角色不做性化处理；服装剪裁以行动方便为先。
- **文字**：画面内不生成任何文字、印章文字、可读榜文。文字统一留给上字阶段。

## Cast slots

角色名与设定图未定。Slugs 在定妆前保持不变；定妆后用真实 kebab-case slug 替换。

### `lead` — 主角位（未定妆）

- **叙事合同**：拾鳞人，第一个听见龙心跳的人；逆鳞的持有者/运送者。
- **必须承担的戏**：在「送回逆鳞」与「使用逆鳞」之间做选择；越靠近龙心，越像龙。
- **定妆时必须确定**：年龄与体型、发型与面部记号、随身物、服装剪裁、配色、never-change 清单。
- **禁令**：定妆图入库前，不得生成被当作 canon 的主角正脸；剪影、背影、手部与氛围图可以。

### `partner` — 同行位（未定妆）

- **叙事合同**：守山一脉，或叛出金鳞司的人；懂山的规矩，和主角在「送回还是使用」上正面冲突。
- **必须承担的戏**：知道得比主角多，但每一句真话都要付代价；第一次带主角看见「山的疼」。
- **定妆时必须确定**：与金鳞司/守山一脉的视觉归属、随身法器或工具、与主角的身高差与剪影对比。

### `rival` — 追兵位（未定妆）

- **叙事合同**：金鳞司执鳞官，负责追回逆鳞；相信控制换鳞才能保住山下的人，不是纯恶。
- **必须承担的戏**：每次交手都推进「谁更有资格替山下的人做决定」；在最后一幕必须做出自己的选择。
- **定妆时必须确定**：官阶标识、制式装备、与主角团相反的配色秩序（整齐、对称、低饱和金）。

### `guide` — 引路位（未定妆）

- **叙事合同**：无面香客或老拾鳞人；带路收费，知道龙心的位置，已经丢了一半名字。
- **必须承担的戏**：用「名字」作为路费；在关键节点提醒读者：山会拿走它想要的东西。
- **定妆时必须确定**：覆面/露脸的程度、名牒与随身物、声音与步态（他/她的戏多半在走路时）。

### `dragon` — 龙（非人形锚点，未定妆）

- **形态**：无翼蛇身东方龙，鹿角、鲤鳞、鹰爪、长须；山脉即身体。
- **出现方式**：只以山脊、鳞状岩层、雾中的轮廓、湖眼、地震与金雨出现；全貌留到故事结尾。
- **配色**：墨、青灰、雾白为主，金只作为反光与龙气，不把整条龙画成金色。
- **禁令**：不画西式翼龙；不提前给龙头特写；不把龙做成可对话的萌宠或旁白角色。
- **定妆产出**：1536x1024 横版场景锚点，而非角色设定版式。

### 定妆清单（每个角色位必填）

1. 年龄 / 体型 / 站姿
2. 发型 / 面部记号 / 眼神
3. 标志性道具
4. 服装剪裁与材质
5. 配色（主色、辅色、点缀色）
6. Never-change 清单（三到五项）
7. 当前叙事状态（首次登场页、已知信息、关系）

## Scene anchors（暂无成图）

以下场景在首话成图前以文字为准；成图后回填「以 Pxx 成图为准」。

- **鳞市**：屋顶是落鳞，街道按编号，集市用金鳞交易；整座城可以在一夜之间搬走。不要画成固定古镇。
- **千阶**：石阶没入雾，一侧无栏杆；幡是旧的，字被洗掉；脚步声是主要音效。
- **龙脊**：鳞状岩台、风、旧寺地基；在这里能看见山的「背」，看不见头。
- **龙心**：山顶石臼里的一簇火，没有庙、没有祭坛装饰；周围是被历代守山人磨亮的石头。
- **金雾**：用重影与错位表现「未发生的事」；雾里出现的东西一律不清晰、不可读、不可交谈。

## Using the anchors

1. **Same character, new page**：pass the matching sheet as a reference image and state “the first image is the identity and costume reference; keep face, hair, silhouette, costume and palette unchanged”. Restate the locked art direction.
2. **Multi-character panel**：one reference per character, labeled by order. Keep each character's never-change list in the prompt. Respect the 3-reference limit; build a lineup composite if a panel needs more.
3. **New characters**：generate a sheet in the same layout, add them here, then they become canon.
4. **One pass per asset.** No regeneration loops. If the result deviates, record the deviation in the page notes and move on.
5. **Before 定妆**：only silhouettes, back views, hands, props and atmosphere. No canon faces.
6. **Versioning**：never overwrite an anchor; add `slug-v2.png` and update this file.

## Naming conventions

- Character slugs: lowercase kebab-case, e.g. `shen-yan`, `old-scale-picker`.
- Chinese name + English name in the docs and site.
- Chapter folders: `comic/chNN/`; pages: `pNN.png` + `pNN.md` (two digits, continuous across chapters as the story grows).
